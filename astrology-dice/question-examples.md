# Astrology Dice Question Examples｜占星骰子問題範例

占星骰子的問題可以分成：萬用問題、星象類、工作類、伴侶關係類、居家生活類、財富類、靈性成長類。

## 一、萬用問題

適合任何狀況：

```text
什麼是此刻我最需要知道的事？
狀況背後的意圖／目的是什麼？
真正的阻礙是什麼？
問題的核心是什麼？
我最需要採取的行動是什麼？
最快的捷徑是什麼？
最高的可能性／目標是什麼？
做這個決定會有什麼結果？
我的靈魂想要顯化什麼？
我要把能量聚焦／放在哪裡？
```

## 二、星象類問題

適合搭配行運、新月、滿月、水逆等星象：

```text
這次水星逆行我要學習什麼？
這個星象／相位有沒有要特別給我的更深訊息？
這個星象之後我可以得到什麼力量？
這個新月許願有什麼建議？
這次滿月想提醒我什麼？
```

## 三、工作類問題

適合工作、職涯、面試、考核、客戶、主管：

```text
本週我在工作上的能量狀況如何？
這次談判／面試／考核大概會如何？
今天與新的客戶見面要注意什麼？
今天有沒有機會完成某個工作／解決某個問題？
我要如何做才能達到上司主管的要求？
我要往哪個方向努力？
當前這個狀況中有什麼機會？
我需要再學習進修什麼？
```

## 四、伴侶關係類問題

適合感情、伴侶、人際、曖昧、關係進展：

```text
適合我的伴侶關係有什麼特質？
我跟伴侶真正需要溝通什麼？
伴侶現在需要什麼樣的支持？
關於戀愛運有什麼建議？
要如何改善人際關係？
我和某人的關係真正的主題是什麼？
關係要如何維持？
如何做可以讓關係有進一步發展？
關於下一個新戀情的指引是什麼？
```

## 五、居家生活類問題

適合家庭、居住、親子、手足、父母、祖先能量：

```text
關於親子／手足／父母關係，有什麼相處上的建議？
要如何改善家中環境的能量？
關於家族／祖先能量，有什麼我需要知道的訊息？
我需要為家裡做什麼？
```

## 六、財富類問題

適合財務、收入、開支、賺錢方式：

```text
關於財富管理上的建議是什麼？
適合我的賺錢方式是什麼？
臨時有筆開支，錢可以從哪裡來？
我要選擇哪一種財務安排？
這個投資或花費需要注意什麼？
```

## 七、靈性與自我成長類問題

適合內在探索、人生方向、夢境、直覺：

```text
我現在的靈魂功課是什麼？
夢裡的訊息想提醒我什麼？
我需要放下什麼？
我需要相信什麼？
我現在最需要療癒的地方是什麼？
我該如何強化直覺力？
```

## 八、追問問題

當第一組骰子已經得到結果，但想更清楚時，可以追問：

```text
我可以怎麼做？
這件事的下一步是什麼？
我需要避免什麼？
我需要看見什麼盲點？
如果我照這個方向走，會帶來什麼提醒？
```
