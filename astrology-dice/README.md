# Astrology Dice｜占星骰子資料庫

這個資料夾整理「占星骰子」的使用方法、解讀流程、問題範例與符號對應。

> 來源：使用者提供的星骰附贈書內容。此處為學習筆記與解讀流程整理，不是逐字重製原書。

## 占星骰子的基本組成

占星骰子通常由三顆 12 面骰組成：

```text
行星骰：代表主導問題的狀態／主角／作用力
星座骰：代表此作用力表現出來的能量特質
宮位骰：代表影響或關聯的生命領域
```

因此，占星骰子的答案通常不是單純的「是／否」，而是需要把三個符號整合成一段訊息。

## 核心公式

```text
行星 = 發生什麼能量／誰是主角
星座 = 這股能量怎麼表現
宮位 = 這件事發生在哪個生活領域
```

也可以理解成：

```text
誰／什麼力量 → 用什麼方式 → 在哪個領域發生
```

## 使用態度

占星骰子適合用來獲得當下需要知道的提醒、方向與靈感，而不是把結果視為絕對命定。

占卜前需要：

- 先確認問題
- 靜下心來
- 保持平常心
- 不把骰子當成權威
- 把結果視為提醒與參考
- 最後仍由自己為選擇與行動負責

## 適合使用的情境

- 每日指引
- 工作狀況
- 感情關係
- 人際互動
- 財富管理
- 選擇與決定
- 靈性與內在探索
- 想理解某個狀況背後的核心意義

## 解讀原則

1. 不直接斷吉凶。
2. 不把結果當成命令。
3. 優先給出有幫助的提醒。
4. 若結果看似不理想，改用「需要留意什麼」「可以採取什麼行動」來理解。
5. 可以結合本命星盤一起看，但占星骰子本身仍是當下訊息。
