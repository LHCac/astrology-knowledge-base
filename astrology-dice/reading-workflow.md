# Astrology Dice Reading Workflow｜占星骰子解讀流程

## 一、占卜前準備

### 1. 確認問題

先把問題想清楚。問題越清楚，解讀越容易聚焦。

適合問：

```text
這件事的核心是什麼？
我現在需要採取什麼行動？
目前這段關係真正的主題是什麼？
這個選擇會帶來什麼提醒？
```

不建議只問：

```text
會不會成功？
他到底愛不愛我？
我一定會怎樣嗎？
```

因為占星骰子比較適合提供狀態、方向與提醒，而不是絕對答案。

### 2. 靜心

占卜前先讓自己停一下。

可以做：

```text
深呼吸三次
把問題默念一次
讓情緒先降下來
不要急著得到自己想要的答案
```

### 3. 擲骰

擲出三顆骰子：

```text
行星骰
星座骰
宮位骰
```

記錄結果：

```text
行星：
星座：
宮位：
問題：
時間：
```

## 二、基礎解讀公式

```text
行星 = 主導問題的狀態／主角／作用力
星座 = 行星能量表現出的特質
宮位 = 影響或關聯的生命領域
```

整合句型：

```text
這件事的核心能量是「行星」，它會用「星座」的方式表現，並主要發生在「宮位」代表的生活領域。
```

範例：

```text
金星 + 獅子座 + 第三宮
```

可以解讀為：

```text
這件事的重點與關係、喜好、吸引力或價值感有關。
它會以獅子座的方式表現：需要被看見、需要自信表達、需要有熱度。
影響領域在第三宮：溝通、訊息、學習、日常交流。
```

整合後：

```text
這件事的關鍵在於表達心意。你需要把喜歡、欣賞或真正重視的東西說出來，而不是等對方猜。
```

## 三、解讀順序

### 第一步：先看行星

問自己：

```text
這件事由什麼能量主導？
這顆行星在這個問題裡像誰？
它代表狀況、人物、需求，還是事件？
```

### 第二步：再看星座

問自己：

```text
這股能量用什麼風格表現？
是主動、保守、情緒化、理性、深沉、自由，還是模糊？
```

### 第三步：最後看宮位

問自己：

```text
這件事主要發生在哪個生活領域？
關係？工作？金錢？家庭？學習？社群？潛意識？
```

### 第四步：整合成一句話

```text
這組骰子想提醒的是：＿＿＿＿＿＿。
```

### 第五步：給出行動建議

```text
你現在可以做的是：＿＿＿＿＿＿。
需要避免的是：＿＿＿＿＿＿。
```

## 四、完整解讀格式

```text
## 占星骰子結果

問題：
行星：
星座：
宮位：

## 一、核心訊息
用 1～2 段說明這組骰子最直接的訊息。

## 二、三層拆解

### 行星：
說明主導能量。

### 星座：
說明能量表現方式。

### 宮位：
說明影響領域。

## 三、整合解讀
把行星、星座、宮位合在一起，用生活化語言說明。

## 四、提醒與建議
- 可以採取的行動
- 需要留意的地方
- 可以再追問的問題

## 五、一句話總結
用一句話收束答案。
```

---

## 五、看似不理想的結果怎麼處理

若骰子結果看起來不舒服，不要直接視為壞結果。

可以改問：

```text
這組結果提醒我需要注意什麼？
我可以採取什麼行動？
這件事有什麼更正面的理解？
我需要放下什麼執著？
```

解讀原則：

```text
不恐嚇
不斷言命定
不把結果說死
把訊息轉成提醒與行動方向
```

---

## 六、進階追問法

第一組骰子看出主題後，可以再擲一次問：

```text
我需要採取什麼行動？
這件事真正的阻礙是什麼？
我忽略了什麼？
如果我要改善，下一步是什麼？
```

---

## 七、與本命星盤搭配

如果已經知道自己的本命盤，可以把骰子結果對應回星盤。

例如擲出：

```text
火星 + 牡羊座 + 第十一宮
```

可以回頭查看：

```text
本命盤火星在哪裡？
第十一宮有什麼星？
牡羊座在自己的星盤落在哪個宮位？
```

這樣可以讓占星骰子的訊息更貼近個人脈絡。
