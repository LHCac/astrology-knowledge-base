# 占星骰子解析

## 一、骰子結果

| 類型 | 結果 | 代表 |
|---|---|---|
| 行星骰 |  | 主導問題的狀態／主角／作用力 |
| 星座骰 |  | 能量表現方式 |
| 宮位骰 |  | 影響或關聯的生命領域 |

## 二、核心訊息

這組骰子最直接的提醒是：

```text
一句話先講結論。
```

## 三、三層拆解

### 1. 行星骰：＿＿

說明這顆行星在問題中代表的核心能量。

可包含：

```text
它代表什麼狀態？
可能代表誰？
它在這件事中像主角、事件、需求，還是提醒？
```

### 2. 星座骰：＿＿

說明能量如何表現。

可包含：

```text
這股能量是主動還是被動？
是直接還是迂迴？
是穩定、變動、情緒化、理性、深沉，還是自由？
```

### 3. 宮位骰：＿＿

說明影響的生活領域。

可包含：

```text
這件事主要落在哪個場景？
是工作、關係、金錢、家庭、學習、社群，還是潛意識？
```

## 四、整合解讀

把三個符號整合成生活化說明：

```text
這件事是由「行星」主導，透過「星座」的方式表現，並主要影響「宮位」領域。
```

接著用 2～4 段白話說明。

# 範例

## 問題

```text
我和某人的關係真正的主題是什麼？
```

## 骰子結果

```text
行星骰：金星
星座骰：天蠍
宮位骰：第七宮
```

## 解讀

金星代表關係、喜好、吸引力與價值；天蠍代表深度、信任、佔有、轉化；第七宮代表一對一關係、伴侶與合作。

這組骰子表示，這段關係的主題不是普通互動，而是深層信任與關係轉化。你們之間可能有強烈吸引，也可能有控制、懷疑、害怕受傷的議題需要面對。

建議不是急著確認結果，而是先看：這段關係能不能承受真誠、深度與界線。

**一句話：** 這段關係的關鍵不是表面喜不喜歡，而是能不能在深度裡建立真正的信任。
