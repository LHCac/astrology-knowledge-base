# Astrology Dice Symbol System｜占星骰子符號系統

占星骰子由三組符號組成：行星、星座、宮位。

## 一、行星骰

行星代表各種作用力，也可能隱含人物、事件、狀態或時間長度的訊息。

| 行星 | 核心意義 | 可能代表 |
|---|---|---|
| 太陽 | 自我意識、核心特質、生命力、自我意志 | 重要男性、父親、丈夫、兒子、明星、成就、作品 |
| 月亮 | 情緒、潛意識、安全感、習慣、親密需求 | 重要女性、母親、妻子、家人、房子、照顧、變動 |
| 水星 | 心智、溝通、學習、資訊、交通、理解 | 兄弟姐妹、同學、學生、鄰居、司機、資訊設備 |
| 金星 | 喜好、關係、價值、美感、吸引力、金錢 | 愛人、好朋友、禮物、金錢、美好事物、和平 |
| 火星 | 行動力、慾望、勇氣、競爭、衝突 | 男人、軍人、工人、運動員、武器、戰爭 |
| 木星 | 幸運、擴展、成長、信念、旅行、豐盛 | 老師、教授、哲學家、旅者、神職人員、智者 |
| 土星 | 責任、限制、時間、壓力、結構、成熟 | 老闆、主管、權威、長者、專家、老人 |
| 天王星 | 突變、自由、改革、科技、原創、解放 | 發明家、科技人、叛逆者、革命家、天才、怪才 |
| 海王星 | 夢想、慈悲、靈性、模糊、幻想、療癒 | 藝術家、導演、詩人、攝影師、受害者、救世主 |
| 冥王星 | 深層力量、控制、轉化、陰影、重生 | 掌權者、企業家、強人、大老闆、操控者 |
| 南交點 | 過去、舊緣分、熟悉模式、前世、天賦本能 | 慣性、舒適區、制約、執著、失去與付出 |
| 北交點 | 未來、新緣分、新學習、靈魂發展方向 | 成長、演化、接受、獲得、今生方向 |

## 二、星座骰

星座代表行星能量的表現方式，也可以看極性、模式與元素。

### 極性

| 極性 | 特質 | 對應元素 |
|---|---|---|
| 陽性 | 外顯、主動、自由傾向 | 火象、風象 |
| 陰性 | 內向、反省、平靜傾向 | 土象、水象 |

### 模式

| 模式 | 英文 | 特質 |
|---|---|---|
| 本位 | Cardinal | 開始、主動、啟動 |
| 固定 | Fixed | 維持、顯現目的、穩定 |
| 變動 | Mutable | 適應、改變、調整 |

### 元素

| 元素 | 代表 |
|---|---|
| 火象 | 慾望與行動 |
| 土象 | 物質與應用 |
| 風象 | 心智與社交互動 |
| 水象 | 情緒與感覺 |

## 四、整合解讀公式

```text
行星骰：這件事的主導力量是什麼？
星座骰：這股力量怎麼表現？
宮位骰：它在哪個生活領域發生？
```

整合句：

```text
這件事是由「行星」能量主導，透過「星座」方式表現，並在「宮位」領域發生。
```
