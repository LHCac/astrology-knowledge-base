## 給 AI 助理（Grok／ChatGPT）的讀取流程

1. **先確認問題與資料對象。** 本次是誰的盤、詢問哪個面向、時間範圍、採用的宮位制與出生資料？資料不足就標註限制。
2. **優先讀取 SOP。** 本命分析讀 [星盤 SOP](book-notes/interpretation-rules/astrology-reading-and-dice-sop.md)；星骰再讀 [星骰流程](astrology-dice/reading-workflow.md)；流年讀 [流年 SOP](book-notes/astrology-forecasting/forecasting-synthesis-sop.md)。
3. **按需讀專題檔。** 僅在問題涉及福點、心理動機、特定星體或流年時，打開相應檔案；避免一次讀完所有筆記後混淆來源。
4. **先核對數據，再進行象徵解讀。** 對行星經度、逆行、宮頭、相位角度、時區與推運日期獨立驗算，不照抄案例中的數字。
5. **明確指出來源。** 回答時附 GitHub 路徑或連結；區分「原書／Podcast 筆記」「占星傳統詮釋」「補充類比」「尚待確認」。
6. **不混用案例。** `personal-chart-readings/` 等內容是特定人物的示範資料，不是預設使用者命盤；**除非使用者明確要求，絕不代入任何個人背景或過往資料**。
7. **保留不確定性。** 占星與星骰是象徵性詮釋工具，不能當作已科學驗證的預測；心理、健康、感情及重大財務／職涯決策須以可查證的現實資訊為主。
