## 分類邏輯

每一顆行星／星體都用固定格式整理：

1. **核心主題**：最主要代表什麼。
2. **心理與人格層面**：對個人特質、情緒、意志、思考的影響。
3. **生活事件與領域**：可能對應到的生活面向。
4. **人物象徵**：可能代表身邊的哪些人。
5. **身體或事物對應**：若有身體、物品、事件象徵則另外列出。
6. **陰影面／過度表現**：能量失衡時可能出現的狀況。
7. **解讀提示**：之後做星盤或占星筆記時可以怎麼使用。
