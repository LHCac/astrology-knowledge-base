## 一、五行特性與生剋

五行是六爻、占卜與傳統術數中很重要的基礎概念。五行之間有「相生」與「相剋」兩種主要關係。

### 1. 五行

- 木
- 火
- 土
- 金
- 水

### 2. 五行相生

相生可理解為「生助、滋養、推動」。

```text
金生水 → 水生木 → 木生火 → 火生土 → 土生金
```

### 3. 五行相剋

相剋可理解為「制約、壓制、衝突」。

```text
金剋木 → 木剋土 → 土剋水 → 水剋火 → 火剋金
```

### 4. 五行特性

| 五行 | 特性 |
|---|---|
| 木 | 曲直、易動、喜伸展 |
| 火 | 炎上、溫熱、紅亮、化物 |
| 土 | 載物、生、化 |
| 金 | 聲音、肅殺 |
| 水 | 寒涼、就下、滋潤、閉藏 |

### 5. 五行歸類

| 五行 | 四時 | 方位 | 五色 | 五味 | 六腑 | 五臟 | 五常 |
|---|---|---|---|---|---|---|---|
| 木 | 春天 | 東方 | 青色 | 酸 | 膽 | 肝 | 仁 |
| 火 | 夏天 | 南方 | 紅色 | 苦 | 小腸 | 心 | 禮 |
| 土 | 四季 | 中央 | 黃色 | 甜 | 胃 | 脾 | 信 |
| 金 | 秋天 | 西方 | 白色 | 辣 | 大腸 | 肺 | 義 |
| 水 | 冬天 | 北方 | 黑色 | 鹹 | 膀胱 | 腎 | 智 |

## 二、天干

十天干有陰陽之分，並可依五行分類。書中也提醒：天干的陰陽、生剋、相合，在六爻卦象結論中不一定是主要判斷核心，重點仍需回到卦中納甲地支與實際斷卦規則。

### 1. 十天干

```text
甲、乙、丙、丁、戊、己、庚、辛、壬、癸
```

### 2. 天干陰陽

| 陰陽 | 天干 |
|---|---|
| 陽干 | 甲、丙、戊、庚、壬 |
| 陰干 | 乙、丁、己、辛、癸 |

### 3. 天干五行

| 五行 | 天干 |
|---|---|
| 木 | 甲、乙 |
| 火 | 丙、丁 |
| 土 | 戊、己 |
| 金 | 庚、辛 |
| 水 | 壬、癸 |

### 4. 天干相生

```text
甲乙木 → 生丙丁火
丙丁火 → 生戊己土
戊己土 → 生庚辛金
庚辛金 → 生壬癸水
壬癸水 → 生甲乙木
```

### 5. 天干相剋

```text
庚辛金 → 剋甲乙木
甲乙木 → 剋戊己土
戊己土 → 剋壬癸水
壬癸水 → 剋丙丁火
丙丁火 → 剋庚辛金
```

### 6. 天干方位

| 方位 | 天干 |
|---|---|
| 東方 | 甲、乙 |
| 南方 | 丙、丁 |
| 中央 | 戊、己 |
| 西方 | 庚、辛 |
| 北方 | 壬、癸 |

### 7. 天干相合

| 相合 | 合化 |
|---|---|
| 甲己合 | 化土 |
| 乙庚合 | 化金 |
| 丙辛合 | 化水 |
| 丁壬合 | 化木 |
| 戊癸合 | 化火 |

## 四、地支關係

### 1. 六合

六合是地支一陰一陽相合，共六組。書中提醒：六爻占卜中有「相合」之用，但不一定取「合化」來斷。

| 六合 | 合化 |
|---|---|
| 子丑合 | 化土 |
| 寅亥合 | 化木 |
| 卯戌合 | 化火 |
| 辰酉合 | 化金 |
| 巳申合 | 化水 |
| 午未合 | 化火 |

### 2. 三合

三合是相隔約一百二十度的三個地支連結成局。

| 三合局 | 五行 |
|---|---|
| 申子辰 | 水局 |
| 巳酉丑 | 金局 |
| 寅午戌 | 火局 |
| 亥卯未 | 木局 |

補充分類：

| 類別 | 地支 |
|---|---|
| 四長生 | 寅、申、巳、亥 |
| 四正 | 子、午、卯、酉 |
| 四墓庫 | 辰、戌、丑、未 |

墓庫對應：

| 墓庫 | 對應 |
|---|---|
| 辰 | 水庫 |
| 戌 | 火庫 |
| 丑 | 金庫 |
| 未 | 木庫 |

### 3. 三會

三會是同一方位的三個地支會合，氣專一方，力量很集中。書中提醒：占卜學不論三會。

| 三會 | 方位與五行 |
|---|---|
| 寅卯辰 | 東方木 |
| 巳午未 | 南方火 |
| 申酉戌 | 西方金 |
| 亥子丑 | 北方水 |

### 4. 六沖

六沖是十二地支中相隔一百八十度形成的對沖關係。

| 六沖 |
|---|
| 子午相沖 |
| 卯酉相沖 |
| 寅申相沖 |
| 巳亥相沖 |

| 丑未相沖 |

### 5. 相穿／穿害

相穿又稱穿害。書中提醒：六爻占卜中，丑午、子未可視為桃花，其餘穿害則不論。

| 相穿 |
|---|
| 子未相穿 |
| 丑午相穿 |
| 寅巳相穿 |
| 卯辰相穿 |
| 申亥相穿 |
| 酉戌相穿 |

### 6. 地支相刑

刑有痛苦、折磨、分裂之意，也可理解為力量互相拉扯。

| 類型 | 關係 |
|---|---|
| 恃勢之刑 | 寅巳相刑、巳申相刑、寅巳申三刑 |
| 無恩之刑 | 丑戌相刑、未戌相刑、丑戌未三刑 |
| 無禮之刑 | 子卯相刑 |
| 自刑 | 辰辰、午午、酉酉、亥亥 |

## 五、學習重點整理

六爻入門可以先把下面幾組關係背起來：

1. 五行：木、火、土、金、水。
2. 相生：金生水、水生木、木生火、火生土、土生金。
3. 相剋：金剋木、木剋土、土剋水、水剋火、火剋金。
4. 天干五行：甲乙木、丙丁火、戊己土、庚辛金、壬癸水。
5. 地支五行：寅卯木、巳午火、辰戌丑未土、申酉金、亥子水。
6. 地支互動：六合、三合、六沖、相穿、相刑。
