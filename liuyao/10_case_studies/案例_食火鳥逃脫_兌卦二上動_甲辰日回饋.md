# 六爻案例｜食火鳥逃脫｜兌卦二上動｜甲辰日回饋

## 一、案例背景

占問問題：

```text
上班場所北莊福園內有鳥園，裡面有一隻食火鳥逃脫，想知道這隻食火鳥是如何逃脫、是否會找回來，以及若能找回，幾時能找回。
```

起卦資料：

```text
癸巳月 庚子日
本卦：兌為澤
動爻：二爻、上爻
原紀錄：兌卦轉復卦
自占
```

事後回饋：

```text
實際方向：南方、東南方。
發現位置：田內，被圍籬圍起來。
應期：甲辰日。
方式：有人電話通報。
```

---

## 二、重要校正：方位不能只取本卦方位

本卦為兌，兌一般取象為：

```text
西方
金
口舌
消息
缺口
圍欄、金屬、網狀物
```

若只取本卦兌方，容易判成西方，與實際南方、東南方相反。

本案例的回饋提醒：

```text
逃逸動物尋方位，不能只取本卦方位。
要同時看用神、物象、動爻、變象、月日與現實環境。
```

---

## 三、為何實際為南方、東南方

食火鳥本身可取象：

```text
鳥：巽象、飛禽、東南。
火：離象、南方。
```

因此「食火鳥」這個物象本身就帶有：

```text
離火南方
巽風飛禽東南方
```

若以物象優先於本卦方位，南方、東南方便能成立。

此案例可記為：

```text
問動物方位時，物類象有時比本卦卦位更貼近實際方向。
尤其禽鳥類，宜參巽；帶火名、火象明顯者，宜參離。
```

---

## 四、田內與圍籬的卦象對應

實際位置是田內，且被圍籬圍起來。

可取象：

```text
田地：坤、辰戌丑未土、土象環境。
圍籬：兌金、欄杆、網狀物、缺口、圈圍。
```

本卦兌為澤，兌亦可取象為：

```text
開口
缺口
金屬圍欄
網狀圍設
被圍住但有口可出入
```

因此本卦兌未必只代表西方，也可表示：

```text
牠逃出或被發現的位置，與缺口、圍欄、網狀物、出入口有關。
```

此點與「田內圍籬圍起來」相合。

---

## 五、電話通報的卦象對應

實際是有人電話通報。

兌象可代表：

```text
口
說話
通知
通報
消息
電話溝通
```

若變象或動象帶震，震又可代表：

```text
聲音
消息傳來
驚動
通知
突然有人告知
```

所以「電話通報」可由：

```text
兌為口訊
震為聲動
```

共同取象。

本案例回饋很適合用來記錄：

```text
兌卦在尋物尋動物案例中，不一定只看西方，也可表示有人開口提供線索、電話通知、口頭通報。
```

---

## 六、甲辰日應期解析

實際於甲辰日有人電話通報。

甲辰日可取象：

```text
甲：木、草木、直立物、欄杆、外部線索。
辰：濕土、田地、土庫、圍地、田埂、低窪處。
```

因此甲辰日與實際位置有相合處：

```text
辰土對應田地、圍地、土中藏水之地。
甲木對應田邊植物、木桿、圍籬、外部生發線索。
```

甲辰日也可作「土中見木、田內有線索」之象。

---

## 七、為何原判方位會相反

可能原因：

```text
1. 過度依本卦兌取西方。
2. 未優先考慮食火鳥本身的物象：離火南、巽鳥東南。
3. 尋動物時，方位不只看卦宮，還要看用神與物類象。
4. 兌象在此案更像口訊、圍籬、缺口，而非單純西方。
```

因此此案的修正規則是：

```text
本卦方位不可單用。
物象方位、用神方位、動爻方位、環境象要互參。
若卦象方位與物象方位衝突，應以能同時解釋「物種、地點、發現方式」者優先。
```

---

## 八、實戰規則補強

本案例新增規則：

```text
1. 問飛禽類動物，宜參巽方與離方。
2. 名稱帶火、色彩或特性屬火者，宜參離南方。
3. 本卦兌在尋物時，可表示電話、通報、口訊、缺口、圍籬，不一定只代表西方。
4. 田地、圍地、土庫、低處可參辰戌丑未土。
5. 應期若落辰日，常可對應田地、土庫、圍地、田埂、濕土環境。
6. 方位判錯時，應回頭檢查是否單取卦宮，而忽略物象與環境象。
```

---

## 九、案例總結

```text
食火鳥逃脫案，實際結果為南方、東南方，甲辰日有人電話通報，在田內圍籬處找到線索。

本案驗證：
兌卦不一定只指西方，也可指口訊、電話、通報、圍籬、缺口。
食火鳥本身帶離火南方與巽鳥東南方象，方位應以物象互參。
甲辰日則對應田地、圍地、土庫與外部線索。
```

---

## 十、後續修正方向

```text
以後占逃逸動物或尋物時，方位判斷需分三層：

第一層：用神與物類象。
第二層：本卦、變卦、動爻方位。
第三層：現實環境與日辰應期。

若三者不一致，不能硬取單一卦宮方位，應找最能同時解釋物種、地點與發現方式的組合。
```
