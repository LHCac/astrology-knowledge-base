1. 先讀 `cheatsheet.md` 建立整體框架。
2. 遇到五行、天干、地支問題，查 `01` 和 `02`。
3. 開始斷卦時，先查 `03`，確認用神與生剋關係。
4. 需要補充事件狀態、人物性格、環境氛圍時，再查 `04`。

## 核心觀念

六爻判斷可簡化為：

```text
問題類型 → 取用神 → 看旺衰 → 看生剋沖合 → 看世應關係 → 以六獸補象
```

- 五行是底層生剋邏輯。
- 地支提供沖、合、刑、害等互動關係。
- 六親五行是判斷吉凶主體。
- 六獸偏向「象意輔助」，不單獨決定吉凶。
