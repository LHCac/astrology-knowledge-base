## 相位閱讀框架

相位 = 兩顆星之間的「對話關係」。同時看兩件事：這兩顆星是誰，也就是驅動力；它們在哪裡辦公，也就是宮位。

|---|---:|---|---|
| △ 三分相 | 120° | 流暢天賦 | 能量自然合作，才能不費力流露 |
| ✶ 六分相 | 60° | 機遇激活 | 溫和友好，但需要主動激活 |
| ☌ 合相 | 0° | 能量融合 | 兩股能量完全融合，強化彼此 |

| ⊼ 八分之三相 | 135° | 持續調整 | 慢性小摩擦，像鞋子裡的小石頭 |
