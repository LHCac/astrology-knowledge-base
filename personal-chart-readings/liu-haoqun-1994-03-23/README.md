## 六、解讀前的品質守則

1. 本命行星與 ASC／MC **以本頁校正版為準**，不要再讀取舊金牛版本作為正式盤。
2. 二次推運、太陽回歸及當期行運**必須分開計算，最後才交叉解讀**；未算的技法不得聲稱已驗證。
3. **2026 年太陽回歸所在地已確認為新竹縣新埔鎮**，四軸與宮頭依新埔鎮代表座標試算（非當事人精確位置）；**2027 年所在地尚未確認**，2027 宮位仍為桃園暫定盤。
4. 星曆與度數是可驗證資料；占星解讀是象徵詮釋，不等於科學驗證的事件預測。
5. **隱私**：本資料位於公開 GitHub 儲存庫，包含個人出生資訊。若未來要給其他 AI 讀，請考慮將個人案例改為私人儲存庫。
