# Custom Natal Chart Reading Workflow｜自訂本命星盤解析流程

這份流程是依照使用者提供的三份範本整理：

1. 完整宮位解讀總覽
2. 完整相位解析
3. 小天體與虛點解析

之後進行星盤解析時，優先採用此流程與語氣。

---

## 一、使用者需要提供的資料

### 最完整資料

```text
出生日期：YYYY/MM/DD
出生時間：HH:mm
出生地點：城市／國家
想問主題：整體／感情／事業／財運／學業／人際／人生課題
```

### 最穩定資料格式

若使用者已經用星盤網站算好，請提供：

```text
上升：星座 + 度數
天頂：星座 + 度數
宮位制：例如普拉希德斯

星體 星座 度數 宮位
太陽：
月亮：
水星：
金星：
火星：
木星：
土星：
天王星：
海王星：
冥王星：

主要相位：
小天體與虛點：
```

若只提供出生資料，需先提醒：沒有出生地點與準確出生時間，上升、宮位、天頂會不準。

## 二、總體輸出架構

完整解析分成三大篇：

```text
第一篇：完整宮位解讀總覽

```

最後再加上：

```text
整體圖像

一句話總結
```

## 4. 十二宮位解讀格式

每一宮都用以下固定格式：

```text
## [emoji] X宮 — 宮位名稱

| 層次 | 內容 |
|---|---|
| 底色 | 星座 — 氣質關鍵字 |
| 守護星 | 守護星星座在X宮遠端管理／回駐 |
| 現場員工 | 落入星體；若無則寫空宮 |

白話整合解讀：
用 2～4 段說明這個宮位如何運作。

一句話： 用一句話收束此宮位的重點。
```

## 5. 宮位解讀原則

### 底色

宮頭星座代表這個宮位的氛圍。例如：

```text
金牛：穩重、踏實、感官導向、有品味
雙子：靈活、多元、不執著單一方向
巨蟹：細膩、情感驅動、保護性
獅子：需要被重視、有溫度、有舞台感
```

### 守護星

守護星代表該宮位的主管。

```text
守護星在本宮：回駐，主管就在現場，能量集中。
守護星在其他宮：遠端管理，該宮位受到守護星所在宮位影響。
```

### 現場員工

落入此宮位的星體代表現場實際發生的能量。

```text
有星體：該宮位主題被明顯啟動。
空宮：不代表沒有此主題，要追守護星位置。
```

# 第二篇｜完整相位解析

## 1. 開頭格式

```text
# 完整相位解析

## 相位閱讀框架
相位 = 兩顆星之間的「對話關係」。
同時看兩件事：
1. 這兩顆星是誰，也就是驅動力。
2. 它們在哪裡辦公，也就是宮位。
```

## 2. 相位總表

```text
| 相位符號 | 角度 | 類型 | 感覺 |
|---|---:|---|---|
| △ 三分相 | 120° | 流暢天賦 | 能量自然合作，才能不費力流露 |
| ✶ 六分相 | 60° | 機遇激活 | 溫和友好，但需要主動激活 |
| ☌ 合相 | 0° | 能量融合 | 兩股能量完全融合，強化彼此 |
| □ 四分相 | 90° | 成長張力 | 摩擦衝突，推動成長的壓力 |
| ☍ 對分相 | 180° | 拉扯整合 | 對立與投射，需要整合 |
| ⊼ 八分之三相 | 135° | 持續調整 | 慢性小摩擦，像鞋子裡的小石頭 |
| ⊻ 十二分之五相 | 150° | 格格不入 | 兩股能量需要長期磨合 |
```

## 3. 單一相位解讀格式

```text
## [相位類型]

### 星體A [相位] 星體B

| 項目 | 內容 |
|---|---|
| 星體A | 星體星座宮位 — 驅動力 |
| 星體B | 星體星座宮位 — 驅動力 |
| 感覺 | 此相位的核心感受 |

白話整合解讀：
用 2～4 段說明兩顆星如何互動。

怎麼跟它相處／長期功課／需要注意：
依相位性質給出建議。

一句話： 用一句話收束此相位。
```

## 4. 相位解析語氣

相位解析要具體、生活化，避免只說術語。

範例語氣：

```text
你的人生方向想往外走，但某段深刻關係會把能量往內拉。
這不是正面衝突，而是一種細微、持續存在的拉扯。
```

## 5. 相位篇結尾整理

```text
## 整體相位圖像

### 你的天賦
整理三分相、六分相、合相中最有力的配置。

### 你的課題
整理四分相、對分相、八分之三相、十二分之五相中最需要整合的配置。

### 感情提醒
整理金星、月亮、七宮、冥王、海王相關相位。

### 事業提醒
整理太陽、土星、天頂、十宮、木星相關相位。

### 幸運公式
整理木星、金星、幸運點、三分相或六分相。
```

# 第三篇｜小天體與虛點解析

## 1. 開頭格式

```text
# 小天體與虛點解析

## 小天體與虛點說明
小天體和虛點不是主要行星，但它們提供更細緻的人生線索。
它們描述傷口、使命感、幸運方向、靈魂功課等更深層面向。
```

## 2. 單一小天體／虛點解讀格式

```text
## 名稱（英文）— 宮位 星座

| 項目 | 內容 |
|---|---|
| 代表 | 此點象徵什麼 |
| 位置 | 宮位、星座、是否逆行 |

白話整合解讀：
用 2～4 段說明這個小天體或虛點如何表現。

一句話： 用一句話收束此點。
```

## 3. 建議解析的小天體與虛點

```text
智神星 Pallas：智慧策略、模式識別、解決問題方式
灶神星 Vesta：奉獻能量、神聖使命感、專注投入

穀神星 Ceres：滋養與被滋養的方式
```

```text
靈魂功課：
```

# 五、解析風格要求

1. 先講結論，再補原因。
2. 用白話，不要只堆術語。
3. 每段都要回到生活感受。
4. 一定要有「一句話」總結。
5. 對困難配置不要恐嚇，要說成課題與整合方向。
6. 對天賦配置不要過度誇大，要說成可發展的能力。
7. 若資料不足，要明確標註不確定。
8. 不做絕對命定論，用「傾向、可能、容易、需要學習」來表達。

# 七、一句話工作原則

> 行星是驅動力，星座是表現方式，宮位是生活場景，相位是能量對話，小天體與虛點是深層線索。完整解析時，要把它們整合成一個人真實會感受到的人生故事。
