# Natal Chart Reading Template｜本命星盤解析範本

這份模板用來統一之後的星盤解析流程。使用時可以搭配 `planets/`、`signs/`、`houses/`、`aspects/`、`keywords/` 與 `notion-imports/` 裡的資料。

## 一、使用者需要提供的資料

### 最完整資料

```text
出生日期：YYYY/MM/DD
出生時間：HH:mm
出生地點：城市／國家
性別或稱謂：可選
想問主題：整體／感情／事業／財運／學業／人際／人生課題
```

### 最準確做法

如果可以，請提供星盤網站或軟體算好的資料：

```text
上升星座：
太陽星座與宮位：
月亮星座與宮位：
水星星座與宮位：
金星星座與宮位：
火星星座與宮位：
木星星座與宮位：
土星星座與宮位：
天王星星座與宮位：
海王星星座與宮位：
冥王星星座與宮位：
主要相位：
```

也可以直接提供星盤截圖，由解析者依截圖整理。

## 二、解析前提醒

1. 出生時間會影響上升、宮位與月亮度數。
2. 出生地點會影響上升與宮位。
3. 若沒有出生時間，只能做「無宮位版本」，不適合判斷上升、宮位、財富宮、婚姻宮、事業宮。
4. 若只提供年月日，可解析太陽、部分月亮與行星星座，但精度有限。

## 三、解析順序

### 1. 三大核心

| 項目 | 看什麼 |
|---|---|
| 太陽 | 自我認同、核心意志、想成為誰 |
| 月亮 | 情緒本能、安全感、內在需求 |
| 上升 | 外在形象、第一印象、人生進入方式 |

### 2. 星盤主星

上升星座的守護星就是星盤主星。

解析方向：

```text
上升星座 → 守護星 → 守護星落星座 → 守護星落宮位 → 守護星相位
```

### 3. 個人星

| 星體 | 解析重點 |
|---|---|
| 水星 | 思考方式、溝通、學習、理解資訊 |
| 金星 | 感情模式、喜好、美感、價值觀、關係吸引力 |
| 火星 | 行動力、慾望、衝突、追求方式 |

### 4. 社會星

| 星體 | 解析重點 |
|---|---|
| 木星 | 成長、幸運、擴展、信念、貴人與機會 |
| 土星 | 責任、壓力、限制、長期課題與成熟方向 |

### 5. 世代星

| 星體 | 解析重點 |
|---|---|
| 天王星 | 突破、自由、變革、非典型特質 |
| 海王星 | 夢想、靈性、模糊、理想化與逃避 |
| 冥王星 | 深層轉化、控制、執著、重生與權力議題 |

### 6. 十二宮位

用三層疊加法：

```text
宮位 = 生活場景
宮頭星座 = 這個場景的風格
守護星位置 = 這個場景的主管在哪裡
落入星體 = 現場實際發生的能量
```

每宮解析格式：

```text
第 X 宮｜主題
宮頭星座：
守護星位置：
落入星體：
整合解讀：
一句話總結：
```

### 7. 相位

相位解析步驟：

1. 先看兩顆星代表什麼功能。
2. 再看它們落在哪些宮位。
3. 最後看相位類型。

常用相位：

| 相位 | 角度 | 含義 |
|---|---:|---|
| 合相 | 0° | 能量融合、強化 |
| 六分相 | 60° | 機會、可主動激活 |
| 四分相 | 90° | 張力、摩擦、成長壓力 |
| 三分相 | 120° | 天賦、自然流暢 |
| 對分相 | 180° | 拉扯、投射、需要整合 |

## 四、輸出格式

### 簡短版

```text
一、星盤核心摘要
二、個性與內在需求
三、感情與人際模式
四、事業與財富方向
五、人生課題與成長建議
六、一句話總結
```

### 詳細版

```text
一、星盤基本資料
二、三大核心：太陽、月亮、上升
三、星盤主星
四、個人星解析
五、社會星與世代星解析
六、十二宮位重點
七、主要相位解析
八、感情／事業／財運／人生課題整合
九、具體建議
十、總結
```

## 五、語氣要求

- 用白話解釋，不要只堆術語。
- 先講結論，再補原因。
- 不做絕對斷言。
- 不把星盤說成命定，而是當成性格、傾向與課題參考。
- 若資料不足，要清楚標註「此部分可能不準」。

## 六、解析提醒

星盤解析應該把行星、星座、宮位、相位整合起來，而不是單獨解釋每個符號。

核心公式：

```text
行星 = 什麼能量
星座 = 怎麼表現
宮位 = 發生在哪個生活領域
相位 = 能量之間如何互動
```
