# 行星總覽

在占星中，行星可以理解成一個人內在與外在生命運作的不同功能。

| 行星／星體 | 核心關鍵 | 白話理解 |
|---|---|---|
| 太陽 | 自我、意志、生命力 | 我是誰、我想成為什麼樣的人 |
| 月亮 | 情緒、安全感、習慣 | 我內心真正需要什麼，怎樣才安心 |
| 水星 | 思考、溝通、學習 | 我怎麼想、怎麼說、怎麼吸收資訊 |
| 金星 | 喜好、關係、美感、價值 | 我喜歡什麼、怎麼愛、覺得什麼有價值 |
| 火星 | 行動、慾望、競爭 | 我怎麼出手、怎麼爭取、怎麼表達怒氣 |
| 木星 | 擴展、信念、幸運 | 我在哪裡成長、相信什麼、追求什麼願景 |
| 土星 | 責任、限制、結構 | 我需要面對什麼壓力、建立什麼能力 |
| 天王星 | 變革、自由、突變 | 我在哪裡想突破、想與眾不同 |
| 海王星 | 夢想、信仰、消融 | 我在哪裡容易理想化、感受神祕與共感 |
| 冥王星 | 深層力量、轉化、掌控 | 我在哪裡經歷強烈執著、重生與蛻變 |
