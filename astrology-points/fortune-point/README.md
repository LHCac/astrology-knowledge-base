## 一、福點主軸

【筆記】福點是「幸運座標」，不是「性格描述」。它不是用來判斷一個人是什麼個性，而是指出：

```text
哪裡容易順流
哪裡能感到富足
哪裡有自然資源
哪裡不費力氣也比較容易得到回報
```

【筆記】福點不是一顆星，也不彰顯個性；它比較像是一個「能量會自己靠過來」的位置。

【筆記】福點的關鍵字是「不費力」。但這不代表完全不用努力，而是指在那個星座方式與宮位領域中，努力比較容易被看見、被支持、被放大。

---

## 二、解讀核心

【筆記】解讀福點時，可以先看：

```text
1. 星座：用什麼方式順流
2. 宮位：在哪個人生領域順流
3. 是否反其道而行：若違背福點邏輯，福氣不容易出現
4. 宮位會被加持：福點所在領域是被默默支持的區塊
```

【筆記】星座與宮位可以分開理解：

```text
福點所在星座 = 方法 / 態度 / 能量型態
福點所在宮位 = 場域 / 人生主題 / 容易順流的領域
```

## 五、需要注意

【筆記】福點不是保證「不努力就會成功」，也不是保證財富的位置。

【筆記】如果一個人反其道而行，違背福點所在星座與宮位的順流邏輯，福點不會自然顯現。

【待確認】福點是否等同「幸運」在古典與現代占星中仍有定義差異，後續需要查證補強。
