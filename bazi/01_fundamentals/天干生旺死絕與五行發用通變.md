# 一、十二長生順序

```text
長生 → 沐浴 → 冠帶 → 臨官 / 建祿 → 帝旺 → 衰 → 病 → 死 → 墓 → 絕 → 胎 → 養
```

象意：

```text
長生：初生、有氣。
冠帶：逐漸成形。
臨官：得祿、能任事。
帝旺：最旺。
衰病死絕：氣弱、耗損。
墓：收藏入庫。
胎養：重新醞釀。
```

# 四、十二長生使用原則

```text
長生、冠帶、臨官、帝旺：力量較旺。
衰、病、死、絕：力量較弱。
墓：藏而不顯，需看透干、沖合與喜忌。
胎、養：蓄勢、恢復、未完全發用。
```

注意：

```text
十二長生是天干在地支中的形體消長。
不可單憑長生位斷身強身弱。
仍須合看月令、根氣、透干、生剋制化。
```

# 五、五行發用定例

五行發用重點是：

```text
同一五行，在不同季節、不同旺衰狀態，需要不同制化。
旺者宜洩、宜制。
弱者宜生、宜扶。
寒者宜暖。
燥者宜潤。
濁者宜清。
```

判斷順序：

```text
Step 1：看五行是否得令。
Step 2：看是否有根。
Step 3：看是否透出。
Step 4：看是否有生扶或剋洩。
Step 5：判斷此五行是病還是藥。
```

# 六、天干五陽通變

五陽干較剛、外放、主動。

```text
甲：陽木，重生長與開展。
丙：陽火，重光明與發散。
戊：陽土，重承載與穩定。
庚：陽金，重剛健與裁斷。
壬：陽水，重流動與奔騰。
```

陽干特點：

```text
氣勢明顯。
行動直接。
遇制化得宜，成就外顯。
過旺則剛烈，需制洩。
```

# 七、天干五陰通變

五陰干較柔、內斂、細膩。

```text
乙：陰木，重彈性與延展。
丁：陰火，重燈火與精神。
己：陰土，重承接與滋養。
辛：陰金，重精緻與雕琢。
癸：陰水，重滋潤與細流。
```

陰干特點：

```text
力量較細緻。
重環境配合。
喜清純與得地。
過弱易散，過旺易滯。
```

# 八、大運流年應用

```text
大運地支若為日主長生、建祿、帝旺，日主得助。
大運地支若為用神長生、建祿、帝旺，用神得力。
大運地支若為忌神帝旺，忌神加重。
流年亦同，但力量短於大運。
```

實戰不可只看長生吉凶，需問：

```text
旺的是喜神還是忌神？
衰的是用神還是忌神？
墓庫是否能被引動？
```

# 九、阿咪命盤應用

阿咪日主戊土。

戊土：

```text
長生在寅。
建祿在巳。
帝旺在午。
```

目前庚午大運、2026丙午年，都見午。

```text
午為戊土帝旺，火土力量很強。
表示自我承受力、固執、焦慮、想掌控的力量都會被放大。
```

因此：

```text
午旺不是單純吉，也不是單純凶。
它代表火土過旺時，需要金水來洩秀與流通。
```

最佳走法：

```text
火印學習 → 金食傷輸出 → 水財星落地。
```
