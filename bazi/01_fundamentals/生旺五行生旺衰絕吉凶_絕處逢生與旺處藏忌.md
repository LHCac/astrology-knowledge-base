# 一、原文主題

本章說明五行生旺衰絕的基本框架，以及如何用其判斷命局力量。

最重要提醒：

```text
論命切不可專泥於生旺而吉、衰敗而凶。
```

也就是：

```text
絕地不一定凶。
旺地不一定吉。
需看藏干、全局氣勢與用神是否得力。
```

# 二、五行長生基本位置

| 五行 | 長生地 |
|---|---|
| 金 | 巳 |
| 木 | 亥 |
| 水 | 申 |
| 火 | 寅 |
| 土 | 居中寄母，戊寄巳，己寄午 |

---

# 三、五行分日

傳統說法：

```text
金、木、水、火各旺 72 日。
土旺四季，各 18 日。
合計 360 日為一年之數。
```

此為曆法與氣候框架，實戰需合月令與全局判斷。

---

# 四、絕處逢生

例：丙日亥時。

```text
丙火以主氣看，絕於亥。
但亥中藏甲木，甲為丙火偏印，可生丙火。
所以丙日亥時不宜直接論絕，而是絕處逢生。
```

現代用法：

```text
日主或用神雖在絕地，若藏干有印比生扶，仍有根氣與轉機。
```

---

# 五、旺處藏忌

例：戊日巳時。

```text
戊土祿旺於巳，看似很強。
但若全局金多，巳可轉以金長生論。
巳中庚金為戊土食神，若金旺過度，可能洩土太過或傷官食傷牽動官星。
```

現代用法：

```text
旺地不一定全吉。
若旺地藏有忌神，或全局氣勢轉向其他五行，仍需重新判斷。
```

---

# 六、判斷流程

```text
Step 1：確認日干陰陽，定長生十二運順逆。
Step 2：先看地支主氣，判基本旺衰。
Step 3：再看地支藏干，是否有印比幫身或食傷財殺暗藏。
Step 4：判斷是否絕處逢生。
Step 5：判斷是否旺處藏忌。
Step 6：以全局氣勢與用神是否得力為最終依據。
Step 7：區分長生十二運與陰生陽死，不可混用。
```

---

# 七、地支藏干隱藏力量速查

| 情況 | 判斷 |
|---|---|
| 日主絕地，藏干有印星 | 絕處逢生，實際不一定弱 |
| 日主絕地，藏干無救 | 確實力弱，需他柱補救 |
| 日主長生地，藏干有傷官 | 旺處洩官，用官者需注意 |
| 日主旺地，藏干有七殺 | 旺而不純，仍有壓力 |
| 全局同類五行多 | 可能改以該五行論氣勢 |

---

# 八、大運流年應用

```text
大運流年進入日主或用神長生地，若該五行為喜，力量提升。
大運流年進入忌神長生、帝旺地，忌神加重。
用神在絕地但有藏干生扶，歲運引出藏干時可發用。
旺地藏忌，歲運引動忌神時事件明顯。
```

# 九、阿咪命盤應用

阿咪戊土日主，戊土長生在寅、建祿在巳、帝旺在午。

原局時支巳：

```text
巳為戊土建祿，日主有根。
巳中藏丙、戊、庚，含偏印、比肩、食神。
```

目前庚午大運、2026丙午年：

```text
午為戊土帝旺。
火土旺處容易增強自我、焦慮、固執與想掌控。
但庚金食神也可把旺土洩為作品與輸出。
```

所以不能只說「午旺很好」，而要看能否透過庚金食神洩秀。

# 十、降火修正

```text
長生、帝旺不直接等於吉。
衰、病、死、絕不直接等於凶。
真正關鍵在於該五行是喜是忌，是否有藏干救應，是否被大運流年引動。
```

---

# 十一、總結

```text
生旺衰絕是判斷力量的工具，不是吉凶判決書。
絕地可逢生，旺處可藏忌。
論命要看地支藏干、全局氣勢、用神喜忌與歲運觸發。
```
