# 二、五行相生

```text
金生水
水生木
木生火
火生土
土生金
```

相生不是永遠吉。

```text
生得剛好是助力。
生太多反成壓力。
例如土多金埋、水多木漂、火多土焦。
```

---

# 三、五行相剋

```text
金剋木
木剋土
土剋水
水剋火
火剋金
```

相剋不是永遠凶。

```text
剋得適當是規範與成器。
剋太過才是傷害。
被剋者若太強，反會反傷剋者。
```

# 七、藏干使用原則

```text
地支藏干代表內在、潛在、根氣、心理層。
天干透出代表外顯、事件化、行為層。
藏干不透，力量較隱。
藏干透出，該十神較能實際發揮。
```

月令藏干尤其重要，因為月令是提綱。

# 八、節候歌使用原則

節候歌提醒：

```text
月令旺衰與節氣氣候不可分。
同一個地支月，也要看節氣前後深淺。
命理月份從節開始，不從農曆月初一開始。
```

實戰使用：

```text
1. 先定節氣月令。
2. 再看地支藏干。
3. 看藏干是否透出。
4. 再判斷旺衰、格局、用神。
```

