# 一、財星共同核心

財星代表：

```text
資源
金錢
現實利益
管理能力
男命感情與妻星
父親象，尤其偏財
```

財格最核心不是「看到財就好」，而是：

```text
身旺能任財，財星清純不破，方能發揮。
```

若身弱財旺，財反為壓力，容易變成：

```text
想賺但扛不住。
資源來了卻守不住。
財生官殺反成壓力。
```

# 二、正財格

## 1. 成立條件

```text
1. 月令現正財，或正財成為命局主象。
2. 日主身旺，能承受財星。
3. 財星不被沖剋破害。
4. 無比劫旺而爭財。
5. 財能生官，或有印星助身更佳。
```

## 2. 喜忌

| 正財格 | 喜 | 忌 |
|---|---|---|
| 身財 | 身旺能任財 | 身弱財多 |
| 財源 | 食傷生財 | 比劫奪財 |
| 名位 | 財官相生 | 財星被沖破 |
| 承載 | 印星助身 | 財旺生官殺攻身 |

## 3. 行運

```text
身旺財格行財官運：名利有推進。
身旺財格行印運：身更有力，可承財。
身弱財格行財運：壓力增加，不宜過度求財。
行比劫旺運：財務競爭、合夥摩擦、花費增加。
```

# 三、偏財格

## 1. 偏財性質

偏財為眾人之財，象徵：

```text
廣泛資源
外財
生意財
人脈財
慷慨海派
流動性財源
```

偏財旺者若格局良好，常有廣結善緣、善於調動資源的特質。

## 2. 成立條件

```text
1. 月令現偏財，或偏財為命局主象。
2. 日主身旺，能任偏財。
3. 偏財不被沖破。
4. 無比劫爭財。
5. 有官星相助，財生官則名利俱有。
```

## 3. 偏財喜忌

| 偏財格 | 喜 | 忌 |
|---|---|---|
| 身財 | 身強財旺 | 身弱財旺 |
| 名位 | 財生官 | 比劫透干爭財 |
| 事業 | 官殺護財 | 財星被沖破 |
| 人際財 | 廣結善緣 | 合夥破財、資源分散 |

# 四、正財與偏財差異

| 比較 | 正財 | 偏財 |
|---|---|---|
| 財的性質 | 穩定固定之財 | 流動廣泛之財 |
| 性格表現 | 穩重、守成、管理 | 海派、慷慨、開展 |
| 財源模式 | 薪資、固定收入、穩定資產 | 生意、人脈、機會財、外財 |
| 最大忌神 | 比劫爭財 | 比劫爭財更明顯 |
| 男命感情 | 正妻、穩定關係 | 偏緣、外緣、非固定吸引 |

# 五、財星與官星

```text
財能生官。
財星清純而官星有力，主名利相生。
```

但要注意：

```text
若身弱，財生官殺反攻身，反而變成壓力、責任、職場或關係負擔。
```

# 六、比劫奪財的降火解讀

古文常言：

```text
田園破盡、傷妻損妾、禍多端。
```

現代修正版：

```text
比劫旺而財星為用時，財務競爭、合夥摩擦、衝動花費、人際資源分散會變明顯。
男命財星同時代表伴侶象，因此財務壓力也可能波及感情互動。
不可直接斷破產、剋妻或婚姻必敗。
```

---

# 七、實戰判斷流程

```text
Step 1：確認財星是正財或偏財。
Step 2：看財星是否在月令或成主象。
Step 3：判斷日主能否任財。
Step 4：看財星有無被比劫、沖破、合去。
Step 5：看是否有食傷生財或官星護財。
Step 6：看大運流年是否補身、助財、或引動比劫。
```

# 八、阿咪命盤應用

阿咪戊土日主，水為財星。

```text
壬水為偏財。
癸水為正財。
```

目前 2026 癸巳月，癸正財透出，故感情、金錢、現實互動容易被引動。
但丙午年、庚午大運火印旺，容易把財星引動轉成安全感焦慮。

實戰建議：

```text
看到財星出現，不等於關係立即穩定。
要看財星是否能落地，是否被火印包住，是否轉成焦慮想像。
感情上宜穩定互動，不宜用焦慮硬推。
```

# 九、總結

```text
財格不是見財就好，而是身旺能任財、財星清純不破。
正財偏穩定，偏財偏流動。
財為用最怕比劫奪財，但現代應解讀為財務與關係壓力，不宜直接作恐嚇斷語。
```
