# 淵海子平下冊｜傷官詩訣：五類傷官與傷官傷盡

## 資料定位

來源：《淵海子平》下冊整理，章節「傷官詩訣」。

本篇歸入：

```text
bazi/06_ten_gods/
```

用途：補強傷官格、五類日主傷官、傷官傷盡、傷官配印、傷官生財與見官規則。

---

# 一、原文主題

本章以詩訣形式論述傷官格的核心邏輯。重點在於釐清：

```text
傷官不可例言凶。
```

也就是說，傷官格不能一概論凶。傷官的吉凶要看：

```text
1. 日主五行。
2. 月令調候。
3. 日主身強身弱。
4. 是否見官。
5. 傷官是否傷盡。
6. 是否有財星承接或印星制化。
```

---

# 二、傷官格基本前提

```text
傷官格必要身強，方能以傷官為用。
傷官傷盡最為奇，重點是不見官星，格局清純。
傷多反不宜，若身弱傷官過多，洩身太過，反而難以成事。
```

傷官主：

```text
才華
創作
表達
技術
突破
反體制
不喜拘束
自我風格
```

但傷官是否為喜，要看命局能否承受與引導。

---

# 三、五類日主傷官見官規則

這是本章最重要的內容。

| 傷官類型 | 見官規則 | 原因 |
|---|---|---|
| 火土傷官 | 宜傷盡，不宜見官 | 火日主生土為傷官，水官來剋火，容易反攻身 |
| 金水傷官 | 喜見官，官越旺越貴 | 金寒水冷，需火官調候暖局 |
| 木火傷官 | 官要旺，見官旺為喜 | 木生夏月燥熱，需水官潤局 |
| 土金傷官 | 不宜直接見官，宜配印 | 土被金洩，若再見木官殺，剋洩交加，需印星扶身 |
| 水木傷官 | 財官兩見始為歡 | 水旺春月易氾濫，需土官導流，財官相生較佳 |

# 四、傷官見官不可一概論凶

要分兩種情況：

## 1. 正官主象見傷官

```text
正官為用，傷官來剋官。
```

這是傳統所說：

```text
傷官見官，為禍百端。
```

現代解讀：

```text
制度、職位、承諾、名分、規範被挑戰，容易引發職場、關係、法律或上司壓力。
```

## 2. 傷官主象見正官

```text
命局以傷官為主，見官未必凶。
```

有些類型，如金水傷官、木火傷官，反而需要官星調候或潤局。

所以實戰要先問：

```text
是正官格被傷官破？
還是傷官格需要官星調候？
```

# 五、傷官格三種主要配置

## 1. 傷官傷盡

成立條件：

```text
1. 身強。
2. 傷官有力。
3. 命局不見官星。
4. 傷官氣勢清純。
```

特質：

```text
才藝脫俗。
自成一家。
不喜拘束。
適合創作、技術、自由表達。
```

行運：

```text
喜財運，洩秀生財。
忌官殺通根有力介入，容易產生外部規範與個人堅持的衝突。
官星虛浮時，可能只是名義、清高虛位，未必大凶。
```

---

## 2. 傷官配印

成立條件：

```text
1. 傷官過旺，洩身或反叛過度。
2. 有印星制傷、護身。
3. 印不被財星嚴重破壞。
```

作用：

```text
印星讓傷官才華被規範與學理化。
適合學術、證照、專業技術、創作理論化。
```

---

## 3. 傷官生財

成立條件：

```text
1. 身強能任洩。
2. 傷官為用。
3. 有財星承接。
4. 不被印星嚴重壓制。
```

作用：

```text
才華、技術、表達轉為收入與成果。
適合內容、設計、技術、商業、教學、服務、創作變現。
```

# 六、辛日壬辰時特殊判斷

整理內容中特別提到辛日壬辰時：

| 月令 | 判斷 |
|---|---|
| 秋月，申酉 | 身旺宜洩秀，命局清純可論貴 |
| 冬月，亥子 | 傷旺配印為用，亦可發官貴 |
| 四季庫月，辰戌丑未 | 印月生扶日主，傷官為用，可生財，行傷官財運可發富 |

此例提醒：

```text
同樣是傷官，因月令不同，用法完全不同。
```

# 七、丙火多根土又連案例

整理內容提到：

```text
丙火日主身強，土傷官旺。
生於申月，傷官生財，金水為喜。
生於亥月，七殺出現，身強任殺，殺逢傷制，也可有名。
行金水運，名利提升。
若火土重來，可能是格局失衡的脆弱時段。
```

降火理解：

```text
火土太重時，容易過燥、過剛、過度輸出，若無金水調節，身心與事業壓力會加重。
```

# 八、降火修正

## 1. 壽終之時改為脆弱時段

古文傾向：

```text
火土重來，可能是壽終之時。
```

修正版：

```text
火土重來時，若原局已燥熱偏枯，格局容易失衡，健康與事業同時承壓。應解讀為需要特別注意健康、作息與過度消耗，不宜直接斷壽終。
```

## 2. 傷官傷盡遇官不宜直接斷禍

古文傾向：

```text
傷官傷盡，若有官星禍便隨。
```

修正版：

```text
傷官傷盡格遇官殺有力介入，代表外部規範與個人自由產生強烈摩擦。需注意溝通、制度、職場與法律，不宜直接恐嚇論災。
```

## 3. 刑傷骨肉降火

古文傾向：

```text
恃己凌人心好勝，刑傷骨肉更多悲。
```

修正版：

```text
傷官旺者自尊心強、不喜被管，家庭與人際關係上容易因說話方式或堅持己見造成摩擦。宜提醒溝通方式與情緒彈性，不宜直接斷親人受傷。
```

# 九、應用場景

```text
1. 看才華、創作、技術、自由職業。
2. 看是否適合制度內或制度外發展。
3. 看傷官見官是凶是喜。
4. 看傷官生財是否能變現。
5. 看傷官配印是否能學術化、專業化。
6. 看大運流年官殺介入時的衝突。
```

# 十、阿咪命盤應用

阿咪戊土日主，庚金為食神，辛金為傷官。原局日支申中藏庚、壬、戊，有食神與財星伏藏。

目前庚午大運：

```text
庚金食神：技能、整理、輸出。
午火印星：學習、思考、安全感。
```

實戰方向：

```text
現階段比較適合先走食神路線：穩定整理、輸出、建立作品。
傷官能量若被引動，會更想直接說破、質問、突破規則，但感情與人際上需避免太急、太銳利。
```

---

# 十一、總結

```text
傷官格不能一概論凶。
最重要的是先分日主五行，再看見官是否為喜。
金水傷官喜見官，木火傷官需官旺潤局，火土傷官宜傷盡，土金傷官宜配印，水木傷官需財官兩見。
傷官的正用，是把才華、表達與突破轉化為作品、專業與財富。
```
