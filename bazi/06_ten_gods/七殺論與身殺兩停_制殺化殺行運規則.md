# 一、七殺基本定義

七殺為同性相剋：

```text
陽日主見陽剋我者為七殺。
陰日主見陰剋我者為七殺。
```

七殺代表：

```text
壓力
危機
競爭
權力
挑戰
決斷
非常任務
外部強制力
```

古書有時稱七殺為偏官，但實戰整理建議統一稱「七殺」，再看它是喜是忌。

---

# 二、七殺與正官差異

| 項目 | 正官 | 七殺 |
|---|---|---|
| 性質 | 有情之管束 | 無情之壓迫 |
| 象意 | 規範、名分、制度 | 危機、競爭、權力 |
| 使用 | 喜清純中和 | 喜制伏得宜 |
| 問題 | 官多化殺 | 殺重攻身 |
| 成就方向 | 體制、管理、公職 | 高壓任務、突破、權威、危機處理 |

---

# 三、七殺成用的核心：制伏得宜

七殺不能完全不制，也不能制過頭。

```text
無制：壓力失控，攻身成害。
制太過：七殺銳氣全失，失去驅動力。
制得宜：壓力轉成行動力與成就。
```

常見制化方式：

```text
食神制殺：以技術、理性、才華制壓力。
傷官合殺：以表達、策略、突破收束七殺。
印星化殺：以學習、資格、制度、長輩資源化解壓力。
羊刃駕殺：以強身與剛氣駕馭七殺。
```

# 四、身殺力量對比

| 結構 | 判斷 | 行運方向 |
|---|---|---|
| 身旺殺淺 | 可補殺，形成權力與突破 | 喜財殺旺運，但不可過頭 |
| 身弱殺強 | 七殺攻身，壓力過重 | 喜印比扶身，忌財殺旺運 |
| 身殺兩停 | 最理想，力量平衡 | 可行扶身運，也可行財殺運，看原局制化 |
| 殺旺有食神制 | 壓力轉能力 | 行殺旺運可發，行食傷運更穩 |
| 殺旺無制 | 衝動、壓迫、危機 | 歲運食傷或印星來救 |

# 五、月令七殺天命

月令七殺代表命主天命中自帶壓力、競爭與磨練。

常見特質：

```text
積極。
有膽識。
反應快。
決斷力強。
能處理例外事件。
常被推向高壓情境。
```

失衡時：

```text
急躁。
衝動。
走偏鋒。
壓力太大。
難以穩定持久。
```

# 六、時上一位七殺格

時上一位七殺，又稱時上一位貴。

成立條件：

```text
1. 時干透出七殺一位。
2. 七殺清純，不多雜。
3. 日主身旺能任。
4. 七殺有根，不被刑沖空亡破盡。
5. 有食神制殺、印星化殺，或行運能制化。
```

使用提醒：

```text
使用等級：中頻。
成立難度：中。
是否優先使用：否，需先確認身旺與普通格局。
```

# 七、羊刃駕殺

```text
羊刃 = 強烈自我與衝勁。
七殺 = 外部壓力與危機。
羊刃駕殺 = 以強身駕馭壓力，轉成權力與行動力。
```

成立方向：

```text
身旺。
七殺有力但不過旺。
羊刃可任殺。
不可七殺羊刃同時失控。
```

若身弱殺強，再見羊刃刑沖，不宜直接論貴，需防衝突與健康壓力。

# 九、大運流年應用

月令七殺有食神制：

```text
行殺旺運：積極有野心，壓力轉成果。
行食傷運：制殺更穩，理性行事。
```

月令七殺無制：

```text
行食傷運：衝動性被收束，較能謀定後動。
行殺旺運：壓力加重，易妄動。
```

身旺殺淺：

```text
行財殺旺運：補殺成權，可有發展。
```

身弱殺強：

```text
行財殺旺運：財生殺攻身，壓力大。
行印比運：扶身化殺，較可承受。
```

# 十、降火修正

## 1. 七殺不等於壞人

古文傾向：

```text
七殺如小人，無知凶暴。
```

修正版：

```text
七殺是強烈壓力與競爭能量。若制化得宜，可轉為決斷、抗壓、權威與專業能力；若失控，才會表現為衝動與壓迫。
```

## 2. 身弱殺強不直接斷貧病

古文傾向：

```text
身弱殺強，行財殺運，貧病。
```

修正版：

```text
身弱殺強又行財殺旺運，代表壓力、責任與外界要求加重，健康與事業承受力下降。宜以印比扶身、減少過度承擔，不宜恐嚇斷語。
```

## 3. 三刑六害不直接斷凶死

修正版：

```text
三刑六害、羊刃、七殺同時被引動時，代表衝突、安全與健康風險上升。應提醒避免高風險行為、交通危險與衝動決策。
```

# 十一、阿咪命盤應用

阿咪為戊土日主，甲為七殺，乙為正官。

原局年干甲木七殺、月支卯木正官，官殺都有象，但火印旺能化木生身。

取象：

```text
對責任、名分、壓力很敏感。
遇到關係不確定時，會有想確認、想突破的七殺感。
火印旺使壓力轉成反覆思考。
若能用食神輸出，壓力可轉成作品與行動力。
```

# 十二、總結

```text
七殺的核心不是凶，而是壓力與競爭。
七殺要制伏得宜，不能不制，也不能制太過。
身殺兩停最美，身旺殺淺可補殺，身弱殺強需印比扶身。
七殺若能食神制、印星化、羊刃駕，反能成為突破與成就的力量。
```
