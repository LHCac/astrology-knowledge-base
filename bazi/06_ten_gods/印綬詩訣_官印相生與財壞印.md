# 二、印綬格成立條件

```text
1. 月令現印星，印星成格。
2. 印星為喜用，能生扶日主。
3. 印星不被財星嚴重剋破。
4. 印星不落空亡死絕而失力。
5. 有官殺生印，成官印相生更佳。
```

# 三、官印相生

```text
官殺 → 印星 → 日主
```

官殺代表責任、壓力、職位，印星代表保護、學習、資格。官印相生時，壓力能轉成資歷、名聲與資格。

適合：

```text
公職
考試
證照
教育
研究
行政
制度內升遷
專業資格累積
```

|---|---|---|
| 身弱印為用 | 官殺生印、印星幫身 | 財星壞印、印落空亡死絕 |

# 五、印多為病的反轉

印星不一定越多越好。

```text
身弱需要印，印為喜。
身旺不需要印，印可能轉為忌。
印太重會剋食傷，造成才華輸出、生活樂趣、子女象受壓。
```

若印多為病，財星破印反而可成去病之藥。

# 六、財壞印的判斷

## 1. 印為喜用時

```text
財星剋印 = 保護力受損。
可能表現在學業中斷、資源減少、長輩支持不足、精神安全感下降。
```

## 2. 印為忌神時

```text
財星破印 = 去除過度依賴。
可能反而使命主自立、進入現實、開始行動。
```

所以不可直接說：

```text
財剋印一定凶。
```

要先問：

```text
印是喜，還是忌？
```

| 忌印 | 印比運 | 依賴、內耗、想太多加重 |

# 八、降火修正

## 1. 印逢財不必直接斷凶

古文傾向：

```text
印綬逢財，退職休官，名聲受損。
```

修正版：

```text
若印為喜用，財星來剋印，確實容易影響學業、證照、長輩資源、職位穩定或精神支持。但若印為忌神，財星反可破印去病，使人更務實自立。
```

## 2. 印星死絕空亡不宜恐嚇

修正版：

```text
印星失力代表保護與支援不足，命主需建立外部資源、學習系統與健康作息，不宜直接斷重大災禍。
```

## 3. 印重不等於一定敗家

修正版：

```text
印重可能代表資源多、依賴多、思考多。若能轉成學習、研究與知識系統，反而可成優勢。
```
