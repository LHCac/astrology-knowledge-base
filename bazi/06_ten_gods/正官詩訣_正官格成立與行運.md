# 淵海子平下冊｜正官詩訣：正官格成立與行運

## 資料定位

來源：《淵海子平》下冊整理，章節「正官詩訣」。

本篇歸入：

```text
bazi/06_ten_gods/
```

用途：補強正官格、官印相生、財官相生、傷官破官與官殺混雜的判斷。

---

# 一、原文主題

正官格以月令現正官為用，核心要求是「清純不破」。若無傷官、七殺、刑沖破害，且有財星生官或印星護官，則格局較能發揮。

正官代表：

```text
規矩
制度
名分
責任
秩序
職位
社會承認
```

---

# 二、正官格成立條件

```text
1. 月令現正官。
2. 正官為命局主要用神或格局核心。
3. 無傷官剋官。
4. 無七殺混雜。
5. 無刑沖破害直接破官。
6. 有財星生官或印星護官更佳。
```

判斷流程：

```text
月令是否正官？
├── 否：不以正官格論。
└── 是：繼續看是否清純。
    ├── 傷官剋官：格局受損，需印星化解。
    ├── 七殺混雜：官殺不清，需去殺留官或去官留殺。
    ├── 刑沖破害：官星受損，降格論。
    └── 財印相助：正官格得力。
```

---

# 三、喜忌速查

| 正官格 | 喜 | 忌 |
|---|---|---|
| 用神 | 財星生官 | 傷官剋官 |
| 保護 | 印星護官 | 七殺混雜 |
| 行運 | 財運、印運、官星得根 | 傷官運、官殺混雜運、沖破官星之歲運 |

---

# 四、格局強弱

| 配置 | 判斷 |
|---|---|
| 月令正官＋財星生官＋印星護官 | 最佳，官有源、有護、有位 |
| 月令正官＋財星生官 | 財官相生，事業與名位有推力 |
| 月令正官＋印星護官 | 官印相生，名聲清正，適合體制與專業資格 |
| 月令正官單透，無財無印 | 清純但力弱，需歲運補助 |
| 正官遇傷官、七殺、刑沖 | 格局受損，需救應 |

---

# 五、行運判斷

```text
財星旺運：財生官，利事業推進、名位提升。
印星旺運：官印相生，利學歷、證照、升遷、名聲。
官星旺運：正官得力，但不可混殺太重。
傷官運：最需謹慎，容易破壞職場、規範、承諾。
七殺運：官殺混雜，壓力增大，需分清清濁。
```

# 六、降火修正

## 1. 富貴斷語需降火

古文傾向：

```text
無破無傷貴不休，將相公侯總可為。
```

修正版：

```text
正官格清純且財印配合良好，代表命主較適合穩定制度、管理、專業資格或公職體系發展，容易在職涯上取得穩定位置。實際高度仍需合看整體命局與大運流年。
```

## 2. 無沖無破不是絕對優秀

古文傾向：

```text
無沖無破始為奇。
```

修正版：

```text
無刑沖破害是正官格清純的必要條件，但仍需財印相助與歲運配合，不能只憑無破就斷為高格。
```

---

# 七、應用場景

```text
1. 看是否適合體制、公職、管理、行政、制度性職涯。
2. 看名分、職位、規範、責任感。
3. 看正官格是否被傷官或七殺破壞。
4. 看流年大運財印相助時是否有升遷、考試、證照、職位變化。
```

---

# 八、與其他章節關聯

```text
論八字撮要法：正官為用，忌傷官剋破。
傷官說：分清正官主象見傷官，與傷官主象見正官。
五行元理消息賦：官殺清濁、去殺留官。
大運太歲：財印歲運觸發正官格。
```

---

# 九、總結

```text
正官格核心在「清純不破」。
月令正官若無傷官、七殺、刑沖破害，再得財星生官、印星護官，格局較能穩定發揮。
現代解讀不宜直接斷將相公侯，而應理解為制度、管理、專業、職位與社會承認的發展力。
```
