# 一、劫財基本定義

劫財為與日主同五行、陰陽不同者。

例如：

```text
甲木見乙木。
丙火見丁火。
戊土見己土。
庚金見辛金。
壬水見癸水。
```

劫財象徵：

```text
兄弟姊妹
朋友同輩
競爭者
分財之人
合夥人
資源分享與爭奪
```

---

# 二、劫財本質

劫財不是單純凶神，而是「同類不同陰陽」的力量。

```text
身強時：劫財多半為忌，容易分財、競爭、財務耗損。
身弱時：劫財可以幫身，反而是助力。
```

因此不能看到劫財就斷奪財、奪妻或破敗。

---

# 三、劫財判斷流程

```text
Step 1：確認日主身強或身弱。
Step 2：看劫財是否透干或在月令得勢。
Step 3：看財星是否弱而被劫。
Step 4：看是否有官殺制比劫。
Step 5：看是否有食傷化比劫生財。
Step 6：看大運流年是否再加重比劫。
```

---

# 四、身強身弱差異

| 條件 | 判斷 |
|---|---|
| 身強＋劫財多 | 劫財為忌，財務競爭、合夥摩擦、感情財務壓力明顯 |
| 身弱＋劫財多 | 劫財為喜，朋友同輩可助身，合作有利 |
| 身強＋財星弱＋劫財透 | 財星受壓，守財困難 |
| 身弱＋財星旺＋劫財 | 劫財幫身任財，未必凶 |
| 劫財帶印 | 扶身有力，但身強時可能更固執 |
| 劫財見官殺 | 官殺可制比劫，形成規範與節制 |

# 五、劫財與六親

古法常以財星代表父親與男命妻星，因此劫財旺時，會說父緣、婚姻受壓。

現代用法：

```text
劫財旺且財星弱：父緣較薄、家庭資源較不穩。
劫財旺且身強：婚姻中財務、競爭、掌控感議題較明顯。
劫財為喜：兄弟朋友反能幫助命主。
```

不可單憑劫財斷剋父、剋妻、害子。

# 六、大運流年應用

| 大運流年 | 身強命局 | 身弱命局 |
|---|---|---|
| 比劫運 | 財損、競爭、合夥摩擦 | 得助、貴人、合作有利 |
| 財運 | 可發財，但需防比劫分財 | 財來壓身，需比印扶助 |
| 官殺運 | 制比劫護財，較有規範 | 官殺壓身，需印化 |
| 食傷運 | 化比劫生財，若有財星可用 | 洩身，需看是否過度 |

# 七、降火修正

## 1. 劫財不直接斷剋妻害子

古文傾向：

```text
劫財主剋妻害子。
```

修正版：

```text
劫財旺且身強時，財星受到壓制，婚姻與財務壓力較明顯；但需合看日支夫妻宮、財星根氣與大運流年，不可一見劫財就斷婚姻凶。
```

## 2. 奪財奪妻是象，不是定論

古文傾向：

```text
劫財必奪財奪妻。
```

修正版：

```text
劫財象徵競爭與資源分享。身弱時劫財為喜，可助身任財，不存在奪財問題。名稱不能直接定吉凶。
```

## 3. 父緣薄不宜絕對化

修正版：

```text
劫財旺且財星弱時，父緣或幼年家庭資源較弱是一種傾向，仍需合看年柱、財星根氣與全局。
```

# 八、阿咪命盤應用

阿咪為戊土日主，己土為劫財。

2026 小運己丑：

```text
己土劫財出現。
丑中藏己癸辛，帶劫財、正財、傷官。
```

取象：

```text
內在想抓穩、想比較、想確認自己位置。
感情中容易在意是否被特別看待。
財星癸也被引動，感情與現實互動同時出現。
```

建議：

```text
劫財年或小運不宜用競爭心推關係。
要把比較感轉成自我建設與穩定行動。
```

```text
劫財是同類競爭與資源分配之星。
身強劫財多，容易分財與關係摩擦；身弱劫財可幫身，是助力。
劫財吉凶不能看名稱，必須先看身強身弱與財星狀態。
```
