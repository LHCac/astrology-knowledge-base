# 一、財星基本定義

財星為我所剋者，代表：

```text
金錢
資源
現實利益
生活經營
感情付出
男命妻星與女性緣
```

戊土日主舉例：

```text
壬水 = 偏財
癸水 = 正財
```

---

# 二、正財與偏財差異

| 項目 | 正財 | 偏財 |
|---|---|---|
| 陰陽 | 異陰陽相剋 | 同陰陽相剋 |
| 財的性質 | 專屬之財、穩定財 | 眾人之財、流動財 |
| 感情象 | 正妻、穩定伴侶、固定關係 | 偏緣、外緣、非固定吸引 |
| 性格 | 節儉、顧家、實際 | 慷慨、多情、樂善好施 |
| 財源 | 薪資、固定收入、穩定資產 | 人脈、生意、外財、機會財 |
| 風險 | 身弱財多、比劫奪財 | 浪費、合夥分財、財旺生殺 |

---

# 三、正財論核心

正財的天命：

```text
過好自家生活。
管好自家財務。
顧好自家親人。
重視節儉、秩序、穩定經營。
```

正財格核心前提：

```text
身旺才能任財。
財要得時，但不宜過多。
財多若身旺，可財生官，富而生貴。
財多若身弱，財反盜氣，成壓力。
```

---

# 四、偏財論核心

偏財的天命：

```text
樂善好施。
廣結人緣。
分享資源。
慷慨多情，不太吝財。
```

偏財格核心前提：

```text
身強方能享偏財。
偏財為眾人之財，得財也需分享。
最好有官殺護財，制比劫爭財。
忌比劫分奪。
身弱偏財旺，財旺可能生官殺攻身。
```

---

# 五、財格成立條件

```text
1. 月令為財星，或財星成為命局主象。
2. 財星有根、有氣，不被沖破。
3. 日主身旺或有印比扶身，能承接財星。
4. 財星不被比劫嚴重爭奪。
5. 有食傷生財，財源更順。
6. 身旺時有官殺護財，可富而生貴。
```

# 六、身旺身弱與財星

| 結構 | 判斷 |
|---|---|
| 身旺財旺 | 能任財，財格可發揮 |
| 身旺財弱 | 喜食傷生財，忌比劫奪財 |
| 身財兩停 | 最佳，財能為我用 |
| 身弱財旺 | 財多反累身，需先扶身 |
| 身弱財旺再見官殺 | 財生官殺攻身，壓力最重 |
| 財旺有印比扶身 | 可逐步承財 |

# 七、財星與官殺

正財格：

```text
財多可生官，但須身健。
身旺財生官，富然後貴。
身弱財生官，剋洩交集，壓力加重。
```

偏財格：

```text
有官殺可制比劫護財。
但身弱偏財旺又行官殺運，財生殺攻身，風險增加。
```

---

# 八、比劫奪財

比劫為財星最大壓力之一。

```text
比劫旺：財被分奪。
身旺財弱又見比劫：財更難守。
偏財為眾人之財，比劫多則資源更容易被瓜分。
官殺能制比劫，故可護財。
食傷可化比劫生財，形成轉化。
```

# 九、行運規則

## 身旺財格

```text
喜食傷運：技能、作品、表達生財。
喜財運：財星發動。
喜官運：財生官，名利相生。
忌比劫運：競爭、合夥、分財、衝動花費。
```

## 身弱財格

```text
喜印比運：先扶身，再承財。
忌再行財運：財務與感情壓力加重。
忌官殺運：財生官殺攻身，責任更重。
食傷運需慎用：身弱再洩，可能消耗。
```

# 十、降火修正

## 1. 身弱財旺不直接斷破財傷妻

古文傾向：

```text
身弱財旺，破財傷妻。
```

修正版：

```text
身弱財旺代表金錢、感情與現實責任超過承擔能力，容易有財務壓力、關係壓力或過度付出。需先扶身、建立能力、界線與理財節奏。
```

## 2. 偏財無官不直接斷禍患百出

古文傾向：

```text
財盛無官，禍患百出。
```

修正版：

```text
偏財旺而無官殺護財，代表資源流動大但缺乏規範，容易因合夥、人情、浪費或分財而失衡。宜建立規則、契約與財務邊界。
```

## 3. 比劫奪財不直接斷破敗

修正版：

```text
比劫奪財代表競爭、花費、資源分散、人情壓力與合夥摩擦。是否破財，仍需看財星旺衰、官殺護財與現實行為。
```
