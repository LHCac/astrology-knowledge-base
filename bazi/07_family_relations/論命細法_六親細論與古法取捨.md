# 淵海子平下冊｜論命細法：六親細論與古法取捨

## 資料定位

來源：《淵海子平》下冊整理，章節「論命細法」。

本篇歸入：

```text
bazi/07_family_relations/
```

用途：補強六親判斷，包括父母、兄弟、妻子、子女，以及古法細論的取捨原則。

---

# 一、原文主題

本章以十神為核心，細論六親關係。透過財、印、比劫、官殺、食傷在命局中的位置、旺衰、刑沖合化，推論父母、兄弟、配偶、子女之緣分與互動。

同時，本章也包含對部分古法術士技倆的批評，提醒學習者不可迷信單一顯象或話術。

---

# 二、六親基本對應

| 六親 | 男命常用取象 | 女命常用取象 | 補充 |
|---|---|---|---|
| 父親 | 偏財為主 | 偏財為主 | 也須看年柱、月柱、財星旺衰 |
| 母親 | 正印為主 | 正印為主 | 也看印星是否受財剋 |
| 兄弟姊妹 | 比肩、劫財 | 比肩、劫財 | 看同輩、競爭、手足緣 |
| 妻子 | 財星 | 不以財為夫 | 男命財為妻星 |
| 丈夫 | 不以官為妻 | 官殺 | 女命官殺為夫星 |
| 子女 | 官殺 | 食傷 | 須合看時柱 |

---

# 三、實戰可用規則

## 1. 看父母緣

```text
偏財受剋嚴重、入墓、無氣：父緣較薄，或父親助力有限。
印星受財剋：母親、照顧資源、支持系統較受損。
年月宮受沖刑：早年家庭環境較動盪。
```

降火提醒：

```text
不可直接斷父母早亡。應改為父母緣、家庭支持、早年環境穩定度需要觀察。
```

---

## 2. 看兄弟關係

```text
比劫旺：兄弟朋友、同輩競爭明顯。
比劫為喜：同輩可助身。
比劫為忌：競爭、破財、資源分散。
比劫被三合化為他局：兄弟各自分散，情分較淡。
月令財星被比劫沖剋：財務與同輩關係容易有摩擦。
```

---

## 3. 看妻子與感情，男命

```text
財星透出且旺：伴侶存在感強，對命主影響大。
財星被合化為他象：感情容易被外力牽動，或關係不穩。
財星絕於日時：配偶緣或晚年婚姻支持感不足。
財星入墓：感情藏而不顯，需大運流年引動。
財星坐長生：伴侶有生氣、聰明、有助力。
財星坐沐浴：桃花感較強，關係易帶情慾與變動。
```

降火提醒：

```text
財星狀態不佳不等於必離婚或無妻，需合看日支夫妻宮、大運流年、本人選擇與現實互動。
```

---

## 4. 看子女

男命看官殺，女命看食傷，但必須合看時柱。

```text
男命官殺入墓：子女緣不顯，需歲運引動。
女命食傷入墓：子女緣較晚或較淡。
偏印旺剋食傷：生育、子女緣、才華輸出需注意。
時柱受沖刑：晚年、子女、成果容易有變動。
```

降火提醒：

```text
不可直接斷無子、夭折、流產。應改成子女緣較薄、較晚、需要醫療與現實條件配合。
```

---

## 5. 看官訟是非

```text
命局以官星為用，流年太歲沖官星：容易有制度、法律、上司、職場是非。
忌神原局已現，歲運再來引動：事情容易加重。
若有印星或比劫解救，則可減輕。
```

# 四、古法取捨：不建議直接使用的技倆

整理內容中特別提到，部分古法屬於小道或話術，不宜納入主判斷。

```text
1. 用單一干支斷外貌，例如斷髮旋、外形細節。
2. 用食神受刑沖直接斷小兒缺乳。
3. 用單柱干支直接斷孝病中成親。
4. 過度轉換太極點推六親，容易失之偏頗。
```

現代化取捨：

```text
可作古籍知識保留，但不放入主要實戰判斷流程。
```

# 五、降火修正總表

| 古文傾向 | 修正版 |
|---|---|
| 財星受損即剋妻 | 感情支持感不足，關係需更多經營 |
| 官殺入墓即無子 | 子女緣不顯，需歲運與現實條件引動 |
| 印受財剋即母病 | 母親、照顧資源或心理支持較受損 |
| 比劫旺即兄弟背棄 | 同輩競爭或資源分散較明顯 |
| 官星沖即官訟 | 制度、職場、法律或上司壓力提高 |

# 六、應用場景

```text
1. 看原生家庭與父母緣。
2. 看手足、同輩、人際競爭。
3. 看男命感情與妻星。
4. 看女命夫星與子女星。
5. 看時柱子女、晚年、成果。
6. 看大運流年何時引動六親事件。
```

---

# 七、總結

```text
論命細法的核心，是用十神與宮位細分六親，而不是用單一口訣直接斷人生。
父母看財印與年月，妻子看財星與日支，子女看官殺食傷與時柱，兄弟看比劫與月令。
古法中有些術士話術應保留為歷史材料，不宜作實戰主規則。
```
