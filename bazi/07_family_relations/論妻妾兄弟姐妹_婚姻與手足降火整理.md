# 一、論妻妾：核心主題

男命以財星為感情與配偶星：

```text
正財：正妻、穩定伴侶、正式關係。
偏財：偏緣、女友、外緣、感情中的非固定吸引。
```

婚姻判斷不能只看財星，還要看：

```text
1. 日支夫妻宮。
2. 財星旺衰與根氣。
3. 財星是喜是忌。
4. 比劫是否強旺剋財。
5. 財星是否帶桃花、沐浴。
6. 財星是否逢沖合刑害。
7. 大運流年何時引動財星或夫妻宮。
```

---

# 二、婚姻判斷規則

| 條件 | 判斷傾向 |
|---|---|
| 財星有根有氣且為用神 | 婚姻和順，得妻助 |
| 日支坐財且為用神 | 妻賢，婚姻助力強 |
| 日支坐財但為忌神 | 婚姻帶來財務或情感困擾 |
| 日支空亡 | 婚緣較薄，有距離感或有妻如無妻感 |
| 財多身弱 | 自身能量不足，伴侶相對強勢 |
| 比劫強旺剋財 | 婚姻摩擦較多，對配偶支持力弱 |
| 財星坐桃花＋比劫來合 | 外緣較強，有外遇傾向，但需雙條件成立 |
| 財生官為用 | 妻子能幹，家庭運作順 |
| 財生殺為忌 | 婚姻中本人壓力較大 |
| 偏財強過正財 | 偏緣較強，感情較複雜 |

---

# 三、婚姻判斷流程

```text
Step 1：找出正財、偏財。
Step 2：看財星在年月日時何處出現。
Step 3：看日支夫妻宮狀態。
Step 4：判斷財星是喜用還是忌神。
Step 5：看比劫是否剋財。
Step 6：看財星是否帶桃花、沐浴或入合。
Step 7：用大運流年找婚姻事件時間點。
```

# 四、婚姻降火修正

## 1. 財衰不等於妻不賢

古文傾向：

```text
財衰敗墓絕，主妻有疾不賢，否則年高再嫁。
```

修正版：

```text
財星衰弱代表婚姻能量較低、配偶支持感或婚姻穩定性需觀察。不宜用不賢等道德評價，也不宜斷再嫁。
```

## 2. 財坐桃花不直接斷外遇

古文傾向：

```text
比肩分奪、財臨沐浴桃花，主妻妾私通。
```

修正版：

```text
財星帶桃花沐浴且比劫來合，代表外緣較強、社交與吸引力較明顯。是否外遇需看現實行為與全局，不可直接定罪。
```

## 3. 官殺重不責怪伴侶招禍

古文傾向：

```text
官殺重見，妻招幹蠱可畏。
```

修正版：

```text
官殺過重時，命主本身承受壓力較大，婚姻中容易感受到壓迫感。問題不宜歸咎於伴侶，而應看雙方互動與外部壓力。
```

## 4. 財多身弱不是妻子負面

古文傾向：

```text
財多身弱，妻反勝夫。
```

修正版：

```text
財多身弱代表自身承擔力不足，伴侶能力相對較強。現代不應視為負面，而是提醒命主需提升自我能力與關係承擔力。
```

# 五、論兄弟姐妹：核心主題

兄弟姐妹以比肩、劫財為主。

```text
比肩：同性同類，同輩、兄姐、姊妹視性別細分。
劫財：同類異性，同輩競爭、弟妹或兄弟姐妹延伸象。
```

比劫也代表：

```text
朋友
同學
同事
競爭者
合夥人
同輩資源
```

---

# 六、手足判斷規則

| 條件 | 判斷傾向 |
|---|---|
| 比劫生旺為喜 | 兄弟朋友可助力 |
| 比劫過旺為忌 | 競爭多、資源分散、破財壓力 |
| 比劫受官殺剋 | 兄弟緣較薄或相處較少 |
| 月柱比劫明顯 | 手足、同輩、同學影響早年明顯 |
| 比劫逢沖 | 手足關係變動、分離或競爭加劇 |
| 比劫合財 | 合夥、感情、財務容易交纏 |

---

# 七、兄弟姐妹降火修正

```text
比劫旺不等於一定兄弟不和，也可能代表同輩多、朋友多、競爭意識強。
比劫為喜時，同輩能助身；比劫為忌時，才容易形成損耗與競爭。
兄弟數量不可只靠比劫多寡斷定，現代家庭結構差異大，宜看緣分與互動品質。
```

---

# 八、應用場景

```text
1. 看男命婚姻與配偶緣。
2. 看夫妻宮日支狀態。
3. 看感情外緣與偏財象。
4. 看比劫奪財對婚姻與財務的影響。
5. 看兄弟姐妹、朋友同輩、合夥競爭。
6. 看流年沖財或沖比劫時的人際事件。
```

# 九、阿咪命盤應用

阿咪為戊土日主，水為財星：

```text
壬水偏財。
癸水正財。
```

原局日支申中藏壬偏財，代表感情財星藏於夫妻宮內部，容易被特定互動引動，但未必一開始明顯。

2026 癸巳月，癸正財透出：

```text
感情、女性、現實互動被引動。
但巳火印星同時放大焦慮與安全感議題。
```

提醒：

```text
財星被引動，不等於正緣立即成立。
要看互動是否穩定、是否落地、是否能從焦慮轉為平等認識。
```

# 十、總結

```text
論妻妾以財星與日支夫妻宮為核心，但不可用古代偏見斷伴侶品德。
```
