# 一、總原則

女命富貴貧賤篇的核心，不是用婚姻成敗評價女性，而是看命局是否平衡：

```text
官星是否清純有力。
身主是否能承受財官殺。
食傷是否適度，不過度剋官。
印星是否能護身或化殺。
財官印是否配置得宜。
刑沖合害是否過多。
大運流年是否引動喜用或忌神。
```

現代使用原則：

```text
古文的富貴，可改為：格局順、資源穩、關係與社會支持較佳。
古文的貧賤，可改為：格局失衡、壓力較大、關係或生活較難穩定。
不可用貞潔、下賤、剋夫等語言評價女性。
```

| 財官印三者配置得宜 | 資源、責任、學識三者能流通 |

# 五、判斷流程

```text
Step 1：先看身主旺衰。
Step 2：看官星是否清純，一位有力或混雜多見。
Step 3：看財官印是否流通，是否互相破壞。
Step 4：看食傷是否過旺剋官，或能生財。
Step 5：看七殺是否有制有化。
Step 6：看比劫、羊刃、刑沖、桃花、合局是否造成失衡。
Step 7：看大運流年是否補救或加重。
```

# 六、重點降火修正

## 1. 官殺混雜不等於品行問題

```text
官殺混雜代表關係牽引複雜、伴侶類型不一、感情選擇壓力較大。
不可解釋成女性品行不端。
```

## 2. 傷官太重不等於婚姻必敗

```text
傷官旺代表才華、自主、表達與不受拘束。
若有印星制傷或財星通關，反可成專業、創作與事業能力。
```

## 3. 桃花合多不等於淫亂

```text
桃花、合多代表人際魅力、外緣、社交活動與情感牽連多。
需看喜忌與現實行為，不可直接道德定罪。
```

## 4. 羊刃沖刑不等於必有血光

```text
羊刃沖刑代表安全、衝動、衝突與急性事件風險上升。
應作為交通、運動、健康、法律衝突的安全提醒。
```

## 5. 貴格也要看行運

```text
即使命局成貴格，若行運破用神，仍會受挫。
即使命局有失衡格局，若行運能制化去病，仍能改善。
```

# 七、方法論提醒

本系列最重要的一句方法論是：

```text
命局與行運多變，還是要實際綜合詳斷，不可一見即斷。
```

這句話應放在所有女命章節的總綱：

```text
不可看到一個格局名稱就判富貴貧賤。
不可用古代性別道德觀評價女性。
不可離開旺衰、喜忌、宮位、大運流年而單獨斷命。
```

# 八、總結

```text
女命貴格的共同點是：用神有力、官星清純、身主能任、財官印食能流通。
女命失衡格局的共同點是：官殺混雜、身弱難任、傷官太重、財印衝突、比劫羊刃過強、桃花合沖過多。
現代解讀應把古文貴賤語言轉為格局順逆、壓力來源、關係模式與自我調整方向。
```
