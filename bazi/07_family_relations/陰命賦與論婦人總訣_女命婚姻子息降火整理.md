## 資料定位

來源：《淵海子平》下冊整理，章節「陰命賦（女命專論）」與「論婦人總訣」。

本篇歸入：

```text
bazi/07_family_relations/
```

用途：整理古法女命判斷框架，包括夫星、身主、子息星、傷官、多合、官星宮位與大運成婚條件。因古文帶有明顯性別偏見，本篇以現代降火方式重整。

# 一、女命判斷總綱

古法女命判斷順序：

```text
第一：先觀夫星，官星之盛衰。
第二：次論身主，日主之強弱。
第三：再看子息星，食傷之狀態。
```

現代整理：

```text
官星代表伴侶與關係承諾。
日主代表女性自身狀態與承擔力。
食傷代表子女、才華、表達與自我外放。
```

# 三、夫星與身主組合

| 條件 | 古法傾向 | 現代降火解讀 |
|---|---|---|
| 夫旺身旺，食傷適度 | 夫子俱榮 | 關係、家庭、自我承擔力較平衡 |
| 夫衰子衰 | 孤單難成家 | 伴侶與子女議題能量較弱，家庭建立需更多經營 |
| 夫衰身旺 | 婦操夫權 | 女性獨立性強，婚姻中主導性較高 |
| 官殺旺身弱 | 受丈夫所累 | 關係壓力較大，需提升自我支持與界線 |
| 身弱有夫有子 | 貧寒 | 雖有家庭，但承擔力不足，生活壓力較大 |
| 身旺無夫無子 | 昌盛 | 獨立發展能力強，不宜以婚育有無評價人生 |

# 四、官星所在宮位

| 官星位置 | 判斷傾向 |
|---|---|
| 月令官星旺且為用 | 易遇有才幹或具責任感之伴侶 |
| 日支官星為喜用 | 夫星坐正位，婚姻較穩定 |
| 官星在日時為忌且旺 | 正夫緣較薄，偏緣或晚年感情議題較重 |
| 官殺混雜 | 關係選擇或伴侶類型較複雜 |
| 官星受傷官剋 | 婚姻需更多溝通，女性自我表達與關係承諾有衝突 |

# 五、傷官的雙面性

古法常言女命傷官剋夫，但需降火。

傷官代表：

```text
才藝
表達
自主性
不受約束
自我意識
創作與外放
```

若傷官過旺且無印化、無財通關：

```text
容易與伴侶、制度、婚姻期待產生摩擦。
```

若有財星通關或印星制化：

```text
才華可轉為現實成果，也能使關係更有建設性。
```

# 六、婚姻成立的大運條件

```text
官傷同見：行印運制傷護官，婚姻較容易成立或穩定。
身強比劫旺而官星衰：行官殺運制比劫護財，可能有婚姻之喜。
官星藏而不透：歲運透官或合動夫宮時，感情事件較易出現。
夫宮受沖：感情變動、關係重新定義或婚姻事件被引動。
```

# 七、多合與貴人過多降火

古法傾向把多合、多貴人與女命道德評價連結，這需要現代化處理。

修正版：

```text
命局多合，代表人際牽連較多、外緣廣泛、關係界線需要經營。
貴人多，代表容易獲得外界幫助、人緣佳，但若合多且忌神被合動，家庭生活可能較難安定。
不可用「賤象」「非妓即尼」等古代道德化語言。
```

# 八、降火修正

## 1. 官殺旺身弱不直斷孤寒

古文傾向：

```text
鬼旺身衰，必作孤寒之婦。
```

修正版：

```text
官殺旺而身弱，代表婚姻或伴侶壓力較大，可能難以得到實質支持。需建立自我力量與界線，不宜斷孤寡。
```

## 2. 夫衰子弱不使用下賤語言

古文傾向：

```text
子死夫衰，只是孤單下賤。
```

修正版：

```text
夫星與子息星俱弱，代表家庭能量不足，婚姻與子女議題較需經營。不宜用下賤等價值評判。
```

## 3. 女子無才便是德需完全降火

古文傾向：

```text
女子無才便是德。
```

修正版：

```text
此為古代性別偏見。女命傷官旺可代表才華、自主、表達與創作力。問題不在有才，而在才華是否被健康引導、是否懂得溝通與關係界線。
```

## 4. 多合不等於賤象

古文傾向：

```text
多合貴神，非妓即尼。
```

修正版：

```text
多合代表人際牽連、外緣廣泛或關係較複雜。是否影響婚姻，要看合的是喜神還是忌神，不可道德化斷語。
```

# 九、實戰判斷流程

```text
Step 1：找女命夫星，正官與七殺。
Step 2：看夫星是否生旺、有根、為喜用。
Step 3：看夫星所在宮位，尤其月令與日支。
Step 4：看日主身強身弱，能否承受官殺。
Step 5：看食傷是否過旺剋官，或是否有印財調和。
Step 6：看合多、官殺混雜、夫宮沖合等關係複雜象。
Step 7：用大運流年判斷感情事件時間點。
```

# 十一、總結

```text
陰命賦與論婦人總訣可作女命婚姻子息判斷框架，但古文性別偏見很重。
現代使用時，應把夫星解讀為伴侶與關係承諾，把傷官解讀為才華與自主，把多合解讀為人際牽連與界線議題。
```
