女命總斷歌是女命系列的總結篇，以歌訣方式濃縮女命判斷邏輯。

# 二、官星判斷

女命以官殺為伴侶星。

```text
正官：正式伴侶、穩定婚姻、關係承諾。
七殺：偏緣、壓力型伴侶、強烈吸引與挑戰。
```

判斷規則：

```text
官星一位清純有根且為用：婚姻較穩。
官殺混雜或多見：感情選擇複雜，關係不易單純。
有殺時官被合：可能成去濁留清，需看留殺是否可用。
無殺時官被合：夫星被合去，婚姻承諾受損。
官殺干透但地支無根：夫緣薄，名義有而實質不足。
```

# 三、身主強弱

```text
身不強不弱，能任官任洩：較佳。
身旺無官制：主導性強，婚姻需更多柔軟與協調。
身弱官強：婚姻、責任、外界要求壓力較大。
身弱財官旺為忌：生活負擔較重，需要印比扶身。
```

降火提醒：

```text
女命不是身弱才好，也不是身強必壞。
男女命判斷核心一致：清純、平衡、喜用有力。
```

# 四、印星與財星

## 1. 印星

```text
印星為喜用：穩重、學習、保護、支持力。
印星過多：容易壓食傷，子女星與表達受限。
印帶天月德：性情較穩，逢凶有緩和力。
```

## 2. 財星

```text
財星為感情付出、資源、現實承接。
正財為喜：有私財、實際資源與生活管理能力。
財多身強能任：可論富。
財多身弱或剋印：情感與現實壓力較重。
```

# 五、羊刃判斷

```text
羊刃＋官殺制：羊刃駕殺，能把剛強與壓力轉為能力。
羊刃＋傷官：傷官剋官殺，使殺不制刃，婚姻爭執或自我剛強較明顯。
羊刃逢沖：安全、衝突、急性事件風險上升。
```

# 六、特殊格局

## 1. 財官藏庫格

成立條件：

```text
身強。
財官為喜用。
財官藏於辰戌丑未四庫主氣。
逢歲運沖庫而開。
```

不可濫用：

```text
若財官只是藏於雜氣餘氣，逢沖可能反散，不成財官藏庫格。
```

## 2. 天干一字格

成立條件：

```text
四柱天干同一字。
氣勢純一。
必須有根苗。
歲運扶身。
```

不可濫用：

```text
無根則身弱，難任財官，不可只看四天干同字即論貴。
```

## 3. 地支一字格

古法以地支全同或同類論六親壓力。

現代解讀：

```text
地支俱傷官：婚姻承諾受壓。
地支俱財：印星受壓，照顧與支持系統受損。
地支俱官：身主受壓，責任較重。
地支俱印：食傷子女與表達受壓。
地支俱祿刃：自我能量極旺，感情與親子需更多柔軟。
```

# 八、婚姻時機判斷

```text
命局有財官：成婚多在財官歲運。
傷官歲運：婚姻承諾容易受壓，不宜視為穩定成婚時機。
命局無官殺：行官殺運或財運時，仍可能引動婚姻。
命局官殺俱有，行傷官劫財運：婚姻難成，需待運過或有印化。
```

# 九、降火修正

## 1. 合多不論娼妓

古文傾向：

```text
合神若是多，非妓亦謳歌。
```

修正版：

```text
命局多合代表外緣廣泛、社交活躍，在現代可能對應演藝、公關、服務、創作或人際型職業，不宜道德定性。
```

## 2. 印多不直斷損子

古文傾向：

```text
滿盤都是印，損子必須定。
```

修正版：

```text
印星過多會壓食傷，子女緣或子女發展空間可能受限，應注意養育方式與親子界線，不宜斷必損子。
```

## 3. 四馬全不直斷私生子

古文傾向：

```text
寅申巳亥全，孤淫腹便便。
```

修正版：

```text
四馬全代表奔波、移動、外放與不安定，感情與生活節奏較難安定，不宜斷私生子。
```

## 4. 辰戌相沖不論淫賤

修正版：

```text
辰戌相沖代表水火激盪、情緒與內在矛盾較強，感情決策需更穩，不可用淫賤評價品格。
```
