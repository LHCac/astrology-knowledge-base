# 一、原文主題

本章以日干為命主，從五行生剋與陰陽正偏推衍六親。六親總論說明父母、兄弟、妻財、子孫等六親對應十神；六親捷要歌則以歌訣濃縮六親生剋吉凶規則。

核心觀念：

```text
六親不是死背，而是以日主為中心，由十神關係推出。
正星偏內、偏近、名正言順；偏星偏外、偏遠、形勢使然。
宮位配合十神，才能判斷緣分深淺與事件位置。
```

# 五、六親生剋沖合基本原則

```text
六親星生旺有根：該六親力量較明顯，緣分較實。

六親星受剋沖：與該六親的互動容易有壓力、分離、摩擦或事件。
```

# 六、空亡使用降火

古法提到：

```text
金空則鳴。
火空則發。
水空則流。
木空則折。
土空則崩。
```

降火理解：

```text
空亡不直接等於死亡或完全沒有。
空亡多主虛化、疏離、缺席感、不落實、心理距離或力量不穩。
金火水空有時反而可作特殊發用；木土空則較需留意根基不穩。
```

# 七、實戰判斷流程

```text
Step 1：確認日干。
Step 2：依男命或女命找出六親星。
Step 3：看六親星在天干、地支、藏干中是否出現。
Step 4：看六親星是否得令、有根、生旺。
Step 5：合看宮位：年、月、日、時各主何事。
Step 6：看六親星是否被沖剋合害、空亡。
Step 7：再以大運流年判斷何時發動。
```

# 八、常見判斷降火修正

## 1. 官殺多者難為兄弟

古文傾向：

```text
官殺多，兄弟必少或無緣。
```

修正版：

```text
官殺較多時，比劫受壓，兄弟手足緣分可能較薄或相處較少，但不代表一定早失或無緣，需看旺衰與大運流年。
```

## 2. 印綬受剋難見父母

古文傾向：

```text
印星被財剋，主剋母或難見父母。
```

修正版：

```text
印星受剋時，與母親、照顧者或支持系統的連結可能較弱，早年照顧感不足，但不直接等於母親早逝。
```

## 3. 六親星逢合不直接論不正

古文傾向：

```text
偏財作合，父不正；財作合，妻不正。
```

修正版：

```text
六親星入合，代表該六親社交、人際、情感牽連較多，不宜直接斷不忠或外遇。
```

## 4. 傷官旺不直接論嗣絕

古文傾向：

```text
傷官強旺，子嗣絕後。
```

修正版：

```text
傷官強旺時，子女星受壓，可能晚得子、子女緣較薄或親子互動需經營，不宜直接說無子。
```

## 5. 空亡不等於死亡

古文傾向：

```text
六親星空亡，甚至代表死亡。
```

修正版：

```text
六親星空亡主虛化、疏離、缺席感，不直接等同死亡。需合歲運與其他強烈凶象才可進一步判斷。
```
