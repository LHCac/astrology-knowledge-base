# 淵海子平下冊｜論性情：五行性格與降火修正版

## 資料定位

來源：《淵海子平》下冊整理，章節「論性情」。

本篇歸入：

```text
bazi/08_health_personality/
```

用途：用於八字性格分析、五行心理傾向、十神性情輔助判斷。

---

# 一、原文主題

本章以五行對應五常，說明人的性情根源。五行中和則性情端正，過旺或過衰則性情偏頗。

```text
木主仁
火主禮
土主信
金主義
水主智
```

性情判斷以日主五行為基礎，但不可單看日主，必須合看日干強弱、月令、十神配置與全局旺衰。

---

# 二、核心概念

## 1. 五行與五常

| 五行 | 五常 | 正向性情 | 過旺偏差 | 過衰偏差 |
|---|---|---|---|---|
| 木 | 仁 | 慈祥、有同理心、惻隱 | 執拗、偏激 | 少仁、嫉妒、狹隘 |
| 火 | 禮 | 有禮、重儀式、外放 | 急躁、虛榮、好勝 | 輕浮、失禮、缺乏熱情 |
| 土 | 信 | 誠實、敦厚、穩重 | 固執、遲鈍、頑固 | 憂鬱、缺信、自我封閉 |
| 金 | 義 | 果決、義氣、豪爽 | 好鬥、貪欲、剛硬 | 優柔、少決斷 |
| 水 | 智 | 聰明、多謀、靈活 | 詭計、隱晦、不安定 | 膽小、無主見 |

---

## 2. 日干強弱與性格

```text
日干強：自信、有主見、行動力較強。
日干過強：剛愎、自我、傲人、不易受勸。
日干弱：謹慎、敏感、較被動。
日干過弱：退縮、缺乏安全感、容易受外界影響。
```

# 三、實戰判斷流程

```text
Step 1：確認日干五行。
Step 2：判斷日干身強或身弱。
Step 3：看該五行是否過旺、過衰或中和。
Step 4：用十神修正性格細節。
Step 5：用大運流年觀察性格在不同階段的變化。
```

## 十神輔助

```text
官殺旺：責任、壓力、紀律、受約束。
食傷旺：表達、創意、反叛、才華外露。
印星旺：學習、保護、依賴、想很多。
比劫旺：自我、競爭、主觀、同輩影響。
財星旺：現實、資源、感情、慾望、行動目標。
```

# 四、降火修正

## 1. 水旺不宜直接斷詐欺

古文傾向：

```text
水太過則詐欺、飄蕩、陰謀。
```

修正版：

```text
水過旺或水無制化時，命主可能思慮深、處事隱晦、情緒流動大，不宜直接斷定其人欺詐，需合看官星、印星、食傷與實際行為。
```

## 2. 日干弱不等於懦弱

古文傾向：

```text
日干弱則退縮怕羞。
```

修正版：

```text
日干偏弱者較謹慎、敏感、需要支持，但若有印星、比劫或良好格局扶助，仍可形成穩健、細膩、善觀察的性格。
```

## 3. 五行過旺過衰是傾向，不是定論

修正版：

```text
性格判斷要用「傾向」而非「定性」。不可單憑某一五行旺衰就判斷人品好壞。
```

# 五、應用場景

```text
1. 看命主基礎性格。
2. 看感情相處模式。
3. 看職業適性。
4. 看焦慮、退縮、急躁、固執等心理傾向。
5. 搭配大運流年，看不同階段性格表現是否被放大。
```

# 六、與阿咪命盤的連結範例

阿咪為戊土日主，命局火印偏旺，土有根，月支卯正官空。

可初步取象：

```text
土：重安全感、重穩定、希望事情有秩序。
火印旺：想很多、學習力強、容易內耗、需要被理解與承接。
官星卯空：對規範、承諾、穩定關係有期待，但早年支持感不足。
```

降火版結論：

```text
不是單純固執，而是安全感需求高；不是單純想太多，而是印星旺使內在反覆思考。若能把思考轉成學習與作品，性格優勢會被發揮。
```

# 七、總結

```text
論性情的核心不是用五行貼標籤，而是看五行中和與偏枯。
五行適中則呈現五常之德，過旺過衰則性情偏差。
實戰上須合看日主強弱、月令、十神、用神喜忌與大運流年，不可直接用單一五行斷人品。
```
