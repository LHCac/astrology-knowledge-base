# 淵海子平下冊｜論疾病：五行臟腑與健康傾向

## 資料定位

來源：《淵海子平》下冊整理，章節「論疾病」。

本篇歸入：

```text
bazi/08_health_personality/
```

用途：用於五行健康傾向、體質偏性、八字疾病象的輔助判斷。

> 注意：八字健康判斷只可作為傳統命理象意參考，不能取代醫療診斷。若有身體不適，仍應就醫檢查。

---

# 一、原文主題

本章以五行生剋、太過不及來看疾病傾向。五行分別對應人體臟腑、五官、五體與情緒。

核心觀念：

```text
五行太旺、不及、受剋太重，皆可形成病象。
取傷重者論之。
```

---

# 三、實戰判斷流程

```text
Step 1：看命局哪一五行過旺。
Step 2：看哪一五行過弱或受剋。
Step 3：看病象是否落在日主、月令、用神或忌神。
Step 4：看大運流年是否再引動該五行。
Step 5：只作健康傾向提醒，不作醫療斷語。
```

---

# 四、五行病象傾向

## 1. 木失衡

```text
木過旺：肝膽壓力、筋骨緊繃、情緒怒氣、眼睛疲勞。
木過弱或被金剋：筋脈不足、肝膽調節弱、決斷不足、眼部不適。
```

## 2. 火失衡

```text
火過旺：心火、躁熱、失眠、血壓火氣、眼睛血絲、口舌生瘡。
火過弱或被水剋：精神不足、循環弱、畏寒、心氣不足。
```

## 3. 土失衡

```text
土過旺：脾胃濕滯、消化負擔、痰濕、身體沉重、思慮過多。
土過弱或被木剋：腸胃不穩、吸收差、肌肉不足、容易憂思。
```

## 4. 金失衡

```text
金過旺：呼吸道乾燥、皮膚乾、肅殺感重、情緒壓抑。
金過弱或被火剋：肺氣不足、皮膚敏感、呼吸道較弱。
```

## 5. 水失衡

```text
水過旺：寒濕、腎水過重、情緒低沉、恐懼、流動不定。
水過弱或被土剋：腎水不足、泌尿代謝弱、耳鳴、骨力不足。
```

# 五、降火修正

## 1. 不可直接斷病名

古文傾向：

```text
某五行受剋即斷某病。
```

修正版：

```text
八字只能提示體質傾向，例如火旺易有燥熱、失眠、眼睛血絲等象，不可直接診斷疾病名稱。
```

## 2. 不可用八字取代醫療

修正版：

```text
若已有疼痛、發炎、視力異常、胸悶、長期失眠等症狀，應以現代醫療檢查為主，命理只能作生活作息提醒。
```

## 3. 太過不及皆病，不是旺就一定好

修正版：

```text
五行旺不等於健康，弱也不等於必病；重點是中和、流通與是否被歲運觸發。
```

# 六、阿咪命盤健康象參考

阿咪命盤火印偏旺，2026 丙午年、庚午大運、癸巳月時，火氣被明顯引動。

可提醒：

```text
1. 睡眠與焦慮。
2. 眼睛血絲、眼壓、乾眼。
3. 火氣、口乾、心煩。
4. 肩頸緊繃與用眼過度。
5. 土火旺時腸胃與思慮壓力。
```

生活建議：

```text
規律睡眠、少熬夜、減少過度滑手機、多補水、讓眼睛休息。
若眼睛紅且分泌物多，仍應看眼科。
```
