# 八字大運排法｜順逆、月柱起運與起運歲數

## 資料定位

本篇整理八字大運的基礎排法，重點包含：

```text
1. 大運順行、逆行如何判斷。
2. 男命、女命如何區分。
3. 大運為何以月柱為起點。
4. 第一柱大運如何排列。
5. 幾歲起運如何由節氣換算。
6. 以阿咪命盤作示範。
```

---

# 一、大運順逆不是單純「陽順、陰逆」

常見誤解：

```text
年干屬陽就順行，年干屬陰就逆行。
```

這只講到一半。

八字大運順逆，通常要同時看：

```text
1. 性別：男命或女命。
2. 年干陰陽：陽年干或陰年干。
```

常用口訣：

```text
陽男陰女順行。
陰男陽女逆行。
```

---

# 二、天干陰陽

十天干分陰陽如下：

| 天干 | 陰陽 |
|---|---|
| 甲 | 陽 |
| 乙 | 陰 |
| 丙 | 陽 |
| 丁 | 陰 |
| 戊 | 陽 |
| 己 | 陰 |
| 庚 | 陽 |
| 辛 | 陰 |
| 壬 | 陽 |
| 癸 | 陰 |

簡記：

```text
陽干：甲、丙、戊、庚、壬
陰干：乙、丁、己、辛、癸
```

---

# 三、男命、女命如何判斷順逆

| 性別 | 年干陰陽 | 大運方向 |
|---|---|---|
| 男命 | 陽年干 | 順行 |
| 男命 | 陰年干 | 逆行 |
| 女命 | 陽年干 | 逆行 |
| 女命 | 陰年干 | 順行 |

口訣再記一次：

```text
陽男陰女順。
陰男陽女逆。
```

---

# 四、大運以月柱為起點

大運排法以月柱為起點，但要注意：

```text
月柱本身不是第一步大運。
```

真正排列方式：

```text
順行：取月柱的下一柱為第一步大運。
逆行：取月柱的上一柱為第一步大運。
```

例如月柱為：

```text
丁卯
```

順行時：

```text
丁卯 → 戊辰 → 己巳 → 庚午 → 辛未 → 壬申 → 癸酉
```

第一步大運為：

```text
戊辰
```

逆行時：

```text
丁卯 → 丙寅 → 乙丑 → 甲子 → 癸亥 → 壬戌 → 辛酉
```

第一步大運為：

```text
丙寅
```

---

# 五、起運歲數不是固定月份

需要分清楚兩件事：

```text
1. 大運干支怎麼排。
2. 幾歲開始走第一步大運。
```

大運干支由月柱順逆排列。

幾歲起運則要看出生時間距離節氣的遠近。

---

# 六、順行與逆行的起運時間計算

常見算法：

```text
順行者：從出生時刻算到下一個節氣。
逆行者：從出生時刻算到上一個節氣。
```

換算口訣：

```text
三天折一歲。
一天折四個月。
一個時辰約折十天。
```

意思是：

```text
出生到節氣之間相差多少天，就用三天一歲換算起運歲數。
```

例如：

```text
距離下一節氣約15天。
15 ÷ 3 = 5。
約5歲起運。
```

注意：

```text
不同派別可能會有細部換算差異，例如是否精算到小時、分鐘。
正式排盤建議使用精確國曆生日、出生地、出生時間與節氣交接時間。
```

# 七、阿咪命盤示範

## 1. 命盤資料

```text
男命
年柱：甲戌
月柱：丁卯
日柱：戊申
時柱：丁巳
出生地：桃園
```

## 2. 判斷順逆

年干為：

```text
甲
```

甲為陽干。

阿咪為男命，所以：

```text
陽年男命 → 順行大運
```

---

## 3. 由月柱順排大運

月柱為：

```text
丁卯
```

順行下一柱開始：

```text
第一步：戊辰
第二步：己巳
第三步：庚午
第四步：辛未
第五步：壬申
第六步：癸酉
第七步：甲戌
第八步：乙亥
第九步：丙子
```

# 八、如果同一命盤是女命怎麼排？

同樣年干為甲。

甲為陽干。

若為女命：

```text
陽年女命 → 逆行大運
```

月柱仍是：

```text
丁卯
```

逆行上一柱開始：

```text
第一步：丙寅
第二步：乙丑
第三步：甲子
第四步：癸亥
第五步：壬戌
第六步：辛酉
第七步：庚申
第八步：己未
第九步：戊午
```

# 九、快速判斷模板

以後排八字大運，可以照這個流程：

```text
第一步：看年干是陽干還是陰干。
第二步：看命主性別是男命還是女命。
第三步：依「陽男陰女順，陰男陽女逆」判定方向。
第四步：找到月柱。
第五步：順行取月柱下一柱為第一步大運，逆行取月柱上一柱為第一步大運。
第六步：計算出生到節氣的距離，換算起運歲數。
第七步：一柱大運管十年，依序排列。
```

# 十、常見錯誤整理

## 1. 錯誤：男命一定順，女命一定逆

修正：

```text
男命不一定順，女命不一定逆。
要看年干陰陽。
```

## 2. 錯誤：陽年一定順，陰年一定逆

修正：

```text
要搭配性別。
陽男陰女順，陰男陽女逆。
```

## 3. 錯誤：月柱就是第一步大運

修正：

```text
月柱只是起點。
順行取下一柱，逆行取上一柱，才是第一步大運。
```

## 4. 錯誤：固定某月起運

修正：

```text
起運歲數不是固定月份，而是出生到節氣的距離換算。
```

## 5. 錯誤：一知道大運就直接斷吉凶

修正：

```text
大運要合原局喜忌、旺衰、格局、流年一起看。
不能只看大運干支名稱就斷吉凶。
```

# 十一、總結

```text
八字大運排法核心：

一、天干分陰陽。
陽干：甲、丙、戊、庚、壬。
陰干：乙、丁、己、辛、癸。

二、性別配年干定順逆。
陽男陰女順行。
陰男陽女逆行。

三、以月柱為起點排大運。
順行取月柱下一柱。
逆行取月柱上一柱。

四、起運歲數看節氣。
順行算到下一節氣。
逆行算到上一節氣。
三天折一歲，一天折四個月。

五、一柱大運管十年。
大運吉凶需回到原局喜忌與流年合看。
```
