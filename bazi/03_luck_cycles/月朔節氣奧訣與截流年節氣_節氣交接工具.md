# 一、原文主題

本章屬於曆法工具，不是格局論命章。

主要功能：

```text
1. 推算月朔與閏月。
2. 推算節氣交節時刻。
3. 幫助沒有萬年曆的術士確認月柱。
```

現代使用者不需背古代口訣，但要理解節氣對月柱的重要性。

---

# 二、月朔與閏月

基本概念：

```text
朔：日月同宮，農曆初一，月亮不可見。
望：月圓之時。
晦：月末，月亮不見。
```

閏月判斷：

```text
某月無中氣，則為閏月。
```

提醒：

```text
閏月出生者，命盤月柱仍以節氣區間為準，不以閏月名稱直接定月柱。
```

# 四、節氣交接注意事項

```text
出生在節氣交接前後幾小時，月柱可能不同。
月柱一變，月令、格局、旺衰、用神都可能改變。
```

實戰規則：

```text
1. 先確認出生時間。
2. 查精確節氣交接時刻。
3. 若接近交節，需多方比對萬年曆或排盤工具。
4. 必要時考慮出生地時區與真太陽時差。
```

---

# 五、古代節氣推算法定位

古法口訣以一年 365 日又 3 個時辰、每節氣約 15 天 5 小時 15 分鐘為基準推算。

但現代整理：

```text
此為古代無曆書時的應急推算法。
精度有限。
現代直接查萬年曆或天文節氣資料即可。
```

---

# 六、實戰可用規則

| 情境 | 實戰規則 |
|---|---|
| 確認月柱 | 以節氣為準，不以農曆月份為準 |
| 節氣前後出生 | 精查交節時間，差幾小時可能換月柱 |
| 閏月出生 | 以節氣區間定月柱，非閏月名稱 |
| 節氣工具 | 使用萬年曆或排盤軟體，不需手算古訣 |
| 排盤存疑 | 交叉比對多個來源，必要時看真太陽時 |

# 七、阿咪命盤應用

阿咪出生國曆 1994/03/23，位於驚蟄後、清明前。

```text
節氣區間屬卯月。
月令卯木成立。
丁卯月柱成立。
```

因此命盤核心月令為：

```text
卯木正官。
```

此點對阿咪命盤非常重要，因為月令正官代表：

```text
重視秩序、名分、關係定位、被正式看待。
```

# 八、降火修正

本章無恐嚇式斷語，屬曆法工具。

需要補充：

```text
古代推算口訣不可取代現代精確節氣資料。
若出生時間接近節氣交接，排盤必須特別謹慎，不可草率定月柱。
```

# 九、總結

```text
月柱以節氣定，不以農曆月初一定。
閏月不直接決定八字月柱。
節氣交接前後出生需精查交節時刻。
古代節氣口訣有歷史價值，現代實戰以萬年曆與排盤工具為主。
```
