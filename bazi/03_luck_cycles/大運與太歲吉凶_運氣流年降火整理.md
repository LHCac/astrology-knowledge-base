# 淵海子平下冊｜大運與太歲吉凶：運氣流年降火整理

## 資料定位

來源：《淵海子平》下冊整理，章節「大運、論太歲吉凶」。

本篇歸入：

```text
bazi/03_luck_cycles/
```

用途：補強大運、流年太歲、運歲互動、轉角接木與行運判斷流程。

---

# 一、原文主題

大運以天干稱五運、地支稱六氣，合稱運氣。命局為靜，大運為動，太歲流年為觸發。

核心觀念：

```text
命局是先天結構。
大運是十年環境。
太歲是當年觸發。
三者缺一不可。
```

---

# 二、核心概念

## 1. 大運與太歲分工

```text
大運主十年之氣，影響深遠但感受較慢。
太歲主一年之氣，反應快速且事件感明顯。
```

古法有：

```text
大運看支，歲君看干。
```

降火理解：

```text
大運地支代表十年氣場與大方向。
流年天干較容易顯示當年外在事件與主題。
但實戰仍需干支同看，不可只看一邊。
```

---

## 2. 天干地支作用

```text
天干主動，顯現快，時間較短。
地支主靜，根氣深，影響較久。
```

大運地支常決定十年的底色，天干則較像外顯主題。

---

# 三、大運干支互動

| 關係 | 意義 | 實戰理解 |
|---|---|---|
| 支生干 | 地支之氣上升天干 | 根氣深，事情容易刻骨銘心 |
| 干生支 | 天干之氣下入地支 | 影響深遠，氣能入根 |
| 干剋支 | 天干制地支 | 地支力量受損，外在衝擊內在根基 |
| 支剋干 | 地支制天干 | 外顯主題受制，影響深但較鈍 |

---

# 四、轉角接木

大運轉換時，若從一個方位氣轉到另一個方位氣，古稱「轉角接木」。

```text
寅卯辰：東方木
巳午未：南方火
申酉戌：西方金
亥子丑：北方水
```

## 判斷

```text
同方向相續：氣勢連貫，較平順。
跨方向轉換：氣勢驟變，人生主題容易轉彎。
```

降火修正：

```text
大運轉角不等於必凶，只代表十年主題交接，若原局偏枯或忌神被引動，該階段需更謹慎。
```

---

# 五、實戰判斷流程

```text
Step 1：先看原局身強身弱與格局。
Step 2：確定喜神、用神、忌神。
Step 3：看大運地支是否補原局不足，或加重偏枯。
Step 4：看大運天干透出何十神。
Step 5：看大運與原局四柱有無合沖刑害。
Step 6：再看流年太歲觸發哪個宮位、十神或用神忌神。
Step 7：最後才判該年事件方向。
```

# 六、大運與流年組合

| 組合 | 判斷方向 |
|---|---|
| 大運吉、流年吉 | 順勢推進，容易成事 |
| 大運吉、流年凶 | 有波折，但有底氣緩衝 |
| 大運凶、流年吉 | 有轉機，但需保守運用 |
| 大運凶、流年凶 | 風險較高，宜避險守成 |

注意：

```text
吉凶不是抽象好壞，而是看是否符合原局喜忌與用神需求。
```

# 七、神煞使用降火

整理內容提到：神煞多主身心煎熬與心理反應，不宜直接當作斷命主因。

修正版：

```text
神煞可作輔助象，不可凌駕原局、喜忌、大運流年。
如大運桃花，可表示十年內感情、人際、吸引力議題較明顯；太歲驛馬，可表示當年移動、變動、出差、搬遷機會增加。
```

---

# 八、需要降火修正

## 1. 身強身弱不可死套

古文傾向：

```text
身強宜財官，身弱宜印比。
```

修正版：

```text
身強身弱是論運起點，不是唯一答案。仍需看格局、月令、調候、用神是否受護，以及命局是否偏枯。
```

## 2. 轉角接木不可直接斷災

古文傾向：

```text
格局凶者死。
```

修正版：

```text
大運交接、氣勢轉換時，若原局不利或忌神被引動，容易遇到較大波折或健康壓力，宜謹慎，不宜冒險。
```

## 3. 劫財運不可直接斷剋父剋妻

古文傾向：

```text
行劫財運，主剋父母及剋妻、破財。
```

修正版：

```text
行劫財運時，競爭、財務損耗、人際摩擦與家庭資源分配壓力較大，需注意理財與溝通。
```

# 九、阿咪命盤應用示範

阿咪目前示範為：

```text
原局：甲戌、丁卯、戊申、丁巳
大運：庚午
流年：2026 丙午
小運：己丑
```

大運庚午：

```text
庚為食神：技能、作品、整理、輸出。
午為印星：學習、思考、安全感、焦慮。
```

2026 丙午流年：

```text
火印再旺，學習與內耗同時放大。
```

因此行運建議：

```text
把火印的焦慮轉為學習系統。
把庚金食神轉為作品、資料庫、技能輸出。
感情不宜用焦慮硬推，宜慢慢落實到生活與行動。
```

# 十、總結

```text
大運不是單看干支吉凶，而是看它進入原局後，是否補足命局、保護用神、制化忌神。
太歲流年則是當年觸發點，決定事件何時顯現。
大運定方向，流年定觸發，原局定承受能力。
```
