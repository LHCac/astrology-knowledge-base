# 淵海子平下冊｜神煞特殊格：刑合、日貴、金神、日德

## 資料定位

來源：《淵海子平》下冊整理，章節「刑合詩訣、日貴詩訣、金神詩訣、日德詩訣」。

本篇歸入：

```text
bazi/05_special_patterns/
```

用途：整理古法特殊神煞格局。此類格局古文常有極端富貴凶禍斷語，現代應大幅降火，以原局旺衰、用神喜忌為主，神煞格局僅作輔助。

---

# 一、總原則

```text
特殊神煞格局不可優先於正格、月令、旺衰、用神。
條件不完整者，不可硬套格名。
古文中的必貴、必富、必死、必孤等語，皆需轉成傾向與風險提醒。
```

---

# 二、刑合格

## 1. 核心主題

刑合格主要指：

```text
癸日甲寅時
```

以寅申之刑去官星，屬條件嚴格的特殊時柱格。

## 2. 成立條件

```text
1. 日主為癸日。
2. 時柱為甲寅。
3. 月令需配合亥子位。
4. 不見戊己庚申等破格字。
5. 不逢寅申沖破。
```

若條件不全，古文稱：

```text
假名刑合亦非真。
```

## 3. 降火修正

古文傾向：

```text
四柱支干合到刑，多因酒色喪其身；若臨羊刃並七殺，定作黃泉路上人。
```

修正版：

```text
四柱合中帶刑，代表感官享樂、衝動行為與關係糾纏需節制；若同時帶羊刃七殺，衝突、意外、高風險行為的機率增加。不可直接斷喪身或死亡。
```

# 三、日貴格

## 1. 日貴日柱

```text
丁亥
丁酉
癸巳
癸卯
```

日貴主氣質、仁慈、貴人象與外在形象，但必須格局清純。

## 2. 喜忌

```text
喜：格局清純、會合得力、柱中有助力。
忌：刑沖破害、空亡、官星沖動。
```

## 3. 降火修正

```text
日貴不等於一定富貴，只代表日柱帶有貴人氣質、仁德與人緣象。
若逢刑沖空亡，則此象受損；仍需看整體命局能否承接。
```

# 四、金神格

## 1. 基本概念

金神格古法常指特定時柱與金氣剛烈之象，重點在於：

```text
金神需制伏。
入火鄉為佳。
無制則剛烈難用。
```

## 2. 實戰理解

```text
金神不是單純凶神，而是剛烈、破舊、改革、執行力強的能量。
若有火來鍛鍊，能成器。
若無制化，則剛硬、衝動、破壞性較強。
```

## 3. 降火修正

古文可能將金神寫成破敗之神。

修正版：

```text
金神象徵強烈、銳利、需鍛鍊的能量。若有適當火煉與格局配合，可成專業、紀律、工程、技術、武職或管理能力；若無制，則需注意衝動與人際剛硬。
```

# 五、日德格

## 1. 日德日柱

古法常列日德日如下：

```text
甲寅
丙辰
戊辰
庚辰
壬戌
```

日德象徵德性、福厚、仁慈與緩和凶性。

## 2. 喜忌

```text
喜：格局清純、日主有力、財官藏蓄得用。
忌：刑沖破害、空亡、魁罡衝犯、過度混雜。
```

## 3. 降火修正

```text
日德不代表自動富貴或災禍全免，而是命局帶有較能緩和衝突、重視德性與人情的象。若原局破壞嚴重，日德力量亦有限。
```

# 六、四格比較

| 格局 | 核心 | 成立難度 | 現代使用方式 |
|---|---|---|---|
| 刑合格 | 癸日甲寅時，刑去官星 | 高 | 條件嚴格，少用 |
| 日貴格 | 特定日柱帶貴氣 | 中 | 看氣質、人緣、貴人象 |
| 金神格 | 剛烈金氣需火制 | 中高 | 看技術、紀律、剛硬能量 |
| 日德格 | 特定日柱帶德性 | 中 | 看仁厚、緩和、福德象 |

# 七、總結

```text
刑合、日貴、金神、日德皆屬特殊神煞格局。
現代實戰應先看月令、旺衰、用神、十神與大運流年。
特殊格局只有在條件完整時才補充，不可喧賓奪主。
```
