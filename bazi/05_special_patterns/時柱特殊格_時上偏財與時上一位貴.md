# 淵海子平下冊｜時柱特殊格：時上偏財與時上一位貴

## 資料定位

來源：《淵海子平》下冊整理，章節「時上偏財詩訣、時上一位貴詩訣」。

本篇歸入：

```text
bazi/05_special_patterns/
```

用途：整理時柱特殊格局，包括時上偏財格與時上一位貴格。此類格局需條件嚴格，不可只憑時柱一字即斷富貴。

---

# 一、時上偏財格

## 1. 核心主題

時上偏財格以時柱見一位偏財為核心，要求偏財清純、不逢沖破、不被比劫爭奪，且日主身旺能任財。

時柱代表：

```text
晚年
子息
成果
長期累積
人生後段收成
```

偏財在時柱若清純得用，常取象為晚年財源、資源調度、外財機會與人生後段成果。

---

## 2. 成立條件

```text
1. 時柱出現偏財。
2. 偏財一位清純，不宜多雜。
3. 偏財不逢沖破。
4. 無比劫透干或旺運爭財。
5. 日主身旺能任財。
6. 若帶正官，財生官，名利可兼。
```

---

## 3. 喜忌

| 時上偏財 | 喜 | 忌 |
|---|---|---|
| 格局 | 偏財一位清純 | 偏財多雜 |
| 身財 | 身旺財旺 | 身弱財旺 |
| 財星 | 不逢沖破 | 沖破時柱偏財 |
| 人事 | 財官相生 | 比劫爭財 |
| 行運 | 財旺、身旺、官旺 | 比劫旺運、沖時柱之歲運 |

---

## 4. 比劫爭財降火

古文傾向：

```text
田園破盡苦還貧。
傷妻損妾多遭辱。
禍百端。
```

修正版：

```text
時上偏財格遇比劫旺運，財務競爭、合夥糾紛、投資損耗與資源分散會變明顯。
男命財星亦代表感情對象，因此財務壓力可能連帶影響親密關係。
不可直接斷破產或剋妻，應提醒謹慎理財與避免高風險合夥。
```

---

# 二、時上一位貴格，時上偏官格

## 1. 核心主題

時上一位貴，通常指時柱見一位七殺，又稱時上偏官格。

核心要求：

```text
時上七殺一位清純。
日主身旺能任殺。
七殺有制伏或有化。
不宜七殺過多或官殺混雜。
```

七殺代表：

```text
壓力
權力
危機
責任
競爭
執行力
非常任務
```

---

## 2. 成立條件

```text
1. 時柱見七殺。
2. 七殺一位清純，不多雜。
3. 日主身旺，可以承受七殺。
4. 有食神制殺、印星化殺，或行運能制化。
5. 不見官殺混雜、七殺過旺無制。
```

---

## 3. 喜忌

| 時上一位貴 | 喜 | 忌 |
|---|---|---|
| 七殺 | 一位清純 | 七殺多雜 |
| 日主 | 身旺能任 | 身弱殺重 |
| 制化 | 食神制殺、印化殺 | 七殺無制 |
| 行運 | 制殺、化殺、身旺運 | 財生殺過旺、官殺混雜 |

---

## 4. 降火修正

古文常把七殺格寫得極端，有「貴不可言」或「殺重有禍」之類語氣。

修正版：

```text
時上七殺清純且有制化，代表命主能在壓力、競爭、專案、危機處理中發揮能力。
若身弱殺重或殺無制，則壓力過大，容易形成身心負擔與職涯風險。
不宜直接以大貴或大凶判斷，需合看日主強弱、食神、印星與大運。
```

---

# 三、兩格共同注意

```text
1. 都強調「時上一位」：清純比數量重要。
2. 都要看日主能不能承受。
3. 都忌混雜、沖破、比劫或官殺失衡。
4. 都不能只看時柱一個字就斷富貴。
5. 都要回到原局喜忌與大運流年判斷。
```

---

# 四、應用場景

```text
時上偏財：看晚年財運、偏財機會、資源調度、男命感情財星。
時上一位貴：看晚年權責、危機處理、專案壓力、是否能把七殺轉為能力。
```

---

# 五、總結

```text
時上偏財重在財星清純、身旺能任、忌比劫爭財。
時上一位貴重在七殺清純、身旺能任、喜食神制殺或印星化殺。
兩者皆屬時柱特殊格，需條件完整才可論格，不可濫用。
```
