# 一、刑合定義

刑合指命局中同時存在：

```text
天干五合
地支相刑
```

常見例如：

```text
丙辛合，子卯刑。
甲己合，寅巳刑。
```

其象意是：

```text
表面有合。
底層有刑。
明面吸引，暗中破壞。
```

---

# 二、刑合真正重點

古法常把刑合直接連結到酒色、敗家、疾病，但實戰不能這樣直接套。

真正重點是：

```text
被刑的是否為財星、官星、祿神或用神。
```

若財官祿神逢刑，才是凶象核心。

若命局有刑合，但用神不受傷，或另有合祿取用，不可直接論凶。

---

# 三、刑合判斷流程

```text
Step 1：找命局是否有天干五合。
Step 2：再看相關地支是否形成相刑。
Step 3：確認被刑之支是否是財官祿神或用神。
Step 4：判斷命主身強身弱，能否承受刑合動盪。
Step 5：看大運流年是否再沖刑合動。
Step 6：若涉及羊刃、財官、夫妻宮、健康宮位，風險提高。
```

---

# 四、合祿格：見不見之形

合祿是刑合章中重要的反例。

概念：

```text
官星祿神不明見於命局。
但透過三合局間接引出祿神。
此稱見不見之形。
```

若命局清純，合祿反可為貴。

但若祿神明見，又遇相刑之支，則為祿神逢刑，凶象提高。

合祿格標註：

```text
使用等級：低頻。
成立難度：高。
是否優先使用：否。
是否需要普通格局互參：是。
```

---

# 五、妒合

妒合常見於比劫旺、天干多個同類爭合財星。

取象：

```text
財被爭合。
財不歸我。
財不能順利生官。
感情或資源被多人牽動。
```

女命看財官時，若比劫旺而形成妒合，不可只看到財官就論貴或婚姻穩定。

---

# 六、喜忌與破格

| 情況 | 判斷 |
|---|---|
| 命局有刑合，但財官未受刑 | 風險較低 |
| 財官祿神直接逢刑 | 用神受損，命局不穩 |
| 合祿成立且用神清純 | 可作特殊貴象輔助 |
| 大運流年沖刑刑合之支 | 刑合引爆，事件明顯 |
| 身弱刑合重 | 承受力不足，凶象較重 |
| 比劫妒合財星 | 財不能生官，資源關係複雜 |

---

# 七、大運流年應用

| 命局情況 | 歲運觸發 | 結果 |
|---|---|---|
| 刑合涉及財官祿神 | 流年沖動刑合之支 | 財損、官訟、病象、關係衝突可能上升 |
| 刑合涉及多柱 | 大運天剋地沖多柱 | 多領域同時動盪，風險最高 |
| 合祿格 | 流年安穩、用神有根 | 貴象可發揮 |
| 合祿格 | 流年沖破三合局 | 合祿破壞，貴象減弱 |
| 羊刃加刑合 | 歲運再沖刃 | 安全、健康、衝突風險上升 |

# 八、降火修正

## 1. 命帶刑合不直接斷酒色敗家

古文傾向：

```text
命犯刑合，多因酒色喪家成病。
```

修正版：

```text
刑合代表表面有合、底層有刑的結構不穩。是否形成嚴重問題，需看財官祿神是否受刑、大運流年是否觸發，不可一見刑合就斷放縱或敗家。
```

## 2. 身入長生不可直接論入格

修正版：

```text
判斷身強身弱必須看整體生扶力量，不可單憑長生位論身旺或入格。
```

## 3. 死亡命例不可直接移植

修正版：

```text
古籍命例中的死亡，多為特定歲運同時沖刑、用神受損、羊刃被沖等多重因素疊加，不能只因刑合就斷生死。
```

# 九、應用場景

```text
1. 看特殊格局刑合與合祿。
2. 看財官祿神是否被刑。
3. 看大運流年何時觸發刑合。
4. 看女命妒合造成財官不能取用。
5. 看羊刃與刑合疊加時的安全風險。
```

# 十、總結

```text
刑合不是見合見刑就斷凶。
真正關鍵是財官祿神與用神是否受刑。
合祿格是刑合中的反例，未見而合出可為用，但成立條件嚴格。
大運流年沖刑合動時，刑合之象才明顯發作。
```
