# 一、福德秀氣格定義

福德秀氣格是特殊古格，條件為：

```text
陰干日主。
地支巳酉丑三合金局完整成立。
```

主要適用日主：

```text
乙、丁、己、癸。
```

但此格不可優先使用，因為只以日主與三合局斷吉凶，容易失之偏執。

---

# 二、福德秀氣的十神差異

同樣是巳酉丑三合金局，對不同日主代表不同十神。

| 日主 | 金局十神 | 方向 |
|---|---|---|
| 乙木 | 七殺 | 身弱喜印化殺，身強可制殺 |
| 丁火 | 財星或七殺 | 喜官旺或印化，忌身弱難任 |
| 己土 | 食傷或財星 | 喜食傷生財，忌印破局 |
| 癸水 | 正印 | 可從強或取財官，忌印再過旺 |

因此不能因為名稱叫「福德秀氣」就直接論吉。

---

# 三、福德秀氣使用標註

```text
使用等級：低頻。
成立難度：高。
是否優先使用：否。
是否需要普通格局互參：是。
```

使用前必須先判斷：

```text
身強身弱。
月令。
用神喜忌。
三合局是否被沖破。
該金局對日主到底是財、官殺、食傷還是印。
```

# 四、福德秀氣降火修正

## 1. 不可直接斷貴

古文傾向：

```text
以福德秀氣命名，暗示符合即有福貴。
```

修正版：

```text
福德秀氣只是特殊三合結構，不能作主格直接論富貴。須回到陰陽五行、生剋制化、身強身弱與全局綜斷。
```

## 2. 不可以月份直接斷凶

修正版：

```text
某月不喜只是局部提示，仍需全局判斷。不可只因出生月份就斷格局不成或人生不利。
```

# 五、雜氣辰戌丑未定義

辰戌丑未為四庫，因藏干不一、氣不純，稱為雜氣。

四庫藏干：

| 地支 | 餘氣 | 本氣 | 墓氣 |
|---|---|---|---|
| 辰 | 乙 | 戊 | 癸 |
| 戌 | 丁 | 戊 | 辛 |
| 丑 | 癸 | 己 | 辛 |
| 未 | 丁 | 己 | 乙 |

---

# 六、雜氣取用三原則

```text
1. 本氣為主，無論是否透干，都有先天影響力。
2. 本氣透干，力量最實際。
3. 本氣不透，餘氣或墓氣透出，則以透出者為有力。
4. 多氣競透時，以得氣深淺、月令與全局力量判斷輕重。
```

地支主內在心理，天干主外在行為。

```text
藏於地支：心理屬性、潛在資源。
透於天干：外在行為、可見事件。
```

---

# 七、四庫逢沖

四庫逢沖不可一概說「開庫即吉」。

要先看喜忌在何處。

| 喜忌位置 | 逢沖結果 |
|---|---|
| 喜用在本氣土 | 沖則土氣旺動，可能有利 |
| 喜用在餘氣或墓氣 | 沖可能把喜用打散，反不利 |
| 忌神在庫中 | 沖開可能引動問題 |
| 財官藏庫 | 需看是否為喜用、是否能承受 |

---

# 八、雜氣判斷流程

```text
Step 1：確認月令是否辰戌丑未。
Step 2：列出藏干：餘氣、本氣、墓氣。
Step 3：看哪一氣透出天干。
Step 4：判斷透出者對日主是何十神。
Step 5：判斷此十神是喜是忌。
Step 6：看四庫是否被沖、刑、合。
Step 7：看歲運是否引動庫中藏氣。
```

---

# 九、大運流年應用

```text
四庫逢沖，若沖動喜用本氣，可能引發資源、財官、成果顯現。
若沖散餘氣或墓氣喜用，反而容易失去暗藏助力。
若沖開忌神，則壓力、疾病、財務或關係事件可能顯現。
```

因此：

```text
開庫不是一律吉。
沖庫不是一律凶。
關鍵是庫中藏的是喜神還是忌神。
```

# 十、降火修正

## 1. 庫藏宜開不可死用

古文傾向：

```text
庫藏逢沖則開，開庫取用。
```

修正版：

```text
四庫逢沖要看喜忌所在。喜用在本氣時，沖可能使其旺動；喜用在餘氣、墓氣時，沖可能打散喜用。不可一律說開庫吉。
```

## 2. 雜氣財官不可見辰戌丑未就論富貴

修正版：

```text
四庫月令只是藏氣複雜，是否成財官印格，要看藏干透出、喜忌、身強身弱與行運引動。
```

# 十一、阿咪命盤應用

阿咪年支戌為四庫之一，戌藏丁、戊、辛。

對戊土日主而言：

```text
丁 = 正印
戊 = 比肩
辛 = 傷官
```

取象：

```text
年支戌帶早年印比傷官暗藏。
有學習、保護、自我、才華表達的潛伏結構。
遇辰戌沖或火土金被引動時，早年背景、家族、安全感、表達欲可能被觸發。
```

目前庚午大運、丙午年火印旺，容易引動戌中丁印與火土結構，焦慮與學習力同時放大。

# 十二、總結

福德秀氣是低頻特殊古格，不可優先使用。

四庫逢沖不等於必吉或必凶，關鍵在沖動的是喜神還是忌神。
