# 一、羊刃基本定義

羊刃是陽干日主在帝旺附近的極旺之氣，代表過剛、強烈、堅忍與爆發力。

重要規則：

```text
只有五陽干有羊刃。
五陰干無羊刃。
```

羊刃位置：

| 日主 | 羊刃 |
|---|---|
| 甲 | 卯 |
| 丙 | 午 |
| 戊 | 午 |
| 庚 | 酉 |
| 壬 | 子 |

---

# 二、羊刃性質

羊刃象徵：

```text
剛強
堅忍
衝動
不服輸
強烈意志
爆發力
排他性
冒險傾向
```

羊刃不是單純凶星，而是一股極強的能量。

```text
用得好，是利器。
用不好，傷人傷己。
```

# 三、月刃格成立條件

```text
1. 日主為五陽干。
2. 月令在羊刃位。
3. 日主不弱。
4. 有七殺制衡最佳。
5. 不宜羊刃逢沖、逢合過重。
6. 不宜身弱又見殺刃交攻。
```

使用標註：

```text
使用等級：中頻。
成立難度：中。
是否優先使用：否，需先確認身強與普通格局。
是否需要普通格局互參：是。
```

# 四、殺刃俱全

羊刃最喜七殺制衡。

```text
殺無刃不顯。
刃無殺不威。
殺刃俱全，能把強烈意志導向任務與成就。
```

殺刃配合判斷：

| 命局狀況 | 行運方向 | 結果 |
|---|---|---|
| 有刃無殺 | 行殺運 | 任務激活意志，可發 |
| 有殺無刃 | 行刃運 | 有力承壓，可發 |
| 刃旺殺弱 | 行官殺運、財運 | 財生殺，增加制刃力量 |
| 殺強刃弱 | 行印比運 | 扶身、開智慧、可承殺 |
| 身弱殺旺 | 行官殺運 | 剋洩交集，壓力大 |

# 六、羊刃逢沖與逢合

羊刃宜安靜。

## 1. 逢沖

```text
沖則動，羊刃被沖動，風險上升。
```

現代取象：

```text
交通風險。
運動傷害。
衝突升高。
急性疾病。
衝動決策。
法律或職場衝撞。
```

## 2. 逢合

```text
合也會動刃，尤其合去用神時不佳。
```

現代取象：

```text
被人事牽連。
關係綁定。
用神動搖。
狀態不穩。
```

# 八、降火修正

## 1. 羊刃不是必凶

古文傾向：

```text
羊刃乃天上凶星，人間惡殺。
```

修正版：

```text
羊刃代表強烈、極旺、剛硬的能量，本身中性。身強有殺制，可成承擔大任與開創格局；失控或身弱無法駕馭時，風險才會提高。
```

## 2. 有刃不直接論富貴

古文傾向：

```text
命有刃者，多主富貴人。
```

修正版：

```text
羊刃若能殺刃俱全、身主不弱，確有開創與承壓潛力；若無七殺制衡或身弱難任，反而易成衝動與壓力。
```

## 3. 沖刃不直接斷性命之危

修正版：

```text
羊刃逢沖代表安全與健康風險上升，尤其交通、運動、衝突與急性事件。應作風險提醒，不宜直接斷生死。
```

阿咪為戊土日主，戊羊刃在午。

目前庚午大運、2026丙午年，午火被反覆引動。

雖然原局不是月刃格，但歲運午火強，會帶類似羊刃的火土過旺象：

```text
情緒容易上火。
想快速突破。
心裡不服輸。
焦慮時容易硬撐。
```

提醒：

```text
午火旺時要降火，避免衝動、熬夜、情緒硬推關係。
把強烈能量轉成運動、作品、資料整理與規律行動。
```
