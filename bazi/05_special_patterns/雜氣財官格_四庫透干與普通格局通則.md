# 一、格局定位

雜氣財官格的基本形式：

```text
月令為辰、戌、丑、未四庫之一。
庫中藏干透出天干。
透出的藏干若為財星或官星，即稱雜氣財官格。
```

但本章重要提醒：

```text
雜氣格本質上與普通格局定格規則相同。
另立雜氣格之名，實為多事之舉。
```

所以實戰不應把雜氣格當成神秘特殊格，而應回到：

```text
月令藏干 → 透出天干 → 判十神 → 看身旺身弱 → 定喜忌用神。
```

# 二、四庫藏干

| 月令 | 主氣 | 中氣 | 餘氣 | 可能透出十神 |
|---|---|---|---|---|
| 辰月 | 戊土 | 乙木 | 癸水 | 財、官殺、印，依日干不同 |
| 戌月 | 戊土 | 辛金 | 丁火 | 財、官、食傷，依日干不同 |
| 丑月 | 己土 | 癸水 | 辛金 | 財、官、食傷，依日干不同 |
| 未月 | 己土 | 丁火 | 乙木 | 財、食傷、印，依日干不同 |

---

# 三、成立條件

```text
1. 月令為辰戌丑未四庫之一。
2. 月支未被三合、六合完全改變主氣。
3. 四庫藏干透出天干。
4. 透出者在月支藏干中有根。
5. 以透出者為格局主象。
6. 以日主身旺身弱決定透出十神是喜是忌。
```

若月支被三合六合改變主氣，需重新判斷，不可仍以原雜氣論。

---

# 四、判斷流程

```text
Step 1：確認月令是否辰戌丑未。
Step 2：檢查月支是否被三合、六合改變五行屬性。
Step 3：列出月令藏干。
Step 4：找出天干透出者。
Step 5：把透出者轉成對日主的十神。
Step 6：判斷日主身旺身弱。
Step 7：身旺者，財官食傷多可為用；身弱者，先取印比。
Step 8：多神透出時，不可全取，必須分主用。
```

# 五、四庫透出組合

| 透出組合 | 格局主象 | 用神取向 |
|---|---|---|
| 財透，官不透 | 財格 | 身旺用財，身弱用比印 |
| 官透，財不透 | 官格 | 身旺用官，身弱用印化官 |
| 財官俱透 | 財官同現 | 身旺可用，身弱先補身 |
| 財官印俱透 | 結構複雜 | 財印不能並用，需擇主用 |
| 食傷透 | 食傷格 | 身旺洩秀生財，身弱需補身 |

# 六、地支三合改變主氣

雜氣格最容易誤判之處，是月令被合局改變。

例如：

```text
巳酉合，巳化金。
亥子丑三會，丑隨水局。
```

若月支被合化：

```text
原本四庫藏干的取用要重算。
透出十神也要重新判斷。
不可死守原本雜氣財官格名稱。
```

# 七、喜忌與破格

喜的情況：

```text
藏干透出天干，且有根有力。
月令主氣未被合化破壞。
身旺時財官食傷透出為用。
身弱時印比得力，能承接財官。
行運引動喜用藏干。
```

忌的情況：

| 破格 | 說明 |
|---|---|
| 月支被合化 | 原定格局主象改變 |
| 財官印俱透而不分主用 | 財剋印，格局混亂 |
| 身弱財官旺透 | 財官轉壓力，需補身 |
| 藏干未透，行運也不引動 | 格局能量難顯 |
| 官格行傷官運 | 官星受損 |
| 印格行財運 | 財破印，保護力受損 |

---

# 八、大運流年應用

```text
藏干未透者，行運透出該藏干時，格局主象被引動。
四庫逢沖者，不可直接論開庫吉，要看沖出喜神或忌神。
月支被合化者，大運流年再成合局時，原局主象可能暫時轉向。
身旺行財官運，財官可發。
身弱行印比運，先補承擔力。
```

# 九、阿咪命盤應用

阿咪原局年支戌為四庫之一，但月令不是四庫，故不以雜氣財官格論。

戌藏：

```text
丁正印
戊比肩
辛傷官
```

取象：

```text
年支暗藏印、比、傷官，代表早年背景中有學習保護、自我支撐與才華表達的潛伏力量。
若歲運辰戌沖，會引動原生家庭、安全感、學習與表達議題。
```

# 十、降火修正

## 1. 雜氣格不宜特殊化

```text
雜氣財官格只是四庫藏干透出的普通格局變化，不宜另立神奇格局。
```

## 2. 四庫逢沖不一定開庫吉

```text
四庫逢沖要看沖動的是喜神還是忌神。喜神被沖散未必吉，忌神被沖出反可能成壓力。
```

## 3. 財官印俱透不可全取

```text
財官印同時出現，看似資源豐富，但財印相剋，必須分清主用，不可三者並取。
```

---

# 十一、總結

```text
雜氣財官格的核心不是格名，而是四庫藏干何者透出。
透出者為主象，身旺身弱定喜忌，三合六合可能改變月令主氣。
雜氣格應納入普通格局通則，不宜被神秘化。
```
