# 一、格局定義

正官格以月令主氣為正官為核心。

```text
月令主氣為正官，正官格成立。
正官透出天干，稱真神得用，格局力量最強。
官星藏地支不透，內有官象但外在發揮較弱，需行運透出。
```

正官代表：

```text
規範
秩序
名分
責任
職位
公共事務
社會認可
```

---

# 二、成立條件

```text
1. 月令主氣為正官。
2. 月支未被三合、六合改變主氣。
3. 正官未被刑沖破害。
4. 日主能承擔官星。
5. 官殺不宜混雜。
6. 傷官不宜剋官。
```

格局力量：

| 條件 | 格局力量 |
|---|---|
| 正官透天干 + 身旺 | 最強，真神得用 |
| 正官透天干 + 時有財星 | 財生官，格局更純 |
| 正官藏地支 + 身旺 | 中等，行運透官可發 |
| 正官透天干 + 身弱 | 官轉壓力，需印比補救 |
| 正官藏地支 + 身弱 | 力量弱，較難發揮 |

# 三、性格與天命

正官格者，多有：

```text
溫文內斂。
重視規則。
願意合作。
有責任感。
傾向公共事務與服務群體。
```

失衡時：

```text
保守。
壓抑。
怕犯錯。
被名分與責任綁住。
遇官殺混雜時，方向感容易混亂。
```

---

# 四、身旺身弱取用

```text
身旺：正官為喜用，可承擔責任與職位。
身弱：官星轉為壓力，需印綬護身或比劫扶身。
```

財印取捨：

```text
財可生官，身旺時喜財生官。
印可護身，身弱時喜印化官生身。
財剋印，財印不可混用，需分清主用。
```

---

# 五、官殺混雜

若月令正官，他柱再見七殺，則稱官殺混雜。

```text
正官主規矩與名分。
七殺主壓力與突破。
官殺混雜時，容易既想守規矩，又想走捷徑；既保守，又激進。
```

處理方式：

```text
合殺留官。
制殺留官。
去官留殺，另成殺格。
以印化殺，使壓力轉為學習與資格。
```

# 六、破格情況

| 破格 | 說明 |
|---|---|
| 見傷官 | 傷官剋官，正官格最忌 |
| 見七殺 | 官殺混雜，格局不純 |
| 月令正官被沖 | 先天格局之氣受損 |
| 月令正官被合化 | 格局可能轉為他格 |
| 財印並出 | 財剋印，需分清主用 |
| 身弱官強 | 官轉壓力，難承擔 |
| 行傷官或刑沖運 | 用神受傷，工作、名分、關係承諾受挑戰 |

# 七、特殊情形：棄命從殺

若全局財生殺旺，日主完全無根，則不再以正官格論，可能考慮從殺。

```text
成立條件：
1. 日主完全無根。
2. 無印比幫身。
3. 財殺成勢。
4. 格局氣勢純粹。
```

使用提醒：

```text
使用等級：低頻。
成立難度：高。
是否優先使用：否。
需普通格局互參。
```

# 八、大運流年應用

喜用運：

```text
身旺者喜財運、官運，財生官則事業名分可發。
身弱者喜印比運，先補身再任官。
官藏不透者，行運透官時較易發揮。
```

忌神運：

```text
傷官運：正官受剋，工作或社會關係易摩擦。
七殺運：原局純官者，行殺運引入混雜。
刑沖月令運：格局根基受動。
財破印運：以印護身者，行財運反壓力重。
```

# 九、阿咪命盤應用

阿咪為戊土日主，月令卯木，卯藏乙正官。

```text
月令正官為提綱。
代表內在重視秩序、名分、關係正當性與被正式看待。
```

但官星藏於卯支，未直接透出乙木；天干透丁印。

```text
官生印象強。
外界規範、感情名分、責任壓力，容易轉成內在思考與焦慮。
```

建議：

```text
正官需求要用成熟秩序表達，不宜變成焦慮追問。
若能把官印壓力轉成學習、資格、作品與穩定生活節奏，則正官可成用。
```

# 十、降火修正

## 1. 正官格不直接論大貴

```text
月令正官代表制度與責任主題強，是否能發展，仍取決於身旺身弱、官星透藏、財印配合與行運。
```

## 2. 官殺混雜不直接論壞命

```text
官殺混雜代表責任與壓力系統不清，需要制化取清。若能合殺留官或印化殺，仍可成局。
```

## 3. 傷官運不直接恐嚇

```text
正官格行傷官運，代表體制、名分、關係承諾、工作規範被挑戰，需以溝通與制度調整化解。
```

# 十一、總結

```text
正官格以月令正官為核心，最喜正官清純、透干、身旺可任。
身弱需印比補救，身旺可用財官。
官殺混雜、傷官剋官、月令沖合，是正官格主要破格點。
```
