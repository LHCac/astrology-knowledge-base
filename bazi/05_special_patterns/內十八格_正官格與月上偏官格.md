# 一、正官格

## 1. 格局定義

```text
月令主氣為正官，且未被合化改變。
正官透出天干，格局力量最強。
正官藏於地支不透，仍有官象，但需行運透出才較能發揮。
```

正官代表：

```text
規範、責任、制度、名分、職位、承諾、公共事務。
```

正官格的方向是承擔秩序與公共責任，不是單純「貴」。

## 2. 成立條件

```text
1. 月令主氣為正官。
2. 月支未被三合、六合完全改變主氣。
3. 正官未被沖破。
4. 日主身旺或有印比能承官。
5. 不見七殺混雜。
6. 不見傷官剋官。
```

## 3. 官星透與不透

| 狀態 | 判斷 |
|---|---|
| 正官透天干 + 身旺 | 真神得用，格局力量強 |
| 正官透天干 + 時有財星 | 財生官，格局更明確 |
| 正官藏地支 + 身旺 | 內有責任感，外顯較弱，待行運透出 |
| 正官透天干 + 身弱 | 官轉壓力，需印比扶身 |
| 正官藏地支 + 身弱 | 格局難以發揮，需大運補救 |

## 4. 喜忌與破格

| 正官格 | 喜 | 忌 |
|---|---|---|
| 身旺 | 財星生官、官星透出、行財官運 | 傷官剋官、七殺混官 |
| 身弱 | 印綬護身、比劫扶身 | 財破印、官殺太重 |
| 格局 | 官星清純、月令不受沖 | 月令被沖、被合化、官殺混雜 |

## 5. 官殺混雜

```text
月令正官，他柱再見七殺，為官殺混雜。
```

取象：

```text
一邊想守規矩，一邊想突破或走捷徑。
責任方向不清，行事風格可能忽保守忽激進。
```

處理方式：

```text
去殺留官：保留穩定秩序。
合殺留官：使格局清純。
印化殺或食神制殺：讓混雜壓力有出口。
```

## 6. 大運流年

```text
身旺正官格：喜財來生官、官旺運、印護官。
身弱正官格：喜印比扶身，先承官再論發展。
忌傷官運、七殺混入、刑沖月令之運。
```

流年觸發：

```text
流年透出月令藏官：工作、名分、責任、制度事件被引動。
流年傷官透出：與上司、制度、關係承諾容易有摩擦。
流年沖月支：格局根基動，人生方向感易波動。
```

# 二、月上偏官格：七殺格

## 1. 格局定義

```text
月令主氣為七殺，且未被合化改變。
月令七殺一位為純，殺不宜過多。
```

七殺代表：

```text
壓力、挑戰、危機、決斷、權力、競爭、系統外應變。
```

七殺格的核心不是凶，而是「壓力能不能被承擔與轉化」。

## 2. 成立條件

```text
1. 月令主氣為七殺。
2. 月支未被三合、六合改變主氣。
3. 七殺之氣仍存在，未被完全制化消滅。
4. 日主身旺或有印比能承殺。
5. 殺重時須有食傷制殺或印星化殺。
```

## 3. 七殺輕重與行運

| 命局狀態 | 喜運 | 忌運 |
|---|---|---|
| 身旺殺輕 | 殺運，增加壓力建業 | 財生殺過度 |
| 身旺殺重 | 食傷制殺運 | 官殺旺運 |
| 身弱殺旺 | 印比旺身運 | 財破印、殺旺運 |
| 殺印相生 | 印比運 | 財運破印 |
| 從殺格 | 財殺旺運 | 比印旺運破從 |

## 4. 制殺與化殺

```text
食神制殺：用技術、理性、方法管理壓力。
傷官合殺：用策略、表達、突破收束七殺。
印星化殺：用學習、資格、制度、長輩資源化解壓力。
陽刃駕殺：以強身與魄力承擔壓力，但需有制。
```

## 5. 七殺格性格象

七殺格平衡時：

```text
積極、有膽識、機智、決斷快、能處理困難與例外事件。
```

七殺格失衡時：

```text
急躁、衝動、壓力過大、難以穩定、行事無章法。
```

## 6. 從殺格提醒

```text
從殺格使用等級：低頻。
成立難度：高。
是否優先使用：否。
必須日主完全無根，殺勢純粹旺盛。
```

不可一見殺旺就論從殺。

# 三、正官格與七殺格比較

| 項目 | 正官格 | 月上偏官格 |
|---|---|---|
| 月令主氣 | 正官 | 七殺 |
| 核心象 | 秩序、名分、責任 | 壓力、危機、決斷 |
| 最喜 | 清純中和 | 制化得宜 |
| 最忌 | 傷官見官、官殺混雜 | 殺重無制、身弱殺旺 |
| 身旺 | 能任官 | 能任殺 |
| 身弱 | 官成壓力 | 殺攻身更重 |
| 行運 | 財官印視身旺身弱取用 | 殺輕喜殺，殺重喜食傷，身弱喜印比 |

# 四、阿咪命盤應用

阿咪戊土日主，月令卯木。

```text
卯藏乙，乙為戊土正官。
因此阿咪命盤有月令正官提綱之象。
```

取象：

```text
重視名分、界線、秩序與被正式看待。
感情上不容易只滿足於曖昧或慾望，會想知道關係是否正當。
工作與學習上也需要規則與方向。
```

但原局年干甲木為七殺，形成官殺皆有象：

```text
正官：想穩定、想被認真對待。
七殺：遇到不確定關係時，容易焦慮、想突破、想確認。
```

火印旺，能化木生身，但也容易把壓力轉成反覆思考。

建議：

```text
用正官的好處：建立秩序、界線與穩定節奏。
不用七殺的急：不要在焦慮中硬推關係或質問答案。
用庚金食神：把壓力整理成作品、文字、資料庫與實際行動。
```

# 五、降火修正

```text
正官格不等於必貴，代表適合責任、秩序與制度方向。
七殺格不等於凶，代表壓力、挑戰與危機處理能力。
官殺混雜不直接論壞命，重點在能否去留清楚、制化得宜。
身弱官殺旺不宜恐嚇，只代表責任壓力超過承擔力，需先補身與建立支持系統。
```

# 六、總結

```text
正官格以清純中和為美。
七殺格以制化得宜為美。
兩者都要先看月令、身旺身弱、透藏、刑沖合化與大運流年。
格名不能直接定吉凶，真正關鍵在用神能否發用。
```
