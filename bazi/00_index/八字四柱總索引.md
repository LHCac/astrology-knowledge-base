行運判斷順序：

```text
1. 先看原局。
2. 再看大運十年主題。
3. 再看流年太歲觸發。
4. 再看流月、流日細節。
5. 小運只作輔助，看命主該年內在狀態。
```

核心觀念：

```text
大運是十年環境。
流年是當年觸發。
小運是自己那一年內在氣勢。
原局是體質。
選擇是實際走向。
```

## 第四階段：格局與用神

格局不是看名稱，而是看結構能不能成立。

目前已整理：

```text
bazi/04_pattern_structure/五行元理消息賦_中和偏枯與格局總綱.md
bazi/04_pattern_structure/論八字撮要法_用神保護手冊.md
```

判斷重點：

```text
1. 月令是否為格局核心。
2. 用神是否有根、有力、清純。
3. 忌神是否破格。
4. 是否有救應或相神。
5. 行運是否保護用神，或破壞用神。
```

常用觀念：

```text
用神有力，格局才有發揮。
用神被破，需看有無救應。
喜神不是越多越好，忌神也不是永遠不可用。
成敗在配置，不在名稱。
```

```text
不可直接說剋父、剋母、剋妻、剋子。
應改為緣分薄、支持感不足、互動壓力、歲運引動。
```


女命現代使用原則：

```text
1. 不用貞潔、賤格、剋夫等道德評價。
2. 官殺代表伴侶、承諾、關係壓力。
3. 傷官代表才華、自主、表達，不代表壞。
4. 桃花代表人緣、吸引力、外緣，不代表品行問題。
5. 身強身弱沒有性別好壞，仍以命局平衡為主。
```

# 二、實戰批命使用順序

每次看一個命盤，建議照此順序：

```text
1. 確認出生資料與排盤。
2. 確認四柱、藏干、十神。
3. 看日主五行與旺衰。
4. 看月令與格局。
5. 定喜忌、用神、相神。
6. 看十神配置。
7. 看四柱宮位。
8. 看大運。
9. 看流年。
10. 看具體主題：事業、財運、感情、六親、健康。
11. 最後給降火版結論與行動建議。
```

# 四、降火總原則

整理與批命時，所有古文斷語需依下列原則轉換：

| 古文重語 | 現代降火版 |
|---|---|
| 必死 | 健康或安全風險較高，需留意歲運觸發 |
| 剋父、剋母 | 父母緣薄、支持感不足、互動壓力 |
| 剋妻、剋夫 | 伴侶星受壓，關係需經營 |
| 無子、剋子 | 子女緣較薄、較晚、親子需經營 |
| 賤、淫、娼 | 外緣強、關係界線需管理 |
| 大貴、公侯 | 具備職位、專業、制度或社會承認的發展力 |
| 破家、破財 | 財務與資源管理壓力提高 |
| 血光 | 安全、交通、運動、衝突風險提醒 |
