---

# 一、原文主題

月令是八字命局的核心中樞。

主要功能：

```text
1. 判斷所有五行旺衰。
2. 代表命局提綱與人生主題。
3. 作為格局起點。
4. 連結父母宮、兄弟宮與青年期狀態。
```

---

# 二、月令三大功能

| 功能 | 說明 |
|---|---|
| 旺衰基準 | 所有五行都要依月令判生旺休囚死 |
| 命局提綱 | 代表老天賦予的分類、任務、主題 |
| 格局起點 | 月令透出何神，通常即為命局主格方向 |

---

# 三、四柱宮位功能

| 柱位 | 功能 | 六親宮位 | 象徵 |
|---|---|---|---|
| 年柱 | 出身根本 | 祖上宮 | 家族、背景、早年來源 |
| 月柱 | 提綱主題 | 父母宮、兄弟宮 | 成長環境、社會主題 |
| 日干 | 己身 | 本人 | 論命中心 |
| 日支 | 配偶宮 | 夫妻宮 | 感情與婚姻關係 |
| 時柱 | 輔佐歸宿 | 子息宮 | 晚年、子女、人生成果 |

---

# 四、喜用神宮位得力

```text
年柱有用神：得祖上、背景、早年資源之力。
月柱有用神：得父母、成長環境、社會起點之力。
日支有用神：配偶、親密關係或內在安定得力。
時柱有用神：子女、晚年、成果與歸宿得力。
```

若某宮位受沖剋刑害，則該宮位主題需要更多經營。

---

# 五、時柱歸宿規則

時柱是全局終點與歸宿。

| 時柱狀況 | 判斷 |
|---|---|
| 喜用神引至時上且生旺 | 晚年較圓滿，成果可得 |
| 喜用神引至時上但休囚 | 晚年有用神但力量不足，需要歲運補助 |
| 忌神引至時上且衰絕 | 忌神力弱，禍輕 |
| 忌神引至時上且生旺 | 晚年壓力、子女、成果議題較重 |
| 時柱能生扶日主又制忌神 | 吉上加吉 |

# 六、月令得令速查

| 月令 | 得令五行 |
|---|---|
| 寅卯月 | 木旺 |
| 巳午月 | 火旺 |
| 申酉月 | 金旺 |
| 亥子月 | 水旺 |
| 辰戌丑未月 | 土旺，四季月 |

注意：

```text
月令旺衰是基礎。
十二長生是進階輔助。
兩者可並用，但不可混淆。
```

---

# 七、實戰判斷流程

```text
Step 1：確認月支屬何五行。
Step 2：判斷日主是否得令。
Step 3：所有五行先通過月令判強弱。
Step 4：看月令藏干是否透出。
Step 5：透出者多為命局主格方向。
Step 6：看用神落在哪一柱，對應哪個宮位得力。
Step 7：看時柱是喜用歸宿還是忌神歸宿。
```

---

# 八、阿咪命盤應用

阿咪月令為卯。

```text
卯月木旺。
卯藏乙，對戊土為正官。
```

取象：

```text
月令正官為提綱，人生主題帶有規範、秩序、名分、承諾、責任感。
感情上尤其在意是否被正式看待。
工作上也需要規則與位置感。
```

但原局火印透出：

```text
丁火正印在月干與時干。
官生印，容易把外界規範與關係壓力轉成內在思考與焦慮。
```

時柱丁巳：

```text
時柱印星強，晚年或成果方向偏向學習、研究、資料整理、精神信仰、知識系統。
```

---

# 九、降火修正

## 1. 月令為忌不等於命差

```text
月令只是先天主題。若月令為忌，代表人生主題中有需要修正與轉化的力量，不代表必然不吉。
```

## 2. 時柱忌神旺不直斷晚年凶

```text
時柱忌神旺代表晚年、子女或成果議題壓力較大，仍需看大運流年與現實選擇，不可直接恐嚇。
```

---

# 十、總結

```text
月令是全局旺衰基準、命局提綱與格局起點。
用神落在哪一柱，該宮位較得力；忌神旺在哪一柱，該宮位需經營。
時柱是歸宿，尤其關係晚年、子女與人生成果。
```
