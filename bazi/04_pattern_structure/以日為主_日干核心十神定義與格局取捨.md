## 資料定位

來源：《淵海子平》上冊整理，章節「以日為主」。

用途：確立子平術以日干為命主核心的基本方法，整理十神定義、看命操作順序，以及特殊古格不可濫用的原則。

---

# 一、原文主題

本章說明子平命學的核心方法論：

```text
以日干為主。
年為本。
月為提綱。
時為輔佐。
```

所有十神、旺衰、喜忌、格局都從日干出發。

---

# 二、歷史定位

```text
唐代李虛中：以年月日時干支、生旺死絕休囚制化論命。
宋代子平：確立以日干為主，成為現代子平八字根基。
```

因此，子平術不是只看年命，也不是只看生肖，而是以生日天干為核心。

---

# 三、五類十神定義

以日干為我，十神由五行生剋與陰陽同異推得。

| 類別 | 十神 | 定義 |
|---|---|---|
| 官殺 | 正官、七殺 | 剋我者，異性為正官，同性為七殺 |
| 財星 | 正財、偏財 | 我剋者，異性為正財，同性為偏財 |
| 印星 | 正印、偏印 | 生我者，異性為正印，同性為偏印 |
| 食傷 | 食神、傷官 | 我生者，同性為食神，異性為傷官 |
| 比劫 | 比肩、劫財 | 同我者，同性為比肩，異性為劫財 |

注意：

```text
地支藏干也要依此規則逐一轉成十神。
```

# 四、看命操作順序

```text
Step 1：確認日干，以日干為命主。
Step 2：看日干坐下何支，判斷日柱基礎。
Step 3：判身旺或身弱。
Step 4：看地支三合、六合、刑沖破害是否形成格局或破格。
Step 5：看月令五行何者最旺。
Step 6：看大運流年何者被加強或引動。
Step 7：逐步消詳，不可拘泥一說。
```

---

# 五、特殊古格取捨

本章特別提醒：

```text
妄立格局，從列其名而無實用。
```

現代整理：

```text
沒有結構支撐的特殊古格，不可優先使用。
飛天祿馬、倒沖、井欄叉等古格，很多本質上屬於傷官類，不宜視為神奇獨立格局。
```

使用標準：

```text
先看日主旺衰。
再看月令格局。
再看用神喜忌。
特殊古格只能作補充。
```

# 六、十神喜忌總則

| 十神 | 一般喜忌傾向 |
|---|---|
| 正官 | 身旺可任為喜，身弱則成壓力 |
| 七殺 | 需制化，有制為權，無制為壓力 |
| 正財 | 身旺為喜，身弱成耗身壓力 |
| 偏財 | 身旺可用，身弱易被財務、人情、感情拖累 |
| 正印 | 身弱喜印，身旺印多可能依賴或閉塞 |
| 偏印 | 可作特殊學習與保護，過旺易奪食 |
| 食神 | 身旺喜洩秀，身弱則洩身 |
| 傷官 | 身旺可成才華，見官需辨主象 |
| 比肩 | 身弱可幫身，身旺則競爭加重 |
| 劫財 | 身弱可助，身旺則分財競爭 |

# 七、阿咪命盤應用

阿咪日主為戊土，因此十神轉換為：

```text
甲 = 七殺
乙 = 正官
丙 = 偏印
丁 = 正印
戊 = 比肩
己 = 劫財
庚 = 食神
辛 = 傷官
壬 = 偏財
癸 = 正財
```

這套表是阿咪所有八字分析的基準，不論看流日、流月、大運或流年，都先轉成對戊土的十神。

例如：

```text
壬寅日 = 偏財 + 七殺、偏印、比肩藏於寅。
癸卯日 = 正財 + 正官。
```

所以壬寅偏刺激與壓力，癸卯偏名分、關係定位與穩定感。

# 八、降火修正

## 1. 十神名稱不等於吉凶

```text
正官不一定吉，七殺不一定凶。
財星不一定發財，印星不一定保護。
必須看身強身弱、月令、用神與制化。
```

## 2. 特殊格局不可濫用

```text
古格名稱只是輔助符號，若沒有月令、旺衰、用神、干支結構支撐，不可拿來主判。
```

# 九、總結

```text
以日為主，是子平術的根本。
所有十神、六親、格局、行運都要從日干出發。
論命不可先套古格，應先定日主、月令、旺衰、用神，再看特殊格局是否成立。
```
