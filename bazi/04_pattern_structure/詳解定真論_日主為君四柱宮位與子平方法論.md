# 一、日主為君

子平論命以日干為核心。

```text
日主為君。
年月時為臣。
其餘干支皆圍繞日主而定十神、旺衰、喜忌。
```

古法有以年為主者，但同年同月者眾多，若不以日干為核心，難以細辨命局。

# 二、四柱根苗花果

| 柱位 | 象徵 | 宮位意涵 |
|---|---|---|
| 年柱 | 根 | 祖上、先天根基、田宅宗派、早年背景 |
| 月柱 | 苗 | 父母、兄弟、親蔭、社會起點 |
| 日柱 | 花 | 日干為自己，日支為配偶與親密關係 |
| 時柱 | 果 | 子息、晚年、成果、人生歸宿 |

判斷原則：

```text
年月有財官印綬，為根苗先有氣。
日時配合得宜，為開花結果。
命局本身無基礎，歲運臨財官也只是一時，難以長久。
```

---

# 三、陰陽剛柔

```text
月令有氣為剛。
月令無氣為柔。
陰陽偏枯為病。
剛柔並濟為佳。
```

陰陽偏枯：

```text
過寒、過燥、過剛、過柔，皆需調和。
```

實戰上不能只看五行數量，而要看氣勢是否偏枯、是否能流通。

# 四、用神進退氣

用神不只看有無，還要看進退。

```text
用神在進氣之月令：力量逐漸上升，較有發展。
用神在退氣之月令：力量逐漸下降，發用較弱。
```

例如：

```text
冬至後甲木得陽氣助長，木有進氣。
夏令甲木氣退，木力下降。
```

判斷時須同看：

```text
用神是否有根。
用神是否透出。
用神是否得令。
用神是否進氣或退氣。
```

# 五、財官論命

```text
命局有財官，且根基深，行財官運容易榮達。
命局無財官，行財官運則福氣較淺，難以長久。
```

財星判斷：

| 結構 | 判斷 |
|---|---|
| 身強財旺 | 能任財，自能享福 |
| 身弱財多 | 財多反成壓力，心力耗費大 |
| 財旺身旺 | 財多稱意 |
| 財旺身弱 | 不能任財，易因財致禍 |
| 命有財官，行財官運 | 發展較快 |
| 命無財官，行財官運 | 根源淺薄，難長久 |

# 六、六親宮位判斷

## 1. 祖上，年柱

```text
年柱無刑沖剋害，且與月時配合得宜，祖上根基較穩。
年柱逢刑沖剋害，祖業難守，較需自立。
```

## 2. 父母，月柱

```text
月柱有財官印且旺盛無破，父母親蔭較明顯。
日主居衰死之地，即使有父母之福，也較難承接。
```

## 3. 兄弟，月支

```text
比劫在月支得長生、冠帶、臨官、帝旺，兄弟同輩較有力。
若在死墓絕胎，兄弟同輩助力較薄。
```

## 4. 婚姻，日支

```text
日支無刑沖剋害空亡，婚姻較穩。
日支逢空、刑、剋、害，婚姻緣分或相處穩定度需經營。
```

## 5. 子息，時柱

```text
男命看官殺，女命看食傷，並合時柱。
子息星在長生、冠帶、臨官、帝旺，子女緣較有力。
在衰病死墓絕胎養，子女緣較薄或需更多經營。
```

子息數訣可作古法參考，不宜現代精斷子女數量。

# 七、八專日

八專日指日干與日支五行同類，日支為比劫祿刃之象。

常見：

```text
甲寅、乙卯、丙午、丁巳、戊辰、己丑、己未、庚申、辛酉、壬子、癸亥等。
```

古法常斷損財傷妻，但需降火。

現代用法：

```text
日支為比劫，代表自我力量佔據夫妻宮。
可能在感情中主觀、自我、防衛感較強。
是否影響婚姻，要看日支是喜還是忌、財官狀態與歲運引動。
```

# 八、納音與小運取捨

本章申論指出：

```text
子平術專以生日天干為主。
不用納音作核心論命。
小運亦不應優先於原局、大運、流年。
```

資料庫使用原則：

```text
正五行、生剋制化、月令旺衰、用神喜忌為主。
納音只可作文化背景或輔助，不作主判。
小運只作輔助，不可凌駕大運流年。
```

# 九、實戰判斷流程

```text
Step 1：以日干為主，定十神。
Step 2：看四柱根苗花果，定位人生宮位。
Step 3：看月令旺衰，判剛柔偏枯。
Step 4：找用神，並看用神進退氣。
Step 5：看財官印食是否有根、透干、清純。
Step 6：看六親宮位是否刑沖合害空亡。
Step 7：大運流年補偏救弊或加重病神。
Step 8：只以納音、小運作輔助參考。
```

# 十、阿咪命盤應用

阿咪日主戊土，以日主為君。

四柱：

```text
年柱甲戌：早年根基藏印比傷，祖上與安全感議題有暗藏。
月柱丁卯：月令正官，成長與社會起點重視規範、名分、責任。
日柱戊申：日支夫妻宮藏食神、偏財、比肩，感情中有表達、吸引與自我防衛。
時柱丁巳：晚年與成果宮印星旺，學習、研究、精神支撐明顯。
```

目前庚午大運：

```text
庚食神透出，可把知識轉為作品。
午為戊土帝旺，火土旺，需避免焦慮與硬撐。
```

對應定真論：

```text
命局不是只看財官有無，而要看自己能否承接。
你最重要的是讓食神輸出成為用神的發用管道。
```

# 十一、降火修正

## 1. 日支刑害空亡不直接斷婚姻必敗

```text
日支受刑沖空亡代表親密關係穩定度需經營，不等於必離婚或必重婚。
```

## 2. 八專日不直接斷損財傷妻

```text
八專日代表自我力量佔據日支，若為忌才容易影響婚姻財務；若為喜，反可穩固自身。
```

## 3. 子息數訣不宜精斷

```text
古法子息數量可作參考，不宜現代直接斷幾子幾女。
```
