# 一、原文主題

繼善篇是綜合論命總綱之一，核心是：

```text
欲知貴賤，先觀月令提綱。
次斷吉凶，專用日干為主本。
```

也就是：

```text
月令定先天氣場。
日干定命主本體。
用神定命局所需。
大運流年定觸發。
```

# 二、用神取法流程

```text
Step 1：看月令五行旺氣，確定先天屬性。
Step 2：看日主強弱，判斷能否任財官食傷。
Step 3：身旺者，可取財官食傷為用。
Step 4：身弱者，先取印比扶身。
Step 5：確認用神是否透干、有根、不逢刑沖破害。
Step 6：大運是否順用神方向。
```

用神三條件：

```text
1. 取於月令或能補命局所需。
2. 日時能補強，令用神有根。
3. 用神不被損傷，清而不雜。
```

# 三、日主強弱

| 狀態 | 判斷 |
|---|---|
| 日主得月令旺相，有根有透 | 身強 |
| 日主失令，四柱無生扶 | 身弱 |
| 身強 | 可任財官，能承擔責任與資源 |
| 身弱 | 財官反成壓力，需先印比扶身 |

核心：

```text
日主最宜健旺。
但健旺不等於越旺越好。
仍需用神流通，不可偏枯。
```

# 五、用神不可損傷

古法強調：

```text
月令有官不可傷。
有財不可劫。
有印不可破。
有食不可奪。
```

現代整理：

```text
正官為用，怕傷官剋官。
財星為用，怕比劫奪財。
印星為用，怕財星破印。
食神為用，怕梟印奪食。
```

# 六、太歲流年通關

太歲為當年司令，流年觸發命局。

若太歲剋日主，或日主剋太歲，都代表當年有壓力與變動。

通關救法：

| 日干 | 被剋 | 通關救法 |
|---|---|---|
| 甲乙木 | 庚辛金剋 | 丙丁火食傷制金 |
| 丙丁火 | 壬癸水剋 | 戊己土食傷制水 |
| 戊己土 | 甲乙木剋 | 庚辛金食傷制木 |
| 庚辛金 | 丙丁火剋 | 壬癸水食傷制火 |
| 壬癸水 | 戊己土剋 | 甲乙木食傷制土 |

注意：

```text
流年剋身不一定凶，若有通關星，壓力可化為行動。
```

# 八、大運流年應用

```text
大運順用神方向：事業、財運、身心狀態較順。
大運逆用神方向：壓力增大，格局失衡處被放大。
流年沖用神：該年議題受損或需調整。
流年補用神：該年較易補偏救弊。
```

月令是先天氣場，不宜被沖。

```text
若月令又是用神之地，被歲運沖破，影響更重。
```

# 九、阿咪命盤應用

阿咪戊土日主，生於卯月，月令為正官。

```text
月令卯官：重視秩序、名分、被正式看待。
火印透出：學習、保護、安全感強。
日支申藏庚壬戊：食神、偏財、比肩藏於夫妻宮。
```

2026 丙午年與庚午大運：

```text
午火加重印比火土。
戊土遇木官殺壓力時，庚辛金食傷可通關制木。
```

所以對阿咪而言：

```text
壓力來時，不宜只靠印星想太多。
應用庚金食神整理、輸出、作品化，這就是通關。
```

# 十、降火修正

## 1. 用神受損不直接斷大災

```text
用神受損表示命局關鍵支撐被衝擊，可能反映事業、健康、關係或財務壓力，不宜直接恐嚇。
```

## 2. 財多身弱不只論貧

```text
財多身弱代表資源、感情、財務責任超過承擔力。現代可透過技能、規劃、界線與合作調整。
```

## 3. 太歲相剋不一定凶

```text
太歲相剋代表變動與壓力，若有通關星或現實策略，壓力可轉為成果。
```

用神不可損傷，但若有通關救應，仍可化壓力為成長。
