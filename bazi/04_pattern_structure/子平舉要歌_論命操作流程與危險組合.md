# 淵海子平上冊｜子平舉要歌：論命操作流程與危險組合

## 資料定位

來源：《淵海子平》上冊整理，章節「子平舉要歌」。

本篇歸入：

```text
bazi/04_pattern_structure/
```

用途：建立子平論命操作流程，整理日主、月令、官殺清濁、身強身弱、傷官用財、財多身弱與危險組合。

---

# 一、原文主題

本章是子平論命的操作歌訣，重點在於：

```text
先看日主。
再看月令提綱。
辨官殺清濁。
判身強身弱。
看合剋刑沖。
最後結合大運流年裁斷。
```

---

# 二、論命五大步驟

```text
Step 1：先看日主，確認日主坐下藏官、藏印或其他十神。
Step 2：看月令提綱，藏干是否透出，透出者氣重，不透者氣輕。
Step 3：辨官殺清濁，正官是否純粹，官殺是否混雜。
Step 4：判身強身弱，確認能否承擔財官食傷。
Step 5：看天干地支合剋刑沖，再合大運流年裁斷。
```

---

# 三、官殺清濁

| 結構 | 判斷 |
|---|---|
| 官星純粹 | 格局清，重秩序、名分、制度 |
| 官殺一藏一露 | 多喜露官藏殺，忌露殺藏官 |
| 官殺俱露 | 宜去其一取清 |
| 身旺官殺混雜 | 仍可能掌控局面 |
| 身弱官殺混雜 | 壓力混亂，難應對 |

正官與七殺差異：

```text
正官：條理、合規、合作、被尊重。
七殺：開創、霸道、急躁、壓力、易樹敵。
```

---

# 四、傷官用財

```text
傷官有財，傷官生財為福。
傷官傷盡，身強無官牽制，才氣可發。
財絕官衰時，傷官用財仍有補救作用。
```

傷官的好出路：

```text
才華 → 作品 → 財星 → 現實成果
```

---

# 五、身強身弱配財官

| 結構 | 判斷 |
|---|---|
| 身強見財 | 能任財，可承擔資源與感情責任 |
| 身弱財多 | 財成壓力，心力耗費大 |
| 身強見官 | 能任官，責任可成名分 |
| 身弱官殺重 | 壓力過大，需印比扶身 |
| 官星無根過輕 | 若逢財生，也能有發展 |
| 官星過旺再逢官 | 官多化殺，反成壓力 |

---

# 六、危險組合速查

| 組合 | 風險 |
|---|---|
| 身弱 + 財多 | 心力耗盡，財務與關係負擔重 |
| 身弱 + 財多 + 官運 | 財生官殺攻身，壓力加重 |
| 身弱 + 食神 + 七殺 | 食神洩身，財轉生殺，壓力強而快 |
| 官星過旺 + 歲運再逢官 | 官多化殺，自身受壓 |
| 官殺混雜 + 身弱 | 規則與壓力混亂，難掌握局面 |

---

# 七、貪合忘官與貪合忘殺

```text
貪合忘官：官星被合住，功名、職位、名分容易落空。
貪合忘殺：七殺被合住，壓力解除，反為己福。
```

這表示：

```text
正官怕被合去。
七殺若為忌，反喜被合制。
```

---

# 八、年柱傷官

年柱代表祖上、清名、早年背景。

```text
年上傷官為忌，可能代表祖上破敗、棄離祖業、早年家族背景被議論。
```

降火理解：

```text
這是早年環境或原生家庭名聲壓力，不可直接斷祖上必敗。
若傷官為喜，反可代表早年有才藝、思想突破或不依傳統。
```

# 九、阿咪命盤應用

阿咪日主戊土，日支申藏庚壬戊：

```text
庚食神：技能與輸出。
壬偏財：感情與現實吸引。
戊比肩：自我保護與比較感。
```

月令卯藏乙正官：

```text
內在重視名分、秩序、關係是否被正式看待。
```

目前庚午大運：

```text
庚食神可輸出。
午火印旺，容易想很多。
```

對應子平舉要歌：

```text
身旺火土重時，應讓食神庚金發用。
不要讓印星過旺變成只想不做。
```

# 十、降火修正

## 1. 危險組合不直接斷災

```text
身弱財多、食神見殺等組合代表壓力鏈條，不等於必有災禍。
需看用神是否得力、大運流年是否觸發，以及現實選擇。
```

## 2. 官殺混雜不一定壞

```text
若身旺且能去留清楚，官殺混雜仍可轉為制度與壓力並用的能力。
身弱才容易混亂失控。
```

## 3. 年上傷官不直接斷祖敗

```text
年上傷官為忌，代表早年環境與家族名聲壓力；傷官為喜時，可能是早年才華與突破。
```

---

# 十一、總結

```text
子平舉要歌是論命操作手冊。
核心順序是日主、月令、官殺清濁、身強身弱、干支合沖、大運流年。
真正的吉凶不在單一十神，而在全局是否清楚、有力、能流通。
```
