# 淵海子平下冊｜論八字撮要法：用神保護手冊

## 資料定位

來源：《淵海子平》下冊整理，章節「論八字撮要法」。

本篇歸入：

```text
bazi/04_pattern_structure/
```

用途：作為八字實戰判斷的「用神保護手冊」，整理各十神為用時的喜忌、最怕與最喜。

---

# 一、原文主題

本章以「用神不可被破壞」為核心，逐一整理正官、財星、印星、食神、祿神、傷官、七殺、比肩、羊刃等用神在歲運中最怕與最喜的互動。

核心觀念：

```text
用神是命局中最需要保護與發揮的力量。
用神被刑沖剋破，命局的功能就容易受損。
行運若能保護用神、制化忌神，則命局潛能可發。
```

---

# 二、用神保護總表

| 用神 | 最怕 | 最喜 | 實戰理解 |
|---|---|---|---|
| 正官 | 傷官剋破、七殺混雜 | 財星生官、印星護身 | 保護規範、職位、承諾 |
| 財星 | 劫財爭奪 | 食傷生財、官殺護財 | 保護資源、財務、男命感情 |
| 印星 | 財星剋破 | 官殺生印 | 保護學習、母親、資源、精神支持 |
| 食神 | 偏印奪食 | 財星承接 | 保護才華、享受、輸出、福氣 |
| 祿神 | 官殺沖剋 | 財星有力 | 保護日主根氣與自信 |
| 傷官 | 正官直接衝突 | 財星通關 | 才華需轉成財與現實成果 |
| 七殺 | 制伏太過或無制 | 食神適度制伏 | 壓力需被轉化為行動力 |
| 比肩 | 正官不當剋制 | 七殺適度制伏 | 自我與同輩力量需有規範 |
| 羊刃 | 沖破 | 合迎或七殺制 | 強烈能量需被控制與導向 |

# 三、實戰判斷流程

```text
Step 1：先定原局用神。
Step 2：確認用神是哪一個十神。
Step 3：查該用神最怕被什麼破壞。
Step 4：看大運、流年是否來保護或破壞用神。
Step 5：若用神受損，找是否有通關、制化、救應。
Step 6：依受損宮位與十神，判斷事件方向。
```

# 四、各用神細論

## 1. 正官為用

```text
喜：財星生官、印星護身。
忌：傷官剋官、七殺混雜。
```

實戰：

```text
正官為用時，代表規範、名分、職位、承諾、制度。若歲運傷官來剋，容易有職場、法律、關係承諾、上司制度方面的衝突。
```

---

## 2. 財星為用

```text
喜：食傷生財、官殺護財。
忌：比劫奪財、劫財運。
```

實戰：

```text
財星為用時，需保護財源與現實資源。食傷可生財，代表技能、作品、表達能轉成收入；比劫過旺則競爭、花費、分財壓力上升。
```

---

## 3. 印星為用

```text
喜：官殺生印。
忌：財星壞印。
```

實戰：

```text
印星為用時，印代表學習、保護、證照、母親、精神支持。財星過旺來剋印，容易失去支持、學業中斷、精神壓力或資源被奪。
```

---

## 4. 食神為用

```text
喜：財星承接，食生財。
忌：偏印奪食。
```

實戰：

```text
食神為用時，代表穩定才華、輸出、福氣與生活品質。偏印來剋食神，稱梟神奪食，容易使表達受阻、作品卡住、享受感下降。
```

---

## 5. 傷官為用

```text
喜：財星通關。
忌：正官直接衝突。
```

實戰：

```text
傷官代表才華、突破、技術、批判。若財星通關，傷官能轉化為收入與成果；若直接見官而無財印調和，容易與制度、上司、承諾衝突。
```

---

## 6. 七殺為用

```text
喜：食神適度制伏。
忌：完全無制，或制伏太過。
```

實戰：

```text
七殺代表壓力、競爭、決斷、危機處理。食神適度制殺，可化壓力為能力；制伏太過，反而失去敏銳與行動力。
```

---

## 7. 比肩過多化劫

```text
喜：七殺適度制伏。
忌：正官不當制比，或比劫過旺奪財。
```

實戰：

```text
比劫旺主自我強、競爭強、同輩影響大。七殺可形成社會規範與外部壓力，使比劫有方向；若無制，容易破財、爭奪、排他。
```

---

## 8. 羊刃

```text
忌：沖破。
喜：七殺制刃、合化導引。
```

實戰：

```text
羊刃是強烈的自我與衝勁，不可直接判凶。若有七殺制刃，可成執行力與權威；若逢沖破，易有衝動、衝突、身體受傷風險。
```

# 五、傷官見官補充

本章特別提醒：

```text
傷官主象見官
正官主象見傷官
```

兩者不可混用。

| 情形 | 判斷 |
|---|---|
| 正官為主，見傷官 | 傷官破官，典型傷官見官，制度與承諾受損 |
| 傷官為主，見正官 | 需看財星通關或印星護持，不可直接斷凶 |

# 六、降火修正

## 1. 用神受損不等於必災

古文傾向：

```text
用神逢刑沖剋破，必生禍害。
```

修正版：

```text
用神受損代表命局核心功能受壓，容易產生問題；實際嚴重程度仍需看是否有救應、大運流年力量、宮位與現實條件。
```

## 2. 羊刃不等於血光

修正版：

```text
羊刃逢沖時，身體、衝突、意外風險上升，但不等於必有血光。應作安全提醒，而非恐嚇斷語。
```

## 3. 財星受比劫不等於一定破產

修正版：

```text
比劫奪財代表競爭、花費、資源分散與理財壓力。是否破財，要看財星旺衰、是否有官殺護財與現實行為。
```

# 七、阿咪命盤應用

阿咪戊土日主，目前庚午大運。

```text
庚金食神：技能、作品、整理、輸出。
午火印星：學習、思考、安全感、焦慮。
```

若以食神作為重要發揮點：

```text
要保護庚金輸出，不宜讓火印過旺壓住食神。
實務上就是不要只焦慮與想像，要把想法整理成作品、GitHub資料庫、短影音、程式或設計成果。
```

感情上：

```text
財星代表女性與現實互動，若被比劫或印星包住，容易出現想抓住、想確認、但又內耗的狀態。
此時宜用食神方式處理：表達清楚、低壓互動、把關係落在現實安排，不用焦慮硬推。
```
