# 淵海子平上冊｜看命入勢・五行提綱：月令提綱與判命總綱

## 資料定位

來源：《淵海子平》上冊整理，章節「看命入勢・五行提綱」。

本篇歸入：

```text
bazi/04_pattern_structure/
```

用途：作為八字排盤後的第一層判斷總綱，建立「日干為主、月令為提綱、四柱為人生階段」的基本流程。

---

# 一、原文主題

本章是看命入門總綱，說明八字排盤後的第一步：

```text
以日干為命主。
以月令為提綱。
以四柱宮位看生命階段。
以身旺身弱判斷能否承接財官。
以通變避免死套格局。
```

月令為八字核心，代表出生時節氣給命主的先天能量，也可稱為「天命」或「初步規劃」。

---

# 二、四柱宮位與年齡段

| 柱位 | 象意 | 年齡段 | 主要觀察 |
|---|---|---|---|
| 年柱 | 根 | 0～16歲 | 祖上、家族背景、幼年環境 |
| 月柱 | 苗 | 17～32歲 | 父母、兄弟、成長環境、社會起點 |
| 日柱 | 花 | 33～48歲 | 自身、夫妻宮、婚姻與壯年狀態 |
| 時柱 | 果 | 49歲以後 | 子女、晚年、成果與人生歸宿 |

---

# 三、月令提綱

```text
月令是提綱，看命先看提綱。
月令主氣若為喜用，稱真神得用。
月令若遭刑沖，先天能量受損，格局品質下降。
```

月令主氣對命主的天命傾向：

| 月令主氣 | 天命方向 |
|---|---|
| 正官 | 管理、服務、公共事務、秩序 |
| 七殺 | 競爭、挑戰、壓力、危機處理 |
| 印星 | 學習、文化、保護、傳承 |
| 財星 | 財務、情感、現實資源、生活經營 |
| 食傷 | 才藝、創作、表達、技能輸出 |
| 比劫 | 獨立、競爭、同輩、合作與分立 |

---

# 四、身旺身弱與財官

```text
年時透出財官，須要身旺方能承受。
身衰財旺，財反剋身，財務與感情容易變成壓力。
身旺財多，財官可為命主所用。
無財官時，次看印綬與其他格局。
```

財官不是越多越好，重點是命主能否承擔。

---

# 五、大運基本方向

若用正官：

```text
喜行官旺之鄉、財旺之鄉、印綬之鄉。
忌行傷官之地。
```

若用財星：

```text
身旺喜食傷生財、財旺運。
身弱先喜印比扶身，再論財。
```

---

# 六、通變原則

本章特別強調不可死套：

```text
月令為原始天命。
若命局逢三合三會而另立格局，原始屬性不會消失，只是被壓抑或潛藏。
歲運刑沖時，原始屬性可能重新顯現。
```

因此看命不可只記格名，而要看：

```text
月令是否被改造。
原局是否有合會。
歲運是否沖開或引動。
用神是否仍能發揮。
```

---

# 七、實戰判斷流程

```text
Step 1：確認日干，定命主。
Step 2：看月令主氣，定初步格局與天命方向。
Step 3：判斷月令主氣是喜神還是忌神。
Step 4：看日主旺衰，能否承接財官食傷。
Step 5：看四柱宮位，分辨事件落點與年齡階段。
Step 6：看大運流年，判斷何時觸發。
Step 7：若有合會改格，需同時保留原月令象。
```

---

# 八、降火修正

## 1. 月令為忌不等於命差

古文傾向：

```text
月令真神得用則貴，月令受損則不貴。
```

修正版：

```text
月令為喜用時，先天方向較順；月令為忌或受刑沖時，表示先天結構需要修正與後天調整，不代表命局一定差。
```

## 2. 身弱財旺不直接斷破財傷妻

古文傾向：

```text
身衰財旺，破財傷妻。
```

修正版：

```text
身弱財旺表示財務、感情與現實責任超出承擔力，容易有財務壓力或親密關係壓力。需先扶身、建立能力與界線，不宜直接恐嚇斷語。
```

# 九、應用場景

```text
1. 排盤後的第一步分析。
2. 判斷月令格局與天命方向。
3. 判斷四柱宮位與人生階段。
4. 判斷身旺身弱能否任財官。
5. 判斷三合三會改格後是否仍保留月令原象。
```

# 十、總結

```text
看命入勢的核心是：日干為主，月令為綱，四柱分宮位，身旺身弱定承受力，大運流年定觸發。
月令是命局的先天提綱，但若逢合會改格，仍須通變，不可拘泥死法。
```
