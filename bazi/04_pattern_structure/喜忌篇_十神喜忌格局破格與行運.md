# 一、原文主題

喜忌篇以「四柱排定，三才次分，專以日上天元，配合八字支干」為框架。

核心重點：

```text
以日干為命主天元。
以月令為提綱。
以八字支干定十神。
以旺衰、喜忌、制化定吉凶。
```

本章同時收錄十神喜忌、七殺制化、食神制殺、傷官見官、財破印、羊刃沖動與特殊古格等規則。

---

# 二、四吉神與四凶神

古法將十神分為：

```text
四吉神：財、官、印、食。
四凶神：傷、殺、梟、劫。
```

但現代使用不可照字面定吉凶。

```text
吉神用錯也會成害。
凶神制化得宜也能成用。
```

所以真正要看：

```text
是否為用神。
是否得令有根。
是否清純不雜。
是否有制化救應。
是否被大運流年引動。
```

| 七殺格 | 食神制殺、印星化殺、身旺能任 | 無制、梟神奪食、財旺生殺 |

# 四、七殺判斷

七殺不是單純凶，重點在有無制化。

```text
七殺有食神制：決策力強，可立功業。
七殺有印星化：壓力轉為資格、學習與保護。
七殺無制：行事衝動，人生壓力與衝突較多。
七殺現於時柱且他處不雜，可能成時上一位貴。
```

提醒：

```text
身旺能任殺，殺可成權。
身弱殺旺，壓力攻身，宜印比扶身。
```

# 五、食神與梟印

食神格喜身旺洩秀。

```text
食神生財：技能、作品、服務可轉為收入。
食神制殺：以理性、技術、策略制住壓力。
```

最忌：

```text
梟印奪食。
```

象意：

```text
才華被壓住。
輸出中斷。
財源斷續。
生活享受下降。
子息星受壓。
```

# 六、印綬與財破印

印星是保護、學習、資格、名譽與安全感。

印綬格喜：

```text
印星清純。
官印相生。
身弱得印生扶。
```

忌：

```text
財星破印。
```

財破印象意：

```text
資源、金錢、感情、現實壓力破壞學習與保護系統。
名譽、健康、資格、安全感受損。
```

---

# 七、傷官見官

傷官見官不可一概論凶，需先辨主象。

```text
正官為用而見傷官：制度、名分、職位、承諾被挑戰。
傷官為用而見正官：才華、創意、自由被體制壓制。
```

傷官格若身旺，最喜：

```text
傷官傷盡。
傷官生財。
傷官配印。
```

# 八、羊刃與歲運觸發

羊刃喜靜不喜動。

```text
原局帶羊刃，歲運逢沖、刑、伏吟時，安全、衝突、健康風險上升。
```

降火用法：

```text
不可直接斷血光或死亡。
應提醒避免交通、運動、情緒衝突與衝動決策。
```

# 九、實戰判斷流程

```text
Step 1：確認日干強弱。
Step 2：確認月令用神。
Step 3：看十神是否透出或藏伏。
Step 4：分辨吉神是否被破、凶神是否有制。
Step 5：看格局是否清純，或官殺、財印、食梟混雜。
Step 6：看大運是否順用神方向。
Step 7：看流年是否沖刑破害關鍵字。
```

# 十、降火修正

## 1. 四凶神不等於壞

```text
傷、殺、梟、劫為凶神，是因其力量較激烈或不穩，不代表人格或命運必壞。
制化得宜，反能成才華、權力、特殊學習、競爭力。
```

## 2. 女命七殺不作道德評價

```text
女命七殺旺，現代可解讀為直接、有主見、社交活躍、承壓力強。
不可用古代婚配標準論賢淑或品行。
```

## 3. 七殺無制不直斷災病貧窮

```text
七殺旺無制代表壓力、衝突與身心負荷較大。若逢印化殺、食神制殺，仍可轉化。
```

## 4. 身旺無依不直斷僧道

```text
日主過旺無財官食傷承接，現代可對應自由職業、研究、藝術、靈性探索或不易融入體制。
```

# 十一、阿咪命盤應用

阿咪戊土日主，月令卯正官，原局火印旺，日支申藏庚壬戊。

可對應喜忌篇：

```text
正官在月令：重視名分與秩序。
火印旺：安全感、學習、保護系統強，但也容易想太多。
日支藏食神偏財：感情與輸出需靠正常互動慢慢引動。
```

目前庚午大運：

```text
庚食神可作輸出。
午火印旺也會加重焦慮。
最宜以食神洩秀，把學習與焦慮轉為作品。
```

# 十二、總結

```text
喜忌篇的核心不是吉神凶神名稱，而是用神喜忌與制化。
吉神被破則不吉，凶神有制則可用。
論命必須以日主、月令、旺衰、格局清濁、大運流年共同判斷。
```
