# 一、原文主題

本章以格言形式說明五行在旺、生、剋、強、弱不同狀態下的喜忌。

核心為：

```text
五行中和。
過強過弱皆為病。
能制、洩、化、扶者為藥。
有病得藥則發福。
```

---

# 二、病藥總原則

```text
命局某五行過強 = 病。
能剋它、洩它、化它者 = 藥。

命局某五行過弱 = 病。
能生它、扶它者 = 藥。
```

判斷重點不是誰剋誰，而是：

```text
誰太過？
誰不及？
誰能讓全局恢復流通？
```

# 九、實戰判斷流程

```text
Step 1：找出命局最旺的五行。
Step 2：找出命局最弱的五行。
Step 3：判斷旺者是否已經有制、洩、化。
Step 4：判斷弱者是否已有生扶。
Step 5：確認藥神是否有根、有力、透干。
Step 6：看大運流年是補藥，還是加重病。
Step 7：若藥神被合去、沖破、空亡，藥力減弱。
```

---

# 十、大運流年應用

```text
大運流年若來藥神，原局之病得治，容易發展。
大運流年若加重病神，壓力與事件容易放大。
藥神有根則效果大，藥神虛浮則效果有限。
```

例如：

```text
火旺為病，行水運可調候相濟。
金旺為病，行水運可洩金鋒芒。
土旺為病，行木運可疏土。
```

# 十一、阿咪命盤應用

阿咪戊土日主，原局與歲運火土偏旺。

```text
火旺生土，印星與比劫力量容易過重。
火土過旺時，容易焦慮、固執、想很多、想掌控。
```

所需藥：

```text
金：洩土，轉為食傷輸出、技能、作品。
水：潤燥，成財星、現實流動、感情與收入落地。
木：疏土，但木若過度也會變成官殺壓力。
```

最佳用法：

```text
火印學習 → 土承載整理 → 金食傷輸出 → 水財星落地。
```

# 十二、降火修正

本章多為五行規則，無恐嚇式斷語。

需注意：

```text
五行過旺過弱不是絕對吉凶。
重點是有無藥神、有無流通。
不要看到相剋就斷凶，也不要看到相生就斷吉。
```

# 十三、總結

```text
五行生剋制化的核心是中和。
過強過弱都是病，能制洩化扶者為藥。
判命要先找病，再找藥，再看大運流年是否補藥或加病。
```
