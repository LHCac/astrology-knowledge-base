# 一、原文主題

本章以丙丁日主為例，說明墓庫地支藏干複雜，不能只見官庫、印星就論貴。

核心觀念：

```text
墓庫有雜氣。
取用先看藏干是否透出。
再看地支是否合化。
官庫要清，不可被雜氣剋奪。
```

---

# 二、四庫藏干

| 地支 | 藏干 |
|---|---|
| 辰 | 乙、戊、癸 |
| 戌 | 丁、戊、辛 |
| 丑 | 己、癸、辛 |
| 未 | 己、丁、乙 |

辰戌丑未皆為雜氣，取用不能單看地支名稱。

---

# 三、墓庫取用流程

```text
Step 1：確認命局是否有辰戌丑未。
Step 2：列出該庫藏干。
Step 3：判斷藏干對日主是何十神。
Step 4：看哪個藏干透出天干。
Step 5：透出者為實際有力。
Step 6：看是否有三合、六合造成合化。
Step 7：合化後，墓庫原本土性可能減弱或轉向。
```

# 四、官庫清濁，以丙丁日主為例

對丙丁火而言，水為官星。

```text
辰中藏癸水，故辰可視為官庫。
但辰中亦藏戊土，土可剋水。
若土重無制，官星被土濁，不清。
```

官庫清化條件：

```text
命局有木制土。
或見寅、亥卯未木局，使土不奪水官。
```

官庫濁象：

```text
無木制土。
土重壓水。
官星藏而不顯。
名位、制度、職位力量難清楚發揮。
```

---

# 五、合化對墓庫的影響

```text
墓庫逢三合、六合，可能失去原本土性。
若他支合化成木，土性減弱。
若庫中本氣被合化，原本庫藏力量重組。
```

所以：

```text
墓庫不是固定不動的倉庫。
歲運合沖刑會使庫中藏氣被重組或引動。
```

# 六、四庫逢沖

四庫逢沖不可一概論開庫為吉。

| 情況 | 判斷 |
|---|---|
| 喜用在本氣土 | 沖則旺動，可能有利 |
| 喜用在餘氣或墓氣 | 沖可能打散喜用，不利 |
| 忌神藏庫 | 沖開忌神，事件與壓力浮現 |
| 用神藏庫且歲運透出 | 可視為庫藏被引動 |

---

# 七、大運流年應用

| 狀況 | 歲運觸發 | 判斷 |
|---|---|---|
| 官庫清化 | 流年透官或木制土 | 官星清晰發揮 |
| 官庫濁 | 流年再見土旺 | 官星更受壓，濁象加重 |
| 墓庫藏干未透 | 流年透出對應天干 | 庫藏被激活 |
| 墓庫逢合化 | 大運地支合局 | 土性或庫藏重組 |
| 四庫相沖 | 大運流年沖動 | 依喜忌判吉凶，不可一律開庫吉 |

# 八、降火修正

## 1. 官庫加印不等於必貴

古文傾向：

```text
官星入庫，有印可引出，官印相生而貴。
```

修正版：

```text
帶官庫是否發貴，與官庫本身或印星沒有必然關係。關鍵是官庫是否清化、官星是否為喜用、日主是否能承受，以及大運是否引動。
```

## 2. 墓庫不可粗暴套用

修正版：

```text
辰戌丑未藏干複雜，必須先看藏干透出與合化。不可只看一個庫字就斷財庫、官庫或印庫。
```

# 九、阿咪命盤應用

阿咪年支戌為四庫之一。

戌藏：

```text
丁正印
戊比肩
辛傷官
```

取象：

```text
早年根基中藏有印、比、傷官。
代表學習保護、自我意識與才華表達皆有潛伏。
```

若歲運引動辰戌沖：

```text
可能觸發原生家庭、安全感、學習、表達、過去壓力等議題。
需看沖出的是喜用還是忌神，不可單斷吉凶。
```

# 十、總結

```text
墓庫取用先看藏干，再看透干，再看合化與沖動。
官庫不等於官貴，財庫不等於必富。
四庫逢沖不一定吉，也不一定凶；關鍵在庫中藏的是喜神還是忌神。
```
