# 心理學與哲學輔助資料

> 用途：補強星盤解析與星骰占問中的「潛意識、需求、動機、人格、防衛、自我修煉、命運態度」等內容。

這個資料夾不是用來取代占星資料，而是作為占星與星骰解讀的心理學、哲學背景資料庫。

---

## 資料夾目的

星骰與星盤常常會碰到以下問題：

```text
為什麼我會這樣想？
為什麼對方會這樣反應？
這個選擇背後真正的需求是什麼？
我現在是在追求成長，還是在逃避焦慮？
面對壓力時，我該怎麼修煉自己？
```

占星可以提供象徵與結構，心理學可以補充人性需求與行為動機，哲學可以補充人生態度與行動原則。

## 使用方式

之後做星盤或星骰時，依照問題類型引用：

| 問題類型 | 優先參考 |
|---|---|
| 感情、依附、安全感 | 動機與人格 |
| 事業壓力、責任、紀律 | 沉思錄 |
| 潛意識、逃避、投射 | 動機與人格、星骰心理補強 |
| 土星課題、人生修煉 | 沉思錄 |
| 神祕學與心理整合 | 星骰心理補強 |

## 整理原則

1. 不逐字搬書籍原文。
2. 以學習筆記、關鍵概念、解讀框架為主。
3. 每個概念都要能回到星盤或星骰應用。
4. 避免變成純讀書心得，要整理成可查詢、可套用的資料。
5. 之後若整理書中章節，需標明來源書名與主題。
