## 一、新月圖與滿月圖的定位

新月圖與滿月圖可視為短期流年工具，常用來觀察一段時間內事件的開始、發展、完成、分享與收束。

```text
新月 = 開始、播種、啟動、吸收
滿月 = 完成、顯現、分享、結果
```

書中提醒：新月、滿月圖和日蝕、月蝕圖都可視為一種「階段圖」，與行星過運圖一樣，需要放回本命盤中觀察。

---

## 二、新月圖的基本意義

新月象徵事物開始。

可觀察：

```text
當月新開啟的主題
需要吸收與學習的新經驗
準備開始但尚未成熟的事情
未來一段時間要培養的方向
```

### 解讀提醒

```text
新月影響可從新月前一週開始，延續到下一次新月前。
新月圖需要與本命盤合看，不能只單獨看新月盤。
若新月落入本命某宮，該宮主題會成為當月啟動點。
若新月與本命行星形成重要相位，該行星主題被啟動。
```

---

## 三、滿月圖的基本意義

滿月象徵事物成熟、顯現、分享與結果。

可觀察：

```text
某件事的完成或開花結果
需要與他人分享的成果
需要補足、修正或平衡的關係議題
階段性告一段落的事情
```

### 解讀提醒

```text
滿月影響可從滿月前一週開始，延續到下一次滿月前。
滿月常讓事情被看見，也可能讓壓抑或未處理的主題浮上檯面。
滿月與本命盤形成重要相位時，容易帶來較明顯的關係、情緒或事件顯化。
```

## 四、新月／滿月圖的合盤觀察

解讀新月、滿月圖時，可觀察：

```text
1. 新月或滿月落入本命哪一宮。
2. 太陽、月亮分別落入哪些本命宮位。
3. 新月／滿月是否與本命行星合相、對分、四分。
4. 新月／滿月是否落在本命空宮，並因此替該宮帶來短期焦點。
5. 新月／滿月圖中是否有本命上升、天頂、下降、天底附近的行星。
6. 是否與行星過運、推運、太陽回歸中的重複主題相呼應。
```

## 六、日蝕與月蝕圖

日蝕、月蝕可視為放大版的新月與滿月。它們不只顯示短期情緒，也可能代表較長階段的轉折。

### 日蝕

```text
日蝕類似新月，但強度更大。
可看作新的開始、吸收、新方向與強烈啟動。
北交點日蝕更偏向吸收、前進、取得、開始。
```

### 月蝕

```text
月蝕類似滿月，但強度更大。
可看作顯現、完成、釋放、回報或付出代價。
南交點月蝕更偏向釋放、消化、放下、結束。
```

## 七、北交／南交的補充框架

掃描頁中提到北交與南交的象徵：

```text
北交點：龍頭／Rahu，吸收、吞入、未來方向、精神渴望。
南交點：龍尾／Ketu，習慣、釋放、消化、過去累積。
```

應用時可用：

```text
北交日蝕：新的欲望與方向被打開。
南交日蝕：舊有模式需要被釋放，才能迎接新開始。
北交月蝕：某個關係或事件的成果顯現，並推向未來。
南交月蝕：某個階段成熟後需要放下、交付或結束。
```

## 八、解讀句型

```text
這次新月落在你本命第＿＿宮，代表這個月的新開始會集中在＿＿領域。
```

```text
這次滿月落在＿＿宮／＿＿宮軸線，代表你需要看見兩個生活領域之間的平衡。
```

```text
日蝕像是強化版新月，代表某個新方向被打開，但未必立刻成熟。
```

```text
月蝕像是強化版滿月，代表某個議題浮出水面，需要完成、釋放或重新分配能量。
```

```text
若這次新月、滿月或蝕相重複觸及推運、行運、太陽回歸中的同一主題，該主題可信度提高。
```

## 九、暫定使用原則

1. 新月看開始，滿月看顯現與完成。
2. 日蝕、月蝕不宜只看單次事件，要看較長週期的轉折。
3. 新月、滿月、日月蝕都要與本命盤合看。
4. 若落入本命空宮，也可能替該宮帶來短期焦點。
5. 最有力的訊號，是月相／蝕相與回歸圖、行運、推運都指向同一主題。
6. 影響時間需保留彈性；掃描頁提到日蝕與月蝕有較長影響，但具體期限待後續查證補強。
