# 綜合流年解析 SOP

> 來源：使用者提供之《占星流年》多份 PDF 二次整理。  
> 用途：之後進行流年、推運、回歸、行運、月相與日月蝕解析時，統一使用這份流程。

---

## 一、總原則

```text
不要單看一個技法。
不要直接預言結果。
不要離開本命盤。
先看主題，再看時間，再看當事人可以怎麼回應。
```

---

## 二、第一層：本命盤底圖

先確認本命盤是否具備該主題。

```text
1. 本命行星、宮位、宮主星是否有相關結構？
2. 本命盤是否已有該類事件或心理模式的可能性？
3. 該主題是人生核心議題，還是短期觸發？
4. 是否有重複出現的宮位或相位？
```

解讀原則：

```text
本命盤是地基；流年是啟動時間。
本命盤沒有的東西，不因流年突然完全無中生有。
```

---

## 三、第二層：長期發展技法

用推運與太陽弧看生命主軸。

```text
二次推運：內在成熟、心理節奏、情緒與人格方向。
太陽弧正向推運：人生事件、時間校正、重大轉折。
一次推運／小限法：傳統技法，可作補充。
```

判斷問題：

```text
這是短期事件，還是人生階段轉換？
內在態度是否正在變？
太陽、月亮、上升、天頂或重要行星是否被推運觸及？
```

---

## 四、第三層：年度舞台

用太陽回歸圖看年度主題。

```text
1. 太陽回歸上升與第一宮：今年怎麼面對世界？
2. 上升守護星落宮：今年生活重點導向哪裡？
3. 太陽落宮：今年自我與生命力集中在哪裡？
4. 星群：三顆以上行星落同一宮時，該宮為年度重點。
5. 四角合相：上升、天頂、下降、天底附近行星要優先看。
6. 與本命盤合盤：太陽回歸行星落入本命哪一宮？
```

---

## 五、第四層：行星過運壓力

用行運看外在環境與時間壓力。

```text
木星、土星：社會性成長、責任、擴張與壓力。
天王、海王、冥王：長期變化、瓦解、理想化、自由、深層轉化。
火星以內：短期事件、情緒與行動觸發。
```

判斷問題：

```text
慢行星是否與本命行星／上升／天頂形成合相、四分、對分？
是否有行星逆行導致同一相位反覆發生？
慢行星是否換宮，改變長期人生主題？
```

---

## 六、第五層：觸發時間

當長期主題已存在時，用快速行星找明顯時間點。

```text
太陽：照亮該主題。
月亮：情緒與事件日觸發。
水星：訊息、文件、溝通觸發。
金星：關係、金錢、價值感觸發。
火星：行動、衝突、急迫事件觸發。
```

觸發公式：

```text
慢行星長期相位 + 快速行星經過同度數 = 事件容易浮現
```

---

## 七、第六層：新月、滿月、日月蝕

```text
新月：開始、播種、吸收。
滿月：顯現、完成、分享。
日蝕：放大版新月，較強的新方向或啟動。
月蝕：放大版滿月，較強的顯現、釋放或結束。
```

用法：

```text
1. 看月相／蝕相落入本命哪一宮。
2. 看是否與本命日月、上升、天頂、個人行星形成強相位。
3. 看是否與太陽回歸、推運、行運重複同一主題。
```

---

## 八、綜合判斷可信度

| 訊號層級 | 可信度 |
|---|---|
| 只有單一行運 | 低，需保守說明 |
| 行運 + 本命盤有相同主題 | 中 |
| 推運／太陽弧 + 行運同時指向 | 中高 |
| 太陽回歸 + 推運 + 行運重複同一宮位／行星 | 高 |
| 上述再被新月、滿月、日月蝕或快速行星觸發 | 事件時間更明顯 |

---

## 九、輸出解析建議格式

```text
1. 目前被啟動的主題：
2. 本命盤中的根源：
3. 長期技法顯示的發展：
4. 年度舞台：
5. 行運壓力：
6. 觸發時間窗口：
7. 當事人可以做的事：
8. 不宜過度斷定的部分：
```

---

## 十、解讀句型

```text
這個主題不是突然發生，而是本命盤原有結構在這段時間被啟動。
```

```text
推運顯示內在已經轉向；行運則提供外在事件或壓力的時間點。
```

```text
太陽回歸圖把＿＿宮主題放到年度舞台，因此這一年容易圍繞＿＿展開。
```

```text
這次新月／滿月／蝕相與同一主題呼應，代表事件可能在這段時間更明顯。
```

```text
這不是絕對命定，而是提醒你在哪個領域需要準備、回應或主動創造條件。
```

---

## 十一、暫定使用原則

1. 流年解析至少要有本命盤與一種時間技法交叉。
2. 涉及重大人生決策時，不用單一行運斷結果。
3. 吉凶都要轉成可行動建議。
4. 若資料不足，明確說「目前只能看到傾向，不能斷定結果」。
5. 解析越重大，越需要：本命盤 + 推運／太陽弧 + 太陽回歸 + 行運觸發 + 月相／蝕相。
