# 流年預測倫理與技法總覽

> 來源：使用者提供之《占星流年》第一章與相關頁面。  
> 二次篩選狀態：已保留方法論與解析倫理；細部案例不納入正式筆記。

---

## 一、核心觀念

### 1. 預測不是替人決定人生

本書強調，現代占星的流年解析不應走向僵硬宿命論。占星師可以分析趨勢、可能性與事件對當事人的影響，但不應替當事人作決定。

可用在資料庫中的核心原則是：

```text
占星師負責指出趨勢與可能性；當事人保留選擇與行動權。
```

---

### 2. Forecast 比 Predict 更適合現代占星

流年判讀更像天氣預報：

```text
會有什麼壓力？
哪個領域開始變化？
哪個時間點容易被觸發？
當事人可以如何準備？
```

而不是：

```text
一定會發生什麼。
你只能照命盤走。
你不需要選擇。
```

---

### 3. 事件需要轉化成「可行動建議」

例如命盤或流年出現感情機會時，不應直接說「一定會結婚」。比較成熟的說法是：

```text
這段時間有較高的關係機會。
若當事人已有互動對象，關係可能推進。
若當事人沒有對象，則需要增加互動與社交，讓象徵有現實出口。
```

---

### 4. 本命盤是流年判斷的底圖

流年不是從天而降的單獨事件。流年象徵能不能實際發生，要先看本命盤是否有相關結構。

```text
本命盤 = 可發生主題的基礎
流年技法 = 何時被啟動
當事人行動 = 如何實際落地
```

---

## 二、流年判讀的倫理底線

| 不建議 | 建議 |
|---|---|
| 斷言一定會結婚、分手、死亡、發財 | 說明可能性與時間窗口 |
| 替當事人決定是否換工作、結婚、分手 | 描述該選擇牽涉的壓力、機會與風險 |
| 用單一流年象徵下結論 | 回到本命盤、推運、回歸、行運交叉驗證 |
| 用恐嚇式語言製造依賴 | 提供準備方向與行動提醒 |
| 把吉象理解為不需努力 | 說明機會需要現實行動承接 |

## 三、常用預測技法地圖

### 傳統流年技法

```text
一次推運／一次正向推運：觀察較重大的人生階段。
小限法：透過年齡找出該年強調的宮位，常搭配行運與太陽回歸。
法達星限：傳統技法，可與其他預測方式整合。
```

### 現代常用技法

```text
二次推運：用出生後一天象徵出生後一年，常看內在心理與生命主軸的演化。
太陽弧正向推運：用太陽推進的度數推動整張盤，常用於人生事件與時間校正。
行星過運：觀察行運星與本命盤互動，適合看壓力、觸發與時間窗口。
回歸圖：太陽回歸、月亮回歸、土星回歸等，觀察週期重新開啟。
新月／滿月圖：看階段性的開始、完成、分享與收束。
日蝕／月蝕圖：放大版的新月／滿月，通常牽涉較強的階段轉折。
```

## 四、判斷某個象徵是否能成為事件

不直接用「看到象徵 = 一定事件」。建議依下列順序篩選：

```text
1. 本命盤是否有此主題？
2. 推運或太陽弧是否也碰到同一主題？
3. 太陽回歸是否把此主題放到年度舞台？
4. 行星過運是否正在啟動本命或推運結構？
5. 內行星或月亮是否形成短期觸發？
6. 現實生活是否有對應條件？
7. 當事人是否願意採取相應行動？
```

---

## 五、可直接用於解析的句型

```text
這個流年象徵比較像是一個機會窗口，不是保證事件一定發生。
```

```text
本命盤若已有相關主題，這次流年會比較像是啟動；若本命盤沒有，則可能只是短暫感受或旁觀他人事件。
```

```text
這段時間適合留意某個領域的變化，但決定權仍在當事人手上。
```

```text
這不是要你被命運推著走，而是提醒你在哪裡需要準備、調整或主動回應。
```

## 六、與星骰／命盤解析的整合

星骰若問未來趨勢，不要直接把骰象當成確定事件。可套用本章的預測倫理：

```text
行星 = 這次被啟動的力量
星座 = 這股力量的表現方式
宮位 = 事件可能落入的人生領域
提問背景 = 現實可落地條件
當事人行動 = 象徵是否真正實現
```

---

## 七、使用提醒

1. 流年不是用來取代當事人的選擇。
2. 吉象需要行動承接；凶象也可用準備與調整降低衝擊。
3. 單一象徵只代表可能性，不代表完整結論。
4. 預測應該是「提醒」，不是「控制」。
5. 越涉及人生選擇，越要保留自由意志與客觀語氣。
