# 行運相位解析卡：月亮、火星、天王、海王、冥王

> 來源：使用者提供之《占星流年》補充掃描頁：`星盤補充-3.pdf`、`星盤補充-4.pdf`、`星盤補充-5.pdf`。  
> 用途：建立流年相位的速查型解析卡，供後續星盤流年與事件觸發判斷使用。  
> 整理原則：只整理可轉成穩定解讀的概念，不逐字搬運原文；掃描頁無法完整辨識處保留為待補強。

---

## 一、相位解析總公式

```text
行運／推運行星 = 此階段被啟動的力量
本命行星 = 原本人格與生命主題
相位類型 = 互動方式
宮位 = 發生場域
星座 = 表現風格
```

解讀時不要只說「某星合某星會發生什麼」，而要整合：

```text
這個力量啟動了哪個本命議題？
它在哪個宮位發生？
是短期觸發，還是長期背景？
本命盤原本是否已有類似相位或主題？
柔和相位是自然流動，還是過度放鬆？
強硬相位是壓力，還是推動改變的力量？
```

## 二、月亮相位卡

### 關鍵字

```text
情緒、不安、需求、安全感、日常習慣、潛意識、母親、女性、伴侶情緒互動
```

### 合相

```text
新的情緒循環開始。
需要被安撫、被理解，無意識累積的感受容易浮現。
```

### 柔和相位

```text
心靈較平靜，與家人、女性、伴侶互動較順。
適合安撫他人、回到熟悉環境、整理情緒。
```

### 強硬相位

```text
情緒需求衝突，容易與親近的人起爭執。
需注意負面情緒、溝通語氣、情緒化投射。
```

### 解讀提醒

月亮相位多半先從「感受」開始，不一定立刻是大事件。行運月亮時間短，推運月亮時間長。

## 三、火星相位卡

### 關鍵字

```text
行動、衝動、慾望、競爭、攻擊、防衛、身體能量、急迫感
```

### 合相

```text
能量被點燃，容易急著行動。
可能帶來動力，也可能變成衝動、爭執或身體過度消耗。
```

### 柔和相位

```text
行動力較容易被引導。
適合運動、執行計畫、處理需要勇氣與效率的事。
```

### 強硬相位

```text
壓力、衝突、急躁、受傷風險增加。
要避免把不安直接變成攻擊，也要注意過度勉強身體。
```

### 解讀提醒

火星相位要給出口。不能只叫當事人忍耐，而要建議他把能量放進安全、具體、有方向的行動中。

## 四、天王星相位卡

### 關鍵字

```text
突變、解放、自由、反叛、意外、創新、覺醒、打破慣性
```

### 合相

```text
某個本命主題被強烈喚醒。
人會突然想改變、想跳脫舊規則，或遇到外界變動迫使自己更新。
```

### 柔和相位

```text
較容易接受新方法、新朋友、新生活模式。
能把改變用比較順的方式導入生活。
```

### 強硬相位

```text
原本壓抑的自由需求被強迫打開。
可能出現突發事件、關係或生活節奏斷裂，也可能是內在忍耐到臨界點。
```

### 解讀提醒

天王星不是單純災難，而是舊系統不能再維持時的「斷電重啟」。要問：哪裡需要自由？哪個模式已經太僵硬？

## 五、海王星相位卡

### 關鍵字

```text
模糊、理想、失落、幻滅、靈性、藝術、慈悲、逃避、犧牲、邊界溶解
```

### 合相

```text
某個本命主題被理想化或溶解。
可能出現靈感、藝術性、信仰感，也可能感到迷惘、不確定、失去方向。
```

### 柔和相位

```text
較容易以柔軟、想像、靈性或藝術方式處理問題。
適合創作、療癒、冥想、同理，但仍需保留現實檢查。
```

### 強硬相位

```text
容易逃避、投射、失望、看不清真相。
關係、工作、信念或自我認同可能因過度理想化而產生幻滅。
```

### 解讀提醒

海王星相位要特別檢查：這是直覺還是幻想？這是慈悲還是犧牲？這是愛還是投射？

---

## 六、冥王星相位卡

### 關鍵字

```text
深層轉化、權力、控制、危機、陰影、慾望、恐懼、死亡與重生
```

### 合相

```text
某個本命主題被推到深層轉化的位置。
可能感到壓力變大，也可能發現自己真正的慾望與力量。
```

### 柔和相位

```text
深層力量較容易被整合。
適合心理治療、研究、清理舊模式、重新掌握生命方向。
```

### 強硬相位

```text
權力拉扯、控制與失控、關係衝突、內在恐懼浮現。
人可能被迫面對原本不想承認的陰影。
```

### 解讀提醒

冥王星相位不宜只說「倒楣」。它通常是舊結構必須瓦解，讓更真實的生命力重新長出來。

---

## 七、柔和相位與強硬相位的二次判斷

### 柔和相位

```text
不是一定好，而是能量較容易流動。
可能帶來機會，也可能讓人太舒服、太放鬆、沒有意識到需要調整。
```

### 強硬相位

```text
不是一定壞，而是衝突較明顯。
它讓問題不能再被忽視，常是行動、轉折、修正與成長的壓力來源。
```

## 八、解讀 SOP

```text
1. 確認行星：是哪一種力量被啟動？
2. 確認本命行星：它觸動了人格中的哪個核心功能？
3. 確認相位：合相、柔和、強硬、150 度？
4. 確認宮位：發生在哪個生活場域？
5. 確認時間層級：月亮／內行星短期，木土中期，三王星長期。
6. 檢查本命盤是否已有同類主題。
7. 轉成心理狀態、事件可能性、行動建議。
```

---

## 九、可直接套用的句型

```text
這個相位不是直接替你決定事件，而是啟動你本命盤裡某個原本存在的主題。
柔和相位代表比較容易流動，但仍要看你是否有意識地使用它。
強硬相位代表壓力明顯，但也可能是推動你改變的關鍵。
天王星要你打破舊模式。
海王星要你辨認理想與幻覺。
冥王星要你面對真正的控制、恐懼與欲望。
火星要你把不安轉成行動，而不是衝突。
月亮要你先看見自己的安全感需求。
```
