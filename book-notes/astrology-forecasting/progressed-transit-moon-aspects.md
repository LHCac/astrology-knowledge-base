# 推運／行星過運月亮與本命行星相位

> 來源：使用者提供之《占星流年》補充掃描頁：`星盤補充-3.pdf`。  
> 用途：補強流年解析中「月亮作為情緒、需求、安全感與觸發點」的判讀能力。  
> 整理原則：僅整理可清楚辨識的月亮相位段落；不逐字搬運原書。

---

## 一、月亮在流年判讀中的定位

月亮象徵：

```text
情緒
不安
需求
安全感
日常習慣
無意識與潛意識反應
母親與女性關係
伴侶關係中的情緒互動
童年經驗留下的心理反應
```

因此，流年、推運或太陽弧中的月亮，常不是單純事件，而是：

```text
我現在被什麼情緒牽動？
我需要什麼安全感？
我對誰有依賴、期待或不滿？
我是否把童年需求投射到現在的人際關係？
```

## 二、月亮與本命月亮

### 合相：新的情緒循環

月亮與本命月亮合相時，可以視為新的月亮循環開始。

```text
推運月亮回到本命月亮：約 28 歲左右的重要情緒週期。
行運月亮回到本命月亮：月亮回歸，較短期的情緒狀態重啟。
```

可能表現：

```text
情緒變敏銳
需要安撫
無意識累積的能量浮出
想尋找安全、安寧、慰藉
對環境與人際氣氛變得更敏感
```

### 柔和相位：舒適與安撫

六分相、三分相常帶來較溫暖、平靜、舒適的心靈狀態。

可能表現：

```text
與家人、女性、伴侶互動較順
能理解與安撫他人
容易想起美好回憶
舊環境、老朋友、熟悉事物帶來安全感
```

### 強硬相位：情緒需求衝突

四分相、對分相容易讓月亮需求變得強烈，生活中同時出現多種需求，讓人有疲於奔命或魚與熊掌不可兼得的感受。

可能表現：

```text
情緒起伏
與親人、伴侶、女性朋友發生情緒化爭執
容易說出傷害關係的話
感到不滿、失望或不被照顧
很難注意到別人的需求
```

150 度相位可留意心靈盲點：人可能不正視眼前問題，而改用犧牲、補償或逃避方式處理壓力。

## 三、月亮與本命水星

### 核心意義

月亮與水星相位時，情緒會影響思考與溝通。

```text
水星 = 思考、語言、判斷、溝通。
月亮 = 情緒、需求、安全感、過去記憶。
```

合相時，人的思考出發點常和基本需求、安全感、童年不安或生活習慣有關。

### 可能表現

```text
變得感性
容易同理
適合抒發心情、寫作、創作、學習溝通
但也容易過度解讀他人的話
較難保持完全理性
可能把情緒或不滿怪罪到別人身上
```

### 柔和相位

柔和相位使理性與感性比較容易協調。

可能表現：

```text
適合聊天、交換意見、與朋友或兄弟姊妹互動
容易表達內在情感
能透過溝通釐清心中渴望
適合自我理解與心理整理
```

### 強硬相位

強硬相位時，理智與情緒容易打架。

可能表現：

```text
鑽牛角尖
溝通帶火藥味
說話變刻薄或批評
理智知道一件事，情緒卻無法接受
想被理解，但表達方式反而讓別人退開
```

解讀提醒：這不是「不能溝通」，而是溝通前要先承認自己的情緒需求。

---

## 四、月亮與本命金星

### 核心意義

金星可以調和月亮的不安，使情緒需求比較容易透過愛、美感、社交、享樂、交換與關係滿足。

```text
月亮 = 我需要什麼安全感。
金星 = 我如何感到愉悅、被喜歡、被調和。
```

### 合相

可能表現：

```text
心情愉快
女性關係和諧
情愛氣氛變浪漫
願意用柔和態度交換需求
適合聚會、美食、居家布置、藝術與社交
容易出現美好戀情或愉快時光
```

### 柔和相位

柔和相位有利友情、愛情、親情。

可能表現：

```text
與朋友、情人互動更密切
容易散發魅力
不刻意也讓人覺得舒服
與母親、女性、伴侶關係較和諧
適合約會、聚會、享受生活
```

### 強硬相位

月亮與金星的強硬相位通常不像火星那樣激烈，但容易帶來過度縱容。

可能表現：

```text
期待別人滿足自己
情緒上依賴他人
關係中予取予求
用甜言蜜語或交換條件掩蓋真正問題
暴飲暴食、消費過度、懶散
```

解讀提醒：金星會讓問題看起來沒那麼嚴重，但若一味縱容，日後仍會產生不滿。

## 五、月亮與本命火星

### 核心意義

月亮與火星相位時，情緒需求被火星刺激，容易急著行動、反應快速、脾氣變壞，或想立刻處理不安。

```text
月亮 = 安全感與無意識需求。
火星 = 行動、衝動、慾望、攻擊、防衛。
```

### 合相

可能表現：

```text
情緒受到刺激
興奮、坐立不安、反應快
脾氣急、沒耐性
關係過熱，容易爭執
也可能一起從事冒險、運動或親密活動
不適合在情緒高張時做重大決定
```

### 柔和相位

柔和相位能把刺激轉成行動力。

可能表現：

```text
適合運動、郊遊、競賽、整理環境
與朋友或伴侶一起做稍微刺激的活動
能把不安轉為具體行動
適合實現與日常、健康、生活改善有關的小計畫
```

### 強硬相位

強硬相位可能帶來情緒過熱與衝動反應。

可能表現：

```text
情緒大起大落
易怒、衝動、防衛
與人起衝突
覺得別人侵犯自己的安全感
急著行動，但結果未必理想
```

解讀提醒：此時最重要的不是壓抑火星，而是替火星找安全出口，例如運動、體力活動、清楚表達界線。

## 六、月亮相位的解析公式

```text
月亮相位 = 情緒需求被某顆行星啟動

月亮 × 月亮：安全感循環重啟
月亮 × 水星：情緒影響思考與溝通
月亮 × 金星：關係、愉悅、依賴與調和
月亮 × 火星：不安被刺激，轉為行動或衝突
```

---

## 七、解析提醒

1. 月亮相位不一定代表外在大事件，但一定會影響感受。
2. 行運月亮作用短，推運月亮作用長。
3. 柔和相位不是完全沒問題，可能讓人過度舒服或懶散。
4. 強硬相位不是一定壞，而是需求衝突更明顯。
5. 月亮相位解讀要特別看：安全感、母親／女性、伴侶、日常生活與童年情緒。
6. 情緒被觸發時，不宜直接替當事人下決定，應引導他看見自己的需求。

---

## 八、可直接套用的解讀句

```text
這段時間不是只有事件在發生，更像是某個情緒需求被打開。
你現在的反應可能不是單純針對眼前的人，而是過去某種安全感需求被觸動。
月亮與水星的相位提醒你：先整理情緒，再溝通。
月亮與金星的相位提醒你：分辨愛、依賴、享樂與真正的滿足。
月亮與火星的相位提醒你：把不安轉成健康行動，而不是衝動攻擊。
```
