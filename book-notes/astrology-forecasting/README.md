## 核心原則

```text
流年不是單點預言，而是多層技法交叉驗證。
本命盤是底圖；推運與太陽弧看人生主軸；回歸圖看年度／月度舞台；行星過運看時間壓力與觸發；新月滿月與日月蝕看階段開合。
```

---

## 解析時的基本順序

```text
1. 先回到本命盤：本命盤沒有的主題，不宜只靠流年硬判。
2. 看長期技法：二次推運、太陽弧、重要生命週期。
3. 看年度舞台：太陽回歸圖與本命盤合盤。
4. 看行運壓力：外行星、木星、土星與本命點的長期互動。
5. 看觸發時間：太陽、月亮、水星、金星、火星經過關鍵度數。
6. 看月相／蝕相：新月、滿月、日蝕、月蝕提供階段性的開始、完成、釋放與轉折。
7. 最後輸出：可能性、主題、時間窗口、當事人可採取的行動。
```

## 暫定使用原則

1. 不做絕對宿命論判斷。
2. 不用單一流年象徵直接下結論。
3. 每個流年事件都要先回到本命盤檢查。
4. 外行星看長期壓力與環境變化；內行星多用來看觸發時間。
5. 回歸圖、推運、行運、月相／蝕相要互相驗證。
6. 對涉及選擇的問題，回到「提醒與建議」，不要替當事人決定。
