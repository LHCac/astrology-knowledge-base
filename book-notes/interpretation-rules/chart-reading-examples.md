# 解盤範例整理：從宮位、宮主星到事業與關係判讀

> 來源：使用者提供之《書籍 2026年5月24日 (1)(1).pdf》頁 414–429。本文為學習筆記與解讀流程整理，不逐字搬運原書內容。

## 核心觀念

本章的重點不是單純列出每顆行星的意思，而是示範如何把：

```text
宮位主題 + 宮主星位置 + 宮內星 + 相位 + 年齡階段 + 生活事件
```

整合成一段完整的命盤解讀。

書中範例特別強調：

- 剛出社會或工作方式可看第六宮。
- 四十歲後或人生事業定位可看第十宮。
- 深層療癒、心理、神祕學與危機處理可看第八宮、第十二宮。
- 群體定位、人脈、社會評價與分眾眼光可看第十一宮。
- 婚姻與合作的轉向可看第七宮與其宮主星。

## 範例一：從工作到事業——體制內的療癒者

### 命盤重點

此案例上升雙魚，天頂射手。命盤中可見第八宮、第九宮、第十宮、第十二宮的連動，呈現出療癒、神祕學、專業認證與社會服務的主題。

關鍵配置包含：

- 木星在雙魚十二宮。
- 金星天蠍與冥王星有強連結。
- 太陽與土星合相。
- 月亮在摩羯十宮。
- 八宮、九宮、十二宮皆有重要能量。

### 解讀邏輯

第六宮代表剛出社會的工作方式，第十宮代表人生後期的事業定位。案例中，第十宮帶有射手與摩羯的成分，所以同時要看木星與土星。

木星在雙魚十二宮，帶有療癒、靈性、支持與幕後助人的特質。加上八宮冥王星與天蠍能量，表示此人適合處理深層心理、醫療社工、催眠、古典占星或身心靈療癒等領域。

太陽土星合相代表自律、嚴格、責任感與制度性；月亮在摩羯十宮則讓情緒表達穩定，能在面對他人痛苦時保持專業，不容易被悲劇壓垮。

### 解讀提醒

這個案例的重點是：水象宮位帶來共感與療癒能力，摩羯與土星則提供界線與專業框架。若只有水象，容易被情緒淹沒；若只有土星，則可能太冷。兩者結合，才能成為穩定的療癒者。

### 可學習的解盤技巧

```text
1. 先看第六宮，判斷早期工作型態。
2. 再看第十宮，判斷人生事業定位。
3. 若第八宮、第十二宮強，加入心理、療癒、神祕學、危機處理等主題。
4. 若土星、摩羯、十宮強，表示需要專業證照、制度或社會認證。
5. 若水象宮位強，則要判斷共感能力是否能落地為專業。
```

## 範例二：整合事業版圖——十一宮群星的分眾定位

### 命盤重點

此案例上升天蠍，天頂獅子。命盤中十一宮群星明顯，並且與第六宮、第十宮形成工作到事業的連結。

關鍵配置包含：

- 第六宮在牡羊，宮主星火星落十一宮。
- 第十一宮有群星，且多與人際、分眾、形象定位有關。
- 天頂獅子，宮主星太陽落十一宮。
- 水星天蠍帶來敏銳觀察力。
- 金星天秤與社交、美感、商業形象有關。

### 解讀邏輯

第六宮代表早期工作方式。第六宮牡羊的宮主星火星落十一宮，表示工作雖然從具體現場開始，但真正的發展會往十一宮走：人脈、群體、社群、分眾、形象與更高層次的社會定位。

十一宮雖常被簡化為朋友宮，但在此範例中，它更像是「社會評價、理想形象、分眾定位與經紀眼光」。十一宮強的人可能能看見他人特質，替不同的人安排合適位置，像伯樂、經紀人、品牌定位者。

水星天蠍帶來敏銳洞察，能看出人的本質與適合的場域；金星天秤則與美感、社交、形象包裝、商業服務有關。因此此命盤可延伸到經紀、醫美業務、自媒體、分眾行銷、形象顧問等方向。

### 解讀提醒

十一宮不是單純「朋友很多」，而是能站在更高角度觀察群體與定位。此案例的重點是：個人不是直接站到舞台中央，而是懂得安排誰站在哪個舞台。

### 可學習的解盤技巧

```text
1. 看第六宮宮主星落在哪裡，判斷早期工作會導向哪個領域。
2. 看第十宮宮主星落在哪裡，判斷人生事業定位。
3. 若六宮主與十宮主都指向十一宮，表示人脈、社群、經紀、分眾定位很重要。
4. 若水星強，加入觀察、溝通、商業嗅覺。
5. 若金星強，加入美感、業務、人際與形象包裝。
```

## 範例三：婚姻帶來的人生轉向

### 命盤重點

此案例上升雙子，天頂雙魚。命盤重點落在第五宮戀愛、第七宮婚姻、第八宮衝擊，以及第十宮人生方向。

關鍵配置包含：

- 第五宮在天秤，宮主星金星落巨蟹二宮。
- 金星與火星合相，帶來高魅力與吸引力。
- 金火合相對沖第八宮的海王星與天王星。
- 第七宮射手，宮主星木星落摩羯七宮。
- 木星與太陽有和諧相位，但也與其他宮位形成壓力。

### 解讀邏輯

第五宮看戀愛，七宮看正式伴侶與婚姻。金火合相在二宮，表示個人魅力強，重視質感、安全感與物質條件，也容易吸引異性注意。

但金火合相對沖八宮的海王星與天王星，表示戀愛或追求者可能帶有不穩定、奇怪、模糊、不夠理想或不容易掌握的特質。這類配置容易吸引強烈但複雜的人際與感情經驗。

第七宮射手，宮主星木星在七宮，表示婚姻本身是人生重要轉向，有機會透過伴侶、婚姻或合作提升社會地位。木星摩羯則表示這個提升可能與責任、資產、制度、現實條件或長期磨合有關。

### 解讀提醒

此案例的核心不是單純「感情好不好」，而是婚姻如何改變人生結構。七宮宮主星在七宮，表示婚姻議題很強；木星帶來提升，但摩羯與相位壓力表示過程不會完全輕鬆。

### 可學習的解盤技巧

```text
1. 戀愛看第五宮，婚姻看第七宮。
2. 第五宮宮主星看戀愛品味與吸引類型。
3. 第七宮宮主星看婚姻走向與伴侶帶來的影響。
4. 八宮參與時，感情常牽涉深層依附、慾望、資源或不穩定因素。
5. 木星落七宮時，婚姻可能帶來提升，但仍要看相位與星座是否穩定。
```

## 解盤流程總結

### 1. 先分清楚工作、事業與人生定位

```text
第六宮 = 剛出社會、工作方式、職場日常
第十宮 = 人生成就、事業定位、社會角色
第十一宮 = 社會評價、群體定位、理想與人脈
```

不要把第六宮和第十宮混在一起。工作是你拿來生存的方式，事業是你被社會記住的定位。

### 2. 用宮主星追蹤事件走向

```text
宮位 = 問題發生的領域
宮主星 = 這個領域會走向哪裡
宮內星 = 這個領域內實際展現的能量
相位 = 能量是否順暢或有衝突
```

### 3. 用水象宮位判斷療癒與神祕學傾向

```text
第八宮 = 深層心理、創傷、禁忌、危機、轉化
第十二宮 = 潛意識、靈性、前世、慈悲、療癒
```

若八宮與十二宮強，再加上土星、十宮或九宮，就可能變成有制度、有證照、有專業框架的療癒工作。

### 4. 用十一宮判斷分眾與社群定位

十一宮不只是朋友，也可代表：

- 分眾定位
- 社群觀察
- 人脈經營
- 群體評價
- 經紀、平台、社會形象
- 更高層次的理想與定位

### 5. 用第五宮與第七宮區分戀愛與婚姻

```text
第五宮 = 戀愛、曖昧、吸引、享樂
第七宮 = 婚姻、正式伴侶、契約、合作
第八宮 = 親密、共享資源、深層依附
```

感情解讀時，不能只看金星。要分清楚是戀愛階段、婚姻階段，還是深層依附與資源交換。

## 小結

本章範例展示的是「整合式解盤」：不是把每顆行星分開解釋，而是用宮位與宮主星追蹤人生主題如何流動。真正有用的解盤，會把命盤配置和實際人生事件連起來，判斷一個人如何從工作走向事業、從關係走向人生轉向，或從創傷走向療癒天職。
