# 星盤架構分析與星骰占問 SOP

> 用途：之後進行個人星盤解析、主題式星盤判讀、星骰占問時，統一使用這份流程。  
> 原則：先定問題，再看結構；先看整體，再看細節；先用資料庫，再做個人化判斷。

---

# 一、星盤架構分析 SOP

## 0. 需要的基本資料

進行完整星盤分析前，先確認以下資料：

```text
姓名或代稱：
出生日期：YYYY/MM/DD
出生時間：HH:MM
出生地點：城市／國家
想問主題：整體、感情、事業、學業、財運、家庭、人際、健康、神祕學天賦等
是否要輸出 PDF：是／否
是否要存入 GitHub：是／否
```

若使用者已提供星盤截圖，優先從截圖整理：

```text
十大行星落入星座與宮位
上升與天頂
十二宮宮頭星座
宮主星落宮
主要相位
逆行狀態
```

## 2. 判斷命盤主軸

先看整體能量集中在哪裡。

### 2-1. 元素分布

```text
火象：牡羊、獅子、射手
土象：金牛、處女、摩羯
風象：雙子、天秤、水瓶
水象：巨蟹、天蠍、雙魚
```

判斷此人偏向：

```text
火多：行動、熱情、直覺、自我推動
土多：務實、穩定、累積、現實導向
風多：思考、溝通、社群、資訊導向
水多：情感、直覺、共感、心理導向
```

### 2-2. 三態分布

```text
開創：牡羊、巨蟹、天秤、摩羯
固定：金牛、獅子、天蠍、水瓶
變動：雙子、處女、射手、雙魚
```

判斷此人偏向：

```text
開創多：主動開始、帶頭、推動事件
固定多：穩定堅持、維持、不易改變
變動多：適應、轉換、多元、流動
```

### 2-3. 半球與象限

```text
上半盤強：外在成就、社會角色、公眾領域
下半盤強：家庭、內在、安全感、私領域
左半盤強：自我主導、獨立、靠自己
右半盤強：他人關係、合作、互動、外界牽動
```

## 3. 三大人格核心

先看個人的基本人格架構。

```text
太陽 = 自我核心、生命方向、意志
月亮 = 情緒需求、安全感、內在反應
上升 = 外在氣質、人生入口、面對世界的方式
```

解讀順序：

```text
1. 太陽星座：這個人想成為什麼樣的人
2. 太陽宮位：在哪個人生領域發光
3. 月亮星座：情緒如何反應
4. 月亮宮位：在哪裡尋找安全感
5. 上升星座：別人第一眼看到的樣子
6. 上升守護星落宮：人生主要導向哪個領域
```

輸出時避免只說星座個性，要組合成：

```text
行星 = 什麼能量
星座 = 如何表現
宮位 = 在哪個領域發生
相位 = 順暢或衝突
```

## 7. 宮主星追蹤法

每個主題都要追宮主星。

```text
宮位 = 問題發生的領域
宮頭星座 = 這個領域的風格
宮主星 = 這個領域的管理者
宮主星落宮 = 這件事最後導向哪裡
宮內星 = 這個領域中直接發生的能量
相位 = 順利或卡住
```

範例：

```text
七宮主星落十宮：伴侶／合作影響事業與社會地位
二宮主星落十一宮：收入來自社群、人脈、網路平台
六宮主星落十宮：工作逐漸變成事業
十二宮主星落九宮：靈性、夢境、潛意識導向神祕學或信仰研究
```

---

## 8. 相位判斷

先看主要相位：

```text
合相 0°：能量融合，強化該主題
六合 60°：機會、協調、可發展
四分 90°：壓力、衝突、需要行動調整
三分 120°：天賦、順暢、自然流動
對分 180°：拉扯、投射、關係中的平衡課題
```

解讀原則：

```text
1. 先看太陽、月亮、上升、天頂相關相位
2. 再看水星、金星、火星等個人行星相位
3. 再看木星、土星帶來的成長與壓力
4. 最後看三王星帶來的深層、突變與靈性議題
```

# 二、星骰占問 SOP

## 0. 問題設定

星骰一定要先確認問題。問題越清楚，解讀越準。

使用者應提供：

```text
問題：
抽到的行星：
抽到的星座：
抽到的宮位：
想問主題：感情／事業／學業／財運／人際／選擇／近期發展等
背景補充：可選
```

如果問題太模糊，先協助改寫。

不建議問題：

```text
我會怎樣？
他到底怎樣？
未來好不好？
```

建議改成：

```text
這段關係接下來一個月會如何發展？
我現在該不該主動聯絡對方？
這份工作目前適不適合繼續投入？
我現在最需要調整的是什麼？
```

---

## 1. 星骰三元素定位

星骰由三個部分組成：

```text
行星 = 事件核心／主角／動力
星座 = 表現方式／情緒色彩／態度
宮位 = 發生領域／問題場景／結果落點
```

解讀公式：

```text
這件事的核心能量是「行星」
它會用「星座」的方式表現
並且發生在「宮位」代表的生活領域
```

## 5. 三段式組合解讀

每次星骰先用三段式。

範例格式：

```text
行星：這件事的核心是什麼
星座：它會用什麼方式表現
宮位：它會在哪個領域發生
```

再組合成一句話：

```text
這次星骰表示：你問的事情，目前核心能量是＿＿，它會以＿＿的方式呈現，主要落在＿＿領域。
```

---

## 6. 正面、負面、建議三層解讀

星骰不能只說好或不好，要分三層：

```text
正面可能：這組骰子的優勢或機會
負面可能：這組骰子的風險或卡點
行動建議：現在最適合怎麼做
```

固定格式：

```text
正面：
負面：
建議：
```

```text

```

## 9. 星盤與星骰結合用法

若使用者有本命盤，可把星骰放回本命盤判斷。

流程：

```text
1. 先解星骰本身：行星、星座、宮位
2. 對照本命盤中該行星的位置
3. 對照本命盤中該星座落在哪一宮
4. 對照本命盤中該宮位的宮主星
5. 判斷這次星骰是否觸發本命盤主題
```

範例：

```text
星骰抽到：天王星・天蠍・第五宮
本命盤若天王星在九宮：問題可能不只是戀愛，也牽涉信念、遠方、學習或神祕學觀念的改變。
本命盤若第五宮宮主星落十宮：戀愛或創作可能影響公開形象或事業。
```

# 三、之後固定作業原則

## 星盤分析時

```text
先整理資料表
再抓命盤主軸
再看三大人格核心
再看主題宮位
再追宮主星
再整合相位
最後給結論與行動建議
```

## 星骰占問時

```text
先確認問題
再解行星
再解星座
再解宮位
再三者組合
再分正面、負面、建議
最後給明確行動方向
```

## 最重要原則

```text
星盤 = 結構性人生地圖
星骰 = 當下問題的象徵訊息
星盤看長期傾向
星骰看當下狀態與行動提示
兩者結合時，以星盤為底，星骰為觸發點
```
