# 相位資料庫

整理自 Notion 匯出的「相位」CSV。此檔補齊相位名稱、度數、容許度與能量互動說明。

| 名稱 | 度數 | 能量互動說明 |
|---|---|---|
| ☌ 合相 | 0° · 容許度 ±8° | 兩顆星能量完全融合，彼此強化。影響力最強，但界線模糊，有時分不清哪個是哪個。 |
| ☍ 對分相 | 180° · 容許度 ±8° | 兩股能量相互拉扯、對立。需要整合，若未整合則容易在兩個極端間擺盪。 |
| △ 三分相 | 120° · 容許度 ±8° | 能量流暢合作，是天賦與才能最自然流露的相位。太順了有時反而不自覺。 |
| □ 四分相 | 90° · 容許度 ±8° | 能量摩擦衝突，製造張力與壓力。痛苦但是最能推動成長的相位，是行動力的來源。 |
| ✶ 六分相 | 60° · 容許度 ±6° | 溫和的機遇相位，能量友好但需要主動激活。機會在那，但不會自動送上門。 |
| ⊼ 八分之三相 | 135° · 容許度 ±2° | 細微的摩擦感，像鞋子裡的小石頭，不嚴重但持續讓你不舒服，需要調整適應。 |
| ⊻ 十二分之五相 | 150° · 容許度 ±2° | 兩顆星彼此「看不順眼」卻又要共存。需要持續調整，帶來一種慢性的不協調感。 |
