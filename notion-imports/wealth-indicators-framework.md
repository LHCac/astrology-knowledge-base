# Wealth Indicators in Natal Chart｜星盤財富判斷框架

整理自 Notion「看星盤判斷財富配置」筆記，已轉成 GitHub Markdown 知識庫格式。

## 核心邏輯

判斷財富不能只看單一位置，而要交叉觀察：

1. **第二宮**：自己賺的錢、財務能力、自我價值。
2. **第八宮**：他人資源、投資、共享財富、被動資源。
3. **木星與金星**：幸運擴展與豐盛感。
4. **土星**：財富累積是否需要長時間磨練。

## 第一層：第二宮｜自己賺的錢

第二宮是最直接的財富宮，主要看三件事：

1. 第二宮宮頭星座：賺錢風格。
2. 第二宮守護星落點：錢從哪個生活領域而來。
3. 第二宮內是否有星體：直接影響財務模式。

### 第二宮宮頭星座：賺錢風格

| 宮頭星座 | 賺錢風格 |
|---|---|
| 牡羊 | 主動出擊，靠行動力與開創賺錢 |
| 金牛 | 穩健積累，重視長期安全與複利 |
| 雙子 | 多元靈活，不執著單一收入來源 |
| 巨蟹 | 情感與安全感驅動，靠直覺與關係流動 |
| 獅子 | 靠才華、表現、被看見來賺錢 |
| 處女 | 靠技術、細節、服務與專業度賺錢 |
| 天秤 | 靠合作、關係、美感與協調賺錢 |
| 天蠍 | 靠深度、資源整合、隱性資源賺錢 |
| 射手 | 靠視野、教育、旅行、冒險與拓展賺錢 |
| 摩羯 | 靠長期累積、責任感、制度與成就賺錢 |
| 水瓶 | 靠創新、獨特性、科技或非傳統方式賺錢 |
| 雙魚 | 靠靈感、藝術、療癒、感受力賺錢，但波動性較高 |

### 第二宮守護星落點：錢從哪裡來

| 守護星落在 | 解讀方向 |
|---|---|
| 第一宮 | 靠個人品牌、個人特質、自我形象賺錢 |
| 第三宮 | 靠溝通、寫作、教學、資訊、表達賺錢 |
| 第六宮 | 靠日常工作、服務、技能、職場穩定輸出賺錢 |
| 第八宮 | 靠投資、他人資源、合作資源、共享財務賺錢 |
| 第十宮 | 靠事業成就、職涯高度、社會地位賺錢 |
| 第十一宮 | 靠社群、人脈、團體、網路資源賺錢 |

### 第二宮有星體：直接影響財務模式

| 星體 | 財務含義 |
|---|---|
| 木星 | 財運擴展，容易放大資源與收入機會 |
| 金星 | 財富流動較順，與美感、關係、享受相關 |
| 太陽 | 自我認同與財富連動，越活出自己越容易帶財 |
| 月亮 | 財務容易受情緒與安全感影響 |
| 土星 | 先苦後甜，需要努力累積，但可建立穩固財務 |
| 天王星 | 收入跳躍不穩定，可能有意外財或突發變化 |
| 海王星 | 財務邊界模糊，需留意幻想、信任與不清楚的帳目 |
| 冥王星 | 財富起伏大，但有深層累積與資源掌控潛力 |

## 第二層：第八宮｜他人資源與被動收入

第八宮觀察的是：別人的資源是否會流向自己，以及自己如何處理共享財務。

觀察重點：

| 觀察項目 | 說明 |
|---|---|
| 第八宮宮頭星座 | 深層資源的風格與氛圍 |
| 第八宮守護星 | 他人資源從哪個領域被引動 |
| 第八宮落入星體 | 直接帶入共享資源、投資、親密與轉化議題 |

### 第八宮強配置

- 木星在第八宮：他人資源豐厚，容易得到外部資源或投資機會。
- 金星在第八宮：關係、合作、伴侶或人際連結可能帶來資源。
- 第八宮守護星狀態良好：共享資源流動較穩定。

### 第八宮需留意配置

- 海王星在第八宮：共有財務、投資、借貸、合夥要保持清楚界線。
- 土星在第八宮：他人資源來得慢，需要信任、責任與長期經營。
- 冥王星在第八宮：資源議題強烈，可能伴隨控制、權力或深層轉化。

## 第三層：木星與金星

### 木星：幸運與擴展方向

木星落在哪裡，代表哪個領域比較容易擴張、得到機會或產生信念感。

| 木星位置 | 財運方向 |
|---|---|
| 第二宮 | 傳統意義上的財運加持，收入與資源容易擴大 |
| 第八宮 | 他人資源、投資、共享財務有擴展機會 |
| 第一宮 | 個人魅力、人格特質本身帶來機會 |
| 第十宮 | 事業帶財，職涯成就與收入連動 |
| 第十一宮 | 社群、人脈、團隊、平台帶來財富 |

木星逆行時，幸運通常不是外部直接送上門，而是需要內在深耕、累積專業與信念。

### 金星：豐盛感與價值吸引力

| 金星狀態 | 說明 |
|---|---|
| 金星在金牛或天秤 | 入廟，金星能量自然、穩定，豐盛感較順 |
| 金星在雙魚 | 入旺，感受力、藝術性、吸引力強 |
| 金星在牡羊或天蠍 | 能量較不自然，需要主動爭取或學習平衡關係與價值 |

## 輔助指標：土星

土星與財富相關時，常表示「慢慢來、先苦後甜」。

常見表現：

- 年輕時財務壓力較大。
- 需要長期規劃與紀律。
- 建立後不容易失去。
- 越成熟越穩定。

土星在第二宮、第十宮，或與第二宮守護星有強關聯時，財富通常需要時間、責任和結構來累積。

## 快速判斷表

| 觀察位置 | 問題 |
|---|---|
| 第二宮宮頭星座 | 這個人用什麼風格賺錢？ |
| 第二宮守護星 | 錢從哪個生活領域來？ |
| 第二宮內星體 | 有沒有直接影響財務的星？ |
| 第八宮 | 是否有他人資源、投資、共享財富議題？ |
| 木星 | 哪個領域容易擴張與得到機會？ |
| 金星 | 豐盛感、吸引力、價值流動強不強？ |
| 土星 | 是快速獲得，還是需要慢慢累積？ |

## 命帶財常見特徵

多項符合時，財富配置較明顯：

- 木星在第二宮、第八宮、第一宮或第十宮。
- 金星狀態良好，例如入廟或入旺。
- 第二宮有木星、金星、太陽等加持。
- 第二宮守護星落在第二、第八、第十或第十一宮。
- 第八宮有強星，且守護星狀態良好。

## 需要努力才有財的特徵

- 土星在第二宮或第十宮。
- 木星逆行，需要向內深耕。
- 第二宮守護星落在第十二宮，財富模式不容易一開始就被自己意識到。

## 需要特別留意的配置

- 海王星在第二宮或第八宮：財務界線模糊。
- 天王星在第二宮：收入不穩定，忽高忽低。
- 冥王星在第二宮：財富起伏大，但有深層掌控與累積能力。

## 總結

看財富時，不要只看「有沒有木星」或「有沒有金星」。比較完整的方式是：

1. 先看第二宮的賺錢方式。
2. 再看第八宮的他人資源。
3. 接著看木星、金星是否加分。
4. 最後用土星判斷是否需要時間與紀律累積。
