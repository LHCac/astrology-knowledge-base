# Western Chart Reading Skill｜西洋星盤解讀框架

整理自 Notion「西洋星盤解讀 SKILL」筆記，已轉成 GitHub Markdown 知識庫格式。

## 使用情境

這份框架適合兩種情境：

1. **繼續學習占星**：用引導式方式練習自己解讀。
2. **幫別人做星盤解析**：直接輸出完整、清楚、有層次的解讀。

## 核心解讀框架：三層疊加法

每個宮位可以用三層來讀：

| 層次 | 說明 |
|---|---|
| 底色 | 宮頭星座，代表這個生活場域的氛圍與風格 |
| 守護星位置 | 宮頭星座的守護星落在哪裡，代表這個宮位從哪裡被驅動 |
| 現場員工 | 實際落入該宮位的星體，代表直接發生的能量 |

## 辦公室比喻

- **宮位**：辦公室，代表生活場景。
- **宮頭星座**：辦公室的裝潢風格與氣氛。
- **守護星**：辦公室主管，負責管理這個宮位。
- **守護星落入的宮位**：主管在哪裡遠端管理。
- **落入宮位的星體**：在現場工作的員工。

這個比喻很適合用來教學，因為能把抽象的星盤結構變成生活化畫面。

## 重要結構識別

### 守護星回駐／廟

守護星落回自己掌管的位置，象徵主管就在現場親自管理，能量集中且純粹。

### 互容

兩個宮位的守護星互換位置，形成彼此支援的封閉循環。可理解成兩個部門互相交換主管，彼此有強烈連動。

### 逆行

星體能量向內運作，不完全依靠外部機會，需要內在深耕與反覆整理。

### 星盤主星

上升星座的守護星，也就是整張星盤的重要基調，能看出一個人生命運作的核心方式。

## 相位系統

| 相位 | 角度 | 類型 | 感覺 |
|---|---:|---|---|
| 合相 | 0° | 能量融合 | 兩股能量融合，影響力強 |
| 六分相 | 60° | 機遇激活 | 溫和友好，需要主動使用 |
| 四分相 | 90° | 成長張力 | 摩擦衝突，痛苦但推動成長 |
| 三分相 | 120° | 天賦流暢 | 能量自然合作，不費力流露 |
| 八分之三相 | 135° | 持續調整 | 慢性小摩擦，需要反覆調整 |
| 十二分之五相 | 150° | 格格不入 | 兩者難以理解，需要持續磨合 |
| 對分相 | 180° | 能量拉扯 | 兩端對立，需要整合與平衡 |

## 相位解讀原則

1. 先識別兩顆星分別代表什麼驅動力。
2. 再看它們落在哪個宮位，也就是在哪些生活場景發生。
3. 最後判斷相位關係：融合、流暢、機會、摩擦、拉扯或格格不入。

## 幫別人做星盤解析的順序

1. 確認基本資料：上升、太陽、月亮。
2. 確認特殊結構：守護星回駐、互容、逆行、星盤主星。
3. 逐宮解讀：有星體的宮位優先，空宮追守護星。
4. 相位解析：先看影響大的主要相位，再補小相位。
5. 小天體與虛點補充：凱龍、南北交點、幸運點、莉莉斯等。

## 每個宮位的輸出格式

| 層次 | 內容 |
|---|---|
| 底色 | 宮頭星座與氛圍描述 |
| 守護星 | 守護星在哪個星座、哪個宮位，如何遠端管理 |
| 現場員工 | 該宮位內有哪些星體，或是否為空宮 |
| 解讀 | 將三層整合成白話說明 |
| 一句話總結 | 用一句話收束這個宮位的重點 |

## 學習占星的引導式教學方式

教學時可以採用：

1. 先讓學習者自己解讀。
2. 回應「說對的部分」。
3. 補充「需要補上的細節」。
4. 若有錯誤，直接指出並修正。
5. 每解完一個宮位，再引導下一宮。

可以用這個問題練習：

> 這個宮位的底色是什麼？守護星在哪裡？現場有沒有星體？

## 行星尊貴系統

| 等級 | 名稱 | 說明 |
|---|---|---|
| 最強 | 廟／Domicile | 行星在自己的星座 |
| 極強 | 旺／Exaltation | 行星在特定星座表現最佳 |
| 中等 | 三分性／Triplicity | 行星在同元素星座有加持 |
| 受阻 | 陷／Detriment | 行星在守護星座的對宮 |
| 最弱 | 弱／Fall | 行星在入旺星座的對宮 |

常見入旺對照：

- 太陽入旺：牡羊座
- 月亮入旺：金牛座
- 木星入旺：巨蟹座
- 土星入旺：天秤座

## 特殊配置提示

### 多星連動

當某一顆星同時與多顆星形成強相位，它可能成為整張盤的關鍵橋樑。

### 大量星體集中

若星體集中在少數宮位，代表生命能量高度聚焦，那些宮位會成為人生主軸。

### 空宮

空宮不代表缺失。要追該宮宮頭星座的守護星，看能量被帶到哪個宮位運作。

### 日間盤與夜間盤

- 太陽在第七宮到第十二宮：偏日間盤。
- 太陽在第一宮到第六宮：偏夜間盤。

## 總結

完整星盤解讀可以用一句話記住：

> 行星是驅動力，星座是表現方式，宮位是生活場景，相位是能量之間的關係。
