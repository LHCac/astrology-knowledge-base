# Astrology Terms｜占星專有名詞整理

整理自 Notion「星座星盤」中的占星名詞筆記，已轉成 GitHub Markdown 知識庫格式。

## 星體分類

| 名詞 | 英文 | 說明 |
|---|---|---|
| 個人星 | Personal Planets | 太陽、月亮、水星、金星、火星，影響最個人化 |
| 社會星 | Social Planets | 木星、土星，代表社會層面的擴展與限制 |
| 世代星 | Generational Planets | 天王星、海王星、冥王星，代表世代共同印記 |
| 小天體 | Minor Bodies | 凱龍、智神、灶神、穀神、婚神等小行星 |
| 虛點／感應點 | Sensitive Points | 幸運點、莉莉斯、南北交點等計算點 |

## 宮位與守護星

| 名詞 | 英文 | 說明 |
|---|---|---|
| 守護星回駐／廟 | Domicile | 守護星落回自己掌管的位置，能量集中純粹 |
| 互容 | Mutual Reception | 兩個守護星互換位置，形成彼此支援的系統 |
| 星盤主星／上升主星 | Chart Ruler | 上升星座的守護星，代表整張星盤的重要基調 |
| 逆行 | Retrograde | 星體能量向內運作，需要內在深耕 |
| 宮頭 | House Cusp | 每個宮位的起點與邊界 |

## 主要相位

| 相位 | 英文 | 角度 | 感覺 |
|---|---|---:|---|
| 合相 | Conjunction | 0° | 能量融合、彼此強化 |
| 六分相 | Sextile | 60° | 溫和機會，需要主動激活 |
| 四分相 | Square | 90° | 成長張力、摩擦與推動 |
| 三分相 | Trine | 120° | 天賦流暢、自然合作 |
| 八分之三相 | Sesquiquadrate | 135° | 持續微摩擦，需要調整 |
| 十二分之五相 | Quincunx / Inconjunct | 150° | 格格不入，需要磨合 |
| 對分相 | Opposition | 180° | 拉扯對立，需要整合 |

## 其他常見名詞

| 名詞 | 英文 | 說明 |
|---|---|---|
| 南北交點 | South / North Node | 南交點代表熟悉模式，北交點代表成長方向 |
| 凱龍星 | Chiron | 深層傷口，也可能成為療癒他人的能力 |
| 莉莉斯 | Black Moon Lilith | 被壓抑的原始力量與不願妥協之處 |
| 幸運點 | Part of Fortune | 容易感受幸福與豐盛的場域 |
| 容許度 | Orb | 判斷相位是否成立的角度誤差範圍 |

## 行星尊貴系統

| 名詞 | 英文 | 說明 |
|---|---|---|
| 廟／回駐 | Domicile | 行星在自己守護的星座，力量最自然 |
| 旺 | Exaltation | 行星在特定星座表現特別好 |
| 三分性 | Triplicity | 行星在同元素星座時有加持效果 |
| 陷 | Detriment | 行星在守護星座的對宮，力量受阻 |
| 弱 | Fall | 行星在入旺星座的對宮，表現較弱 |

## 相位結構

| 名詞 | 英文 | 說明 |
|---|---|---|
| 大三角 | Grand Trine | 三顆星互相三分相，天賦強但可能太順 |
| T 型三角 | T-Square | 一組對分加上一顆星四分兩端，成長壓力強 |
| 大十字 | Grand Cross | 兩組對分與多組四分，壓力與潛力都大 |
| 風箏 | Kite | 大三角加上一顆對分星，讓天賦有出口 |
| 神秘矩形 | Mystic Rectangle | 兩組對分搭配六分相，需整合多股能量 |

## 星盤分析結構

| 名詞 | 英文 | 說明 |
|---|---|---|
| 日間盤 | Diurnal Chart | 太陽在地平線上方，偏外顯與社會化 |
| 夜間盤 | Nocturnal Chart | 太陽在地平線下方，偏內在與私領域 |
| 半球分布 | Hemisphere Distribution | 看星體集中在星盤上下左右哪一區 |
| 入相位 | Applying Aspect | 兩顆星正在靠近，相位影響增強 |
| 離相位 | Separating Aspect | 兩顆星正在遠離，相位影響減弱 |

## 合盤相關

| 名詞 | 英文 | 說明 |
|---|---|---|
| 合盤 | Synastry | 疊合兩張星盤，看彼此星體互動 |
| 複合盤 | Composite Chart | 以兩人星盤中點形成關係盤 |
| 行運 | Transit | 當下天空行星對本命盤的影響 |
| 推運 | Progression | 用推算方式看人生發展階段 |
| 太陽弧 | Solar Arc | 以太陽弧推進方式觀察生命事件 |

## 解讀優先順序

1. 個人星：太陽、月亮、水星、金星、火星
2. 上升與天頂：AC、MC
3. 社會星：木星、土星
4. 世代星：天王星、海王星、冥王星
5. 小天體：凱龍、四大小行星等
6. 虛點：南北交點、幸運點、莉莉斯等
